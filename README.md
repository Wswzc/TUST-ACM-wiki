## 这个知识库是什么

这是一个**持续更新、长期积累**的实验室 Wiki。它不是某一个人的笔记，而是实验室一届又一届传承下来的共同资产。

我们相信一件事：**写下来的知识，才是实验室的知识。** 一个人搞懂了一个算法、踩过了一个坑、读懂了一份行业报告，如果只留在自己脑子里，那么下一届还要从零开始。写进知识库，它就永远属于 TUST-ACM 算法实验室。

## 如何投稿一篇文章

1. 在 [`templates/article-template.md`](templates/article-template.md) 复制一份模板。
2. 放到合适的分类目录下，文件名用简洁的中文或英文，例如 `并查集入门.md`。
3. 按 [写作规范](articles/00-团队指南/写作规范.md) 填写文章头部信息（标题、作者、日期、标签）。
4. 在 [`INDEX.md`](INDEX.md) 里登记你的文章。
5. 如果使用 Git，提交并发起合并请求；如果不用 Git，直接放进目录即可。

## 约定

- 一切文章统一使用 **Markdown** 格式。
- 图片放在 [`assets/images/`](assets/images/) 下，用相对路径引用。
- 鼓励小步快跑：**一篇只讲清楚一件事**，宁可短而精，不要长而空。
- 尊重来源：引用他人内容请注明出处。
