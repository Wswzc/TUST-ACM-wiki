# 莫队：把询问排序，让窗口自己挪

> 读完你应该能：判断一道题是不是「只查、不改、区间」的离线莫队；写出 `add` / `del` 和四句 `while` 伸縮指针；用分块排序把总移动次数压到约 `n√n`；知道带修莫队和树上莫队是另一档。
>
> 一句口号：**暴力是每个询问从头扫区间；莫队让相邻询问共用窗口，只付指针移动的钱。**

## 背景 / 为什么要读这篇

[树状数组](树状数组.md) / [线段树](线段树入门.md) 适合「改一点、问一段」且信息能合并。有些信息不好合并：区间里有多少种数、出现次数的平方和、众数。n、q = 1e5，每个询问扫一遍是 1e10。

如果**没有修改**、询问可以离线，莫队把询问按「左端点所在块、右端点」排序，维护一个当前 `[l,r]`，每次只把 l、r 挪到下一个询问。实验室有人 `del` 和 `add` 顺序反了，指针先越过再删，出现次数变成负数；有人块大小写成 1 或 n。本篇钉普通莫队。

## 正文

### 1. 什么时候能用

要同时满足：

1. 询问是区间 `[L,R]`，只读。  
2. 已知 `[l,r]` 的答案，能 O(1) 或 O(log) 扩展成 `[l,r+1]`、`[l-1,r]` 等（有 `add`），也能缩回来（有 `del`）。  
3. 可以离线：先读完所有询问再输出。

典型：颜色种类数、出现次数的 k 次方和。在线或带点修改，先别上普通莫队。

### 2. 指针怎么挪

当前窗口 `(cl, cr)`，下一个询问 `(l, r)`。四个 while，**先扩后缩或按你习惯固定顺序，但 `del` 时下标必须还在窗口里**：

```cpp
while (cr < r) add(++cr);
while (cl > l) add(--cl);
while (cr > r) del(cr--);
while (cl < l) del(cl++);
```

`add(pos)`：把 `a[pos]` 纳入统计。`del(pos)`：拿出去。例如种类数：

```cpp
int cnt[N], now;  // now = 当前窗口不同数的个数
void add(int i) {
    if (++cnt[a[i]] == 1) now++;
}
void del(int i) {
    if (--cnt[a[i]] == 0) now--;
}
```

初始 `cl=1, cr=0`（空窗口，假设下标从 1）。不要两边都设成 1 却没 `add(1)`。

### 3. 排序：块 + 奇偶翻折

块大小 `B ≈ n/√q` 或 `√n`。询问按 `(L/B, R)` 排。同一块内右端点单调，块与块之间左端点每次跳 O(B)。

总复杂度粗算 O(n√n)：左指针跨块 O(√n · n)，右指针每块内扫 O(n) 再乘块数。常数难看，但 1e5 常能过。

同一块内右端点来回扫会浪费。**奇偶翻折**：块编号为奇数时 R 升序，偶数时降序，右指针少折返。

```cpp
int B;
struct Query { int l, r, id; };
bool cmp(const Query& a, const Query& b) {
    int x = a.l / B, y = b.l / B;
    if (x != y) return x < y;
    return (x & 1) ? (a.r < b.r) : (a.r > b.r);
}
```

`B` 用 `sqrt(n)` 或稍大约 `n / sqrt(q)`。不要 `B=1`。

### 4. 和数据结构怎么选

| 题 | 更可能 |
| --- | --- |
| 单点改、区间和 / 最值 | 树状数组、线段树 |
| 只问、区间种类 / 次数平方 | 莫队 |
| 只问、区间种类、强制在线 | 主席树等，不是本篇 |
| 带改的区间种类 | 带修莫队（再加一维时间），入门先别写 |

P1972 项链一类「区间颜色数」也常用离线树状数组（每种颜色只算最后一次出现）。能上 BIT 往往比莫队快、好写。莫队的价值是：**`add`/`del` 好写、合并公式没有时仍能过。**

## 常见坑 / 注意事项

- **`del` 写在指针已经离开之后。** 先 `del(cr)` 再 `cr--`。  
- **`cnt` 减成负数。** `add`/`del` 不对称，或初始窗口错。  
- **在线输出却莫队离线。** `ans[id]` 最后再打印。  
- **`a[i]` 到 1e9 当数组下标。** 先离散化。  
- **多组数据 `cnt` 没清。**  
- **块大小用 `sqrt(n)` 写成整数 0。** n=1 特判。

## 趣味课间：实验室经典翻车集

- **「莫队就是分块。」** 分块是数据结构；莫队是给询问排序的暴力优化。亲戚，不是同一个板子。  
- **样例 q=1。** 任何顺序都对。造左右端点来回跳的数据才看得出排序。  
- **`while` 四句抄反成先缩后扩，经过非法状态。** 种类数 `cnt` 变负，答案飞了。  
- **TLE 就改成 `__int128`。** 莫队 TLE 先检查 `B` 和是否 `ios::sync`，不是精度问题。

## 小结

离线区间、能加减一个端点，就让窗口爬。块内排 R、奇偶翻折减折返。`add`/`del` 对称，答案记在 `id` 上。能用树状数组合并就别上莫队。
