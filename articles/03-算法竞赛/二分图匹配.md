# 二分图匹配：左右两组，一对一牵手

> 读完你应该能：判断一张图是不是二分图（染色）；用匈牙利算法求出最大匹配；把「每人选一个岗位、每门课一个教室」翻译成左右点集 + 边；知道霍尔定理存在，入门先会写 DFS 增广。
>
> 一句口号：**匹配就是没有公共端点的边集。增广路 = 一条从空男走到空女、交错着已有婚约的路，翻过来匹配数 +1。**

## 背景 / 为什么要读这篇

[新人指南](../00-团队指南/新人指南.md) 第 2 年写过「网络流或匹配看队伍需求」。匹配往往比Dinic短，NOIP/省选普及向也更常见：男孩女孩、任务机器、行与列上的棋子。

二分图：点能分成 L、R，边只出现在 L 与 R 之间，同侧无边。等价于无奇数环，可用 [BFS](BFS网格最短路.md) 黑白染色判定。

实验室有人把一般图匹配拿匈牙利硬套（奇数环会错）；有人 vis 数组没按「每一次增广」重置。本篇只打穿**无权最大匹配**。带权是 KM，一般图是带花树，先别碰。

## 正文

### 1. 名词

- **匹配：** 没有两条边共用一个点。  
- **最大匹配：** 边数最多的匹配。  
- **完备匹配：** 一侧（或全部）点都被匹配。  
- **交错路：** 匹配边与非匹配边交替。  
- **增广路：** 交错路，且两端是未匹配点。沿它翻转（非匹配变匹配、反之），匹配数 +1。

Berge：匹配最大 ⇔ 没有增广路。匈牙利就是反复找增广路。

### 2. 染色判定二分图

```cpp
vector<int> col;  // 0 未染，1/2 两色
bool ok = true;
void dfs(int u, int c) {
    col[u] = c;
    for (int v : g[u]) {
        if (!col[v]) dfs(v, 3 - c);
        else if (col[v] == c) ok = false;
    }
}
```

无向图。有奇环则 `ok=false`。二分图匹配前最好先判，除非题面保证。

### 3. 匈牙利（DFS 增广）

左侧 1..n，右侧 1..m。`match[v]` = 右侧 v 当前匹配的左点，0 表示空。

```cpp
vector<vector<int>> g;  // g[u] = 左 u 连到的右点
vector<int> match, vis;
int stamp;  // 每次增广 +1，代替 memset vis

bool dfs(int u) {
    for (int v : g[u]) {
        if (vis[v] == stamp) continue;
        vis[v] = stamp;
        if (!match[v] || dfs(match[v])) {
            match[v] = u;
            return true;
        }
    }
    return false;
}

int hungarian(int nL, int nR) {
    int ans = 0;
    match.assign(nR + 1, 0);
    vis.assign(nR + 1, 0);
    stamp = 0;
    for (int u = 1; u <= nL; u++) {
        ++stamp;
        if (dfs(u)) ans++;
    }
    return ans;
}
```

每次给一个未匹配的左点找路。`vis` 标记本轮右侧，防止环。若右侧已有对象，就让对方再去找下家——递归。

复杂度 O(n m)：每个左点一次 DFS，每次扫边。n、m=1e3 能过；更大上 Dinic 或 HK（Hopcroft–Karp）。

### 4. 建图翻译

| 题面 | L | R | 边 |
| --- | --- | --- | --- |
| n 人 m 工作，人 i 能做若干工作 | 人 | 工作 | 能做 |
| 棋盘放车互不攻击 | 行 | 列 | 该格可放 |
| 最小路径覆盖（DAG） | 拆点 i 与 i' | i→j 原边则 i 连 j' | 结论：n−最大匹配 |

最小点覆盖 = 最大匹配（König，二分图）。入门知道「覆盖所有边的最少点 = 匹配数」，证明以后补。

### 5. 和网络流的关系

源点连所有左点容量 1，右点连汇点容量 1，原边容量 1，最大流 = 最大匹配。所以匹配是流的特例。[最大流入门](最大流入门.md) 用同一套增广，只是边权变成容量。

能匈牙利就匈牙利。要费用、上下界、一般网络，再上流。

## 常见坑 / 注意事项

- **奇环图用匈牙利。** 先染色。  
- **`vis` 全局只清一次。** 必须每轮增广刷新。  
- **左右编号都从 1 却开在同一个数组里撞号。** 右部可 +n 错开，或分两个数组。  
- **有向边只建一边。** 匹配图通常无向「能配对」。  
- **输出方案时 `match` 是右→左。** 要左→右再扫一遍。  
- **多重边。** 不影响最大匹配个数。

## 趣味课间：实验室经典翻车集

- **「匹配不就是贪心连边吗？」** 贪心没有增广，会卡在局部。增广路就是允许悔婚。  
- **样例完美配对。** 造一个必须悔婚才能最大的：1 连 a、b；2 只连 a。先给 1 配 a 则 2 失败，增广后 1 改配 b。  
- **n=2e5 匈牙利 TLE。** 换 Dinic 二分图优化或 HK。  
- **把 KM 当匈牙利。** 带权是另一份五十行。

## 小结

二分图 = 可二染色。最大匹配 = 反复增广。匈牙利：对每个左点 DFS，让右点要么空着要么原配再找。建图比代码难，先把「谁和谁能配对」画对。
