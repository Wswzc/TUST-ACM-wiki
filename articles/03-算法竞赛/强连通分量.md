# 强连通分量：有向图里谁和谁能互相走到

> 读完你应该能：说出有向图强连通的定义；用 Tarjan 一次 DFS 求出每个点所属的 SCC；把图缩成 DAG 之后用 [拓扑排序](拓扑排序.md)；分清「强连通」和「边双 / 点双」不是同一份模板。
>
> 一句口号：**一个 SCC 里任意两点互相可达；缩完之后，图变成一张没有环的有向图。**

## 背景 / 为什么要读这篇

无向图里「一伙」用 [并查集](并查集.md) 或一次 DFS 就够。有向图里 A 能到 B、B 不一定能回 A——「一伙」要改成**强连通分量**（Strongly Connected Component，SCC）。

区域赛常见套路：先缩点，再在 DAG 上 DP、统计入度 0 的点、或「选最少点能到达全部」。实验室有人把无向图的割边 Tarjan 抄到有向图上；有人 `low[u] = min(low[u], low[v])` 对已经出栈的点也做，SCC 碎成一盘散沙。本篇只打穿**有向图 SCC + 缩点**。

## 正文

### 1. 定义，用一张小图钉死

有向图。若 u 能走到 v 且 v 能走到 u，则它们**强连通**。强连通关系把点划分成若干极大集合，每个集合是一个 SCC。

```text
1 → 2 → 3
↑   ↓   ↓
4 ←┘    5
```

若还有 3→1，则 1,2,3,4 可能同一块（取决于具体边）；5 出不去就自己一块。单点永远是 SCC。一条单向链上每个点各成一块。

缩点：每个 SCC 变成一个超级点。原图跨分量的边变成超级点之间的边。缩完**一定是 DAG**——若两个超级点还能互相走到，它们本该是同一分量。

于是 [拓扑排序](拓扑排序.md) 重新上场：入度、DAG DP、最长路，全部搬到缩点图上。

### 2. Tarjan：dfn、low、栈

给每个点两个时间戳：

| 数组 | 含义 |
| --- | --- |
| `dfn[u]` | u 第一次被访问的时间 |
| `low[u]` | u 这棵 DFS 子树里，能摸到的**仍在栈中**的点的最小 dfn |

沿边走：

- `v` 没访问：先递归，再用 `low[v]` 更新 `low[u]`。
- `v` 在栈里（返祖或横叉到当前分量）：用 `dfn[v]` 更新 `low[u]`。
- `v` 访问过但不在栈里：已经属于别的 SCC，**不要**用它的 `low`。

`dfn[u] == low[u]` 时，u 是当前 SCC 的根：把栈一直弹到 u（含 u），弹出的点同一分量。

```cpp
const int N = 10005;
vector<int> g[N];
int dfn[N], low[N], ins[N], scc[N];
int ts, scc_cnt;
vector<int> stk;

void tarjan(int u) {
    dfn[u] = low[u] = ++ts;
    stk.push_back(u);
    ins[u] = 1;
    for (int v : g[u]) {
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (ins[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (dfn[u] == low[u]) {
        ++scc_cnt;
        while (true) {
            int x = stk.back();
            stk.pop_back();
            ins[x] = 0;
            scc[x] = scc_cnt;
            if (x == u) break;
        }
    }
}

void run(int n) {
    ts = scc_cnt = 0;
    stk.clear();
    fill(dfn + 1, dfn + n + 1, 0);
    for (int i = 1; i <= n; i++)
        if (!dfn[i]) tarjan(i);
}
```

复杂度 O(n+m)。每个点进一次栈、出一次栈。

**Kosaraju** 是另一套：原图 DFS 记完成序，反图按该序再 DFS，每棵树一个 SCC。两套都对。队内模板定一种，赛时不要两种混着改。

### 3. 缩点之后干什么

```cpp
vector<int> dag[N];
int indeg[N];

void build_dag(int n) {
    for (int u = 1; u <= n; u++) {
        for (int v : g[u]) {
            if (scc[u] != scc[v]) {
                dag[scc[u]].push_back(scc[v]);
                indeg[scc[v]]++;
            }
        }
    }
    // 需要时对 dag[i] sort + unique，去掉重边
}
```

经典问法（记形状，不要背题号当唯一）：

| 题在问 | 缩点后 |
| --- | --- |
| 最少选几个点能到达所有点 | 入度 0 的超级点个数（图弱连通等前提下，读题） |
| 加几条边变成强连通 | `max(入度 0 的个数, 出度 0 的个数)`，单点图是 0 |
| 分量上有点权 | 先把同一 SCC 的权合并，再 DAG DP |

P3387 缩点：同一 SCC 里的点权可以都拿（能互相走到），然后在 DAG 上求一条点权最大的链。

### 4. 和「割边 Tarjan」别抢同一份脑子

无向图求桥、割点也叫 Tarjan，也用 `dfn`/`low`，**判定条件和栈不同**。有向图不要拿无向图桥的模板改两行。本篇的 `ins[v]` 判断是 SCC 专用。

边双连通、点双连通以后单独写。看见题面「无向图、割掉一条边」先停手。

## 常见坑 / 注意事项

- **对已出栈的 v 做 `low[u] = min(low[u], low[v])`。** 会把别的分量焊回来。必须 `ins[v]`。  
- **多组数据 `dfn`、`ts`、`stk` 没清。**  
- **图不连通只从 1 开始 `tarjan`。** `for` 扫所有 `!dfn[i]`。  
- **缩点建边没判 `scc[u]!=scc[v]`。** 自环会毁 DAG。  
- **重边把入度算爆。** 去重或用 set。  
- **无向图当有向图跑 SCC。** 无向边要当成两条有向边吗？那几乎整图一块。先确认题目方向。  
- **递归 n=1e5 链。** 可能爆栈，扩栈或改非递归；国内 OJ 有时要 `#pragma`。

## 趣味课间：实验室经典翻车集

- **「强连通就是弱连通加方向。」** 一条单向环是强连通；一条单向链不是。  
- **样例就一个环。** 任何实现都对。造两个环共一个点，或环外挂一条出边。  
- **`low` 和 `dfn` 谁更新谁说不清，于是两个数组混用。** 纸上走一遍 1→2→3→1，弹出时三个点 `dfn` 不同、`low` 都等于根的 `dfn`。  
- **缩点后拓扑，点编号还用原图 1..n。** 超级点只有 `scc_cnt` 个。

## 小结

SCC：有向图里能互相走到的极大点集。Tarjan 用 dfn、low、栈一次 DFS 切出来。缩点得 DAG，再拓扑或 DP。无向图的桥 / 割点是另一份模板。

建议练习：

- 洛谷 [P3387 【模板】缩点](https://www.luogu.com.cn/problem/P3387)
- 洛谷 [P2341 [USACO03FALL / HAOI2006] 受欢迎的牛](https://www.luogu.com.cn/problem/P2341)
- 手跑一个 3 点环外加一个出点，写出每次 `dfn`/`low` 和弹栈顺序
