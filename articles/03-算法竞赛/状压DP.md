# 状压 DP：把集合塞进一个整数

> 读完你应该能：用二进制每一位表示「某个元素在不在集合里」；写出 `for (int s=0;s<1<<n;s++)` 的转移；会枚举子集、枚举子集的子集；判断 n=20 与 n=30 谁能状压、谁不能。
>
> 一句口号：**2^n 个子集就是 0 到 (1<<n)-1 这些整数。DP 的一维从「选了哪些」变成一个 int。**

## 背景 / 为什么要读这篇

[DFS 回溯](DFS回溯.md) 枚举子集是 2^n 棵树。[01 背包](01背包.md) 把「选或不选」压成容量维。当**约束在集合形状上**（哪些城市走过、哪几行已经放了棋）而 n≤20，就把集合当状态。

[新人指南](../00-团队指南/新人指南.md) 第 2 年写过状压。它不是新语言，是位运算 + 背包式循环。实验室有人 `n=25` 硬开 `1<<25` 的 `int` 数组（128MB 量级还乘别的维），MLE；有人枚举子集写成 `for(int s=0;s<(1<<n);s++) for(int t=0;t<(1<<n);t++)` 变成 4^n。本篇先把位运算和 TSP 骨架钉死。

## 正文

### 1. 位运算速查（竞赛用那几下）

集合 s 是 int。第 i 位（从 0）表示元素 i。

| 操作 | 写法 |
| --- | --- |
| 是否含 i | `s >> i & 1` |
| 加入 i | `s | (1 << i)` |
| 去掉 i | `s & ~(1 << i)` |
| 最低的 1 | `s & -s`（[树状数组](树状数组.md) 的 lowbit） |
| 去掉最低 1 | `s & (s - 1)` |
| 元素个数 | `__builtin_popcount(s)` |
| 枚举 0..n-1 的全部子集 | `for (int s = 0; s < (1 << n); s++)` |

`1 << n` 当 n=31 注意符号位；n≥31 用 `1LL << n`。状态数组下标仍是 `int` 时 n 通常 ≤ 20，`1<<20` = 1048576。

**枚举 s 的非空子集 t：**

```cpp
for (int t = s; t; t = (t - 1) & s) {
    // t 是 s 的非空子集
}
// 空集单独处理
```

这是 O(3^n) 总体（对所有 s 做一遍），不是 O(4^n)。记下来，子集卷积、插头 DP 入门会再见。

### 2. 旅行商 TSP：走过的城市 + 当前位置

n 个点，点间距离 `d[i][j]`，从 0 出发走遍每个点恰好一次的最短路（可再回到 0，看题）。

`dp[s][i]` = 已走集合 s、当前停在 i 的最短路。转移：从 j 走到 i，j 在 s 里、i 也在，且 `j!=i`。

```cpp
const int INF = 0x3f3f3f3f;
int n;
int d[20][20];
int dp[1 << 16][16];  // n<=16 量级

int tsp() {
    memset(dp, 0x3f, sizeof dp);
    dp[1][0] = 0;  // 只走了 0，停在 0
    for (int s = 0; s < (1 << n); s++) {
        for (int i = 0; i < n; i++) {
            if (!(s >> i & 1)) continue;
            if (dp[s][i] >= INF) continue;
            for (int j = 0; j < n; j++) {
                if (s >> j & 1) continue;
                int ns = s | (1 << j);
                dp[ns][j] = min(dp[ns][j], dp[s][i] + d[i][j]);
            }
        }
    }
    int ans = INF;
    int full = (1 << n) - 1;
    for (int i = 0; i < n; i++)
        ans = min(ans, dp[full][i] + d[i][0]);  // 回到起点；不需要则去掉 +d[i][0]
    return ans;
}
```

复杂度 O(n² 2^n)。n=16～18 视常数。n=20 再乘别的维要算内存：`dp[1<<20][20]` 的 `int` 约 80MB，卡边界。

哈密顿路径、最短哈密顿回路都是这张表。

### 3. 棋盘互不侵犯一类

n×n 棋盘放 k 个国王互不攻击：每一行的放置是一个 mask（哪些列放了），相邻行 mask 不能「靠近」。`dp[row][k][mask]`。行 n≤10、列 n≤10 时 2^n 很小。

预处理合法 mask：同一 mask 内两位不能相邻（`(s & (s<<1))==0`）。

这是「轮廓 / 行状压」的入口。入门先会 TSP，再做互不侵犯。

### 4. 什么时候不是状压

| n | 集合 DP |
| --- | --- |
| ≤ 20，只要子集形状 | 状压 |
| ≤ 40，子集和 | 折半，不是 2^40 数组 |
| 1e5 | 其他 DP / 数据结构 |

「n 个人排队」n=10 可以状压；n=1e5 是排列计数或贪心。看见 n≤20 先问：状态能塞进 2^n 吗？

## 常见坑 / 注意事项

- **`1 << n` 当 n=31 溢出成负。**  
- **`dp` 没初始化成 INF，min 全是 0。**  
- **转移时 `j` 已在 s 里还或进去。**  
- **枚举子集用双重 1<<n。** 用 `(t-1)&s`。  
- **`memset(dp, 0x3f, sizeof dp)` 后加法溢出 INF。** 比较前判断，或 INF 取小一点。  
- **内存按 `1<<n` 乘第三维没算。**  
- **`__builtin_popcountll` 与 int 搞混。**

## 趣味课间：实验室经典翻车集

- **「状压就是把 vis 数组压成 int。」** 对，而且 vis 要进 DP 下标，不能只是搜索里的 vis。  
- **样例 n=4。** 任何实现都对。n=12 才暴露 INF 和复杂度。  
- **TSP 不回起点却加了 `d[i][0]`。** 读题。  
- **棋盘按格子 2^{n*n}。** n=8 是 2^64。应按行压列。

## 小结

子集 ↔ 二进制。TSP：`dp[s][i]` 已走 s、停在 i。互不侵犯：行间 mask 兼容。n 超 20 先停手。位运算比新算法更重要。
