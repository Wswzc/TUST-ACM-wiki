# 字典树：边是字符，点是前缀

> 读完你应该能：用儿子数组插入、查找一个字符串；统计有多少个单词以某前缀开头；知道 01-Trie 用来做异或最值，那是同一棵树、字符表变成 0/1；和 [AC 自动机](AC自动机入门.md) 的差别：Trie 不负责失配跳转。
>
> 一句口号：**从根往下走，每条边一个字符；走到的点，就是这条路径拼出来的前缀。**

## 背景 / 为什么要读这篇

[map](../01-编程语言/map与set.md) 能存整个字符串当键，前缀查询要扫描所有键。[KMP](KMP.md) 是一个模式对一段文本。很多单词一起问「有没有这个前缀、这个词出现过几次」，用字典树（Trie）：共享前缀，边是字符。

[AC 自动机](AC自动机入门.md) 的第一层就是 Trie，再加 fail。本篇只建树和查询。实验室有人 `ch[u][c]` 的 c 用了字符 `'a'` 没减 `'a'`，下标 97 越界；有人插入时在每个前缀都 `cnt++`，查询单词和查询前缀搅在一起。

## 正文

### 1. 插入和查找

26 个小写字母。结点 0 是根。`ch[u][c]` 是儿子编号，0 表示没有。

```cpp
const int N = 1000005;
int ch[N][26], cnt[N], tot;

void insert(const string& s) {
    int u = 0;
    for (char c : s) {
        int x = c - 'a';
        if (!ch[u][x]) ch[u][x] = ++tot;
        u = ch[u][x];
    }
    cnt[u]++;  // 单词在此结束
}

int query_word(const string& s) {
    int u = 0;
    for (char c : s) {
        int x = c - 'a';
        if (!ch[u][x]) return 0;
        u = ch[u][x];
    }
    return cnt[u];
}
```

`cnt[u]` 只在单词结尾 +1。若要「有多少单词以 s 为前缀」，插入时沿途每个点 `pass[u]++`，查询走到终点读 `pass`。两件事分开存，不要用一个计数身兼二职却说不清。

空间：总字符数 × 26 个 `int`。总长 1e6 时结点约 1e6，`ch` 约 1e6×26×4B ≈ 100MB，卡着。字符集更大就改 `map` 或动态结点，慢一些但省空间。

### 2. 01-Trie：异或最大值

每个数写成 31 位（或 63 位）二进制，高位在前插入。查询 x 的最大异或：从高位走，能走和 x 相反的儿子就走。

这和 [线性基](线性基.md) 都做异或最值，场景不同：

| | 01-Trie | 线性基 |
| --- | --- | --- |
| 问 | 和**某一个已有数**的最大异或 | 子集 XOR 的最大 |
| 可删除 | 可以在结点上挂引用计数 | 删除麻烦 |

n 个数两两最大异或：一边插入一边查询，O(n × 位数)。

### 3. 和哈希、AC

整词是否出现过：哈希或 `unordered_set` 也行。Trie 的优势是**前缀**和**按位贪心**。多模式在文本里跳：AC 自动机，不要在 Trie 上对每个模式各跑一遍 KMP（那是另一题的暴力）。

## 常见坑 / 注意事项

- **`'A'-'a'` 当小写。** 读题字符集。  
- **多组数据 `tot` 和 `ch` 没清。** `memset` 只清 `tot+1` 个结点，不要每次 `memset` 整个 100MB。  
- **根也 `cnt++`。** 空串。  
- **01-Trie 从低位插，查询从高位贪。** 对不齐。  
- **`++tot` 前结点 0 被占用。** 根固定 0，`tot` 从 0 开始，第一个儿子是 1。  
- **前缀计数和单词计数混用。**

## 趣味课间：实验室经典翻车集

- **「Trie 就是 26 叉树。」** 对，并且题几乎总在「共享前缀」或「高位相反」。不会问你中序遍历。  
- **样例单词互不为前缀。** 测不出 `pass` 和 `cnt` 的差别。造 `app` 和 `apple`。  
- **异或题用线性基，题面是「和数组里某一个数」。** 基求的是子集。  
- **清空用 `memset(ch,0,sizeof ch)` 在 1e6×26 上，多组 TLE。** 记录用过的结点回收。

## 小结

边是字符，路径是前缀。结尾计数是单词，沿途计数是前缀。01-Trie 高位贪心做与某个数的最大异或。失配边是 AC 的事。
