# 高斯消元：把方程组熬成上三角

> 读完你应该能：用选主元把增广矩阵消成阶梯形；判断唯一解 / 无解 / 无穷多解；在模 p 下写出一套能交的板子；知道异或方程组是同一套，加法改成 XOR、乘法改成 AND。
>
> 一句口号：**每一列找出一个「1」，用它把同列其它行削成 0。剩下的就是解。**

## 背景 / 为什么要读这篇

[扩展欧几里得](扩展欧几里得.md) 解一个方程两个未知数。[中国剩余定理](中国剩余定理.md) 解一串模数互质的同余。[矩阵快速幂](矩阵快速幂.md) 把矩阵当乘法用。方程组 `Ax = b` 要的是**消元**：把矩阵变成容易回代的形状。

区域赛包装：开关灯、线性递推系数、概率（期望列方程）、异或最大（线性基）。实验室有人用浮点消元去解 `mod 1e9+7`；有人不换主元，对角是 0 就除零；有人有自由元还当唯一解输出。本篇钉模 p 消元，再提一刀异或。

## 正文

### 1. 增广矩阵在干什么

n 个方程、m 个未知数，把系数和右端贴在一起：

```text
a11 x1 + a12 x2 + ... + a1m xm = b1
...
```

变成 n 行、m+1 列。允许三种初等行变换（解集不变）：换两行、一行乘非零、一行加减另一行的若干倍。

目标：每一列尽量出现一个主元（pivot），主元下方（高斯）或整列（高斯-若尔当）变成 0。然后从下往上回代，或直接读最后一列。

解的三种脸：

| 形状 | 结论 |
| --- | --- |
| 秩(A) = 秩(A|b) = m | 唯一解 |
| 秩(A) = 秩(A|b) < m | 无穷多（有自由元） |
| 秩(A) < 秩(A|b) | 无解（出现 `0 = 非 0`） |

竞赛常保证有唯一解，仍要会判——出题人未必保证。

### 2. 模 p 的高斯-若尔当

p 是质数时，除法 = 乘逆元，见 [数论入门](数论入门.md) 的 `qpow(a, p-2)`。下面把第 r 行主元变成 1，再把**所有其它行**的这一列削掉。

```cpp
const long long MOD = 998244353;

long long qpow(long long a, long long b) {
    long long r = 1;
    for (; b; b >>= 1, a = a * a % MOD)
        if (b & 1) r = r * a % MOD;
    return r;
}

// a[i][0..m-1] 系数，a[i][m] 为 b。返回主元个数（秩）。无解返回 -1
int gauss(vector<vector<long long>>& a) {
    int n = (int)a.size();
    int m = (int)a[0].size() - 1;
    int r = 0;
    vector<int> where(m, -1);
    for (int c = 0; c < m && r < n; c++) {
        int p = r;
        for (int i = r; i < n; i++)
            if (a[i][c] != 0) { p = i; break; }
        if (a[p][c] == 0) continue;  // 这一列全 0，c 是自由元
        swap(a[p], a[r]);
        long long inv = qpow(a[r][c], MOD - 2);
        for (int j = c; j <= m; j++) a[r][j] = a[r][j] * inv % MOD;
        for (int i = 0; i < n; i++) {
            if (i == r || a[i][c] == 0) continue;
            long long f = a[i][c];
            for (int j = c; j <= m; j++)
                a[i][j] = (a[i][j] - f * a[r][j] % MOD + MOD) % MOD;
        }
        where[c] = r;
        r++;
    }
    for (int i = r; i < n; i++)
        if (a[i][m] != 0) return -1;  // 0 = 非 0
    return r;
}
```

唯一解时：`where[c] != -1` 的列，`x[c] = a[where[c]][m]`；自由元按题意赋 0。`r < m` 且有解就是无穷多。

浮点几何题用 `eps` 比大小，**不要**和模数题混。`double` 消元解整数同余，是给 WA 开门。

### 3. 异或方程组 = 模 2

加法变 XOR，乘法变「这一位是 1 才加进去」。bitset 加速：

```cpp
const int M = 1024;
vector<bitset<M>> a;  // a[i][0..m-1] 系数，a[i][m] 为 b（M 要 > m）

int gauss_xor(int n, int m) {
    int r = 0;
    for (int c = 0; c < m && r < n; c++) {
        int p = r;
        for (int i = r; i < n; i++)
            if (a[i][c]) { p = i; break; }
        if (!a[p][c]) continue;
        swap(a[p], a[r]);
        for (int i = 0; i < n; i++)
            if (i != r && a[i][c]) a[i] ^= a[r];
        r++;
    }
    for (int i = r; i < n; i++)
        if (a[i][m]) return -1;
    return r;
}
```

线性基（一堆数能 XOR 出哪些值、最大值）是异或消元的亲戚：按位插入、高位优先。见 [线性基](线性基.md)。

开关灯：每个格子按或不按是未知量，影响是模 2 线性。方程个数 = 格子数。

### 4. 复杂度与什么时候不要上

O(n²m) 或 n≈m 时 O(n³)。n=300 可过，n=2000 看常数和 bitset。n=1e5 不是消元题。

非线性（乘积项、`x²`）消不掉。先看是不是线性。

## 常见坑 / 注意事项

- **对角为 0 仍去除。** 先换主元。  
- **模数不是质数还求逆。**  
- **`a[i][j] - f*a[r][j]` 忘加 MOD。**  
- **自由元当唯一解。**  
- **无解行没检查 `a[i][m]`。**  
- **浮点和模数混用。**  
- **bitset 宽度 ≤ m。** 右端 b 也要占一位。

## 趣味课间：实验室经典翻车集

- **「线代课上过，板子不用默。」** 课上用计算器，赛时 1s 内 n=100。默写选主元那几行。  
- **样例 2×2 对角全非 0。** 任何顺序都对。造第一行 `{0,1,1}` 才会逼你换行。  
- **异或写成 `+` 再 `%2`。** 能过，但慢且容易和「真加法模 2」以外的题搅在一起。直接 `^`。  
- **期望 DP 列了方程，消元用 `double` 输出 `%.10f`，题面却要模 998244353。** 读清「模多少」。

## 小结

行变换把增广矩阵变成主元清晰的形状。模 p 用逆元，模 2 用 XOR。先判无解，再谈唯一或自由元。n³ 心里有数。矩阵乘法见 [矩阵快速幂](矩阵快速幂.md)，那是乘，不是消。
