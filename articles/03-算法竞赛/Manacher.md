# Manacher：每个中心的回文半径

> 读完你应该能：把奇偶长度的回文都变成「中心在字符上」的形式；写出带最右回文边界的线性扫描；用半径减一得到原串上的回文长度；知道它不负责后缀排序。
>
> 一句口号：**已经扫到的回文是一面镜子。新中心若落在镜子里，就从镜像的半径开始试，不要从 1 重新比。**

## 背景 / 为什么要读这篇

最长回文子串可以中心扩展，每个中心往外走，最坏 O(n²)。Manacher 记住当前到达最右的回文，利用对称性把失败的比较省掉，总比较次数 O(n)。

[KMP](KMP.md) 的 `pi` 是前缀失配，[后缀数组](后缀数组.md) 的 `height` 是后缀 LCP。回文是另一轴对称。实验室有人忘了插入分隔符，偶数长度的回文中心落在两字符之间，被漏掉；有人半径含分隔符却当原串长度交上去。

## 正文

### 1. 改成奇数长度

原串 `s`。构造 `t = # s0 # s1 # ... #`，再在首尾加哨兵（不同的字符，且不出现在串里），避免边界判断。下面用 `^` 和 `$`。

```text
s = abba
t = ^ # a # b # b # a # $
```

`t` 上每个位置 i 的回文都是奇数长度，中心就是 i。原串的奇数回文中心落在字母上，偶数回文中心落在 `#` 上。

`d[i]`：以 i 为中心、在 `t` 上能扩展的半径（含中心自己那一格）。对应原串回文长度是 `d[i]-1`（因为多出来的是 `#` 或两边被哨兵挡住的那一档；用下面的写法时，最大的 `d[i]-1` 就是原串最长回文长度）。

### 2. 线性扫描

维护当前最右回文的中心 `c` 和右端 `r`。i 在这个回文内部时，镜像是 `2*c-i`，半径至少是 `min(d[镜像], r-i+1)`，然后再暴力向外，直到失配。若扩展更新了最右端，移动 `c` 和 `r`。

```cpp
int manacher(const string& s) {
    string t = "^#";
    for (char c : s) {
        t.push_back(c);
        t.push_back('#');
    }
    t.push_back('$');
    int m = (int)t.size();
    vector<int> d(m);
    int ans = 0;
    for (int i = 1, c = 0, r = 0; i < m - 1; i++) {
        if (i < r) d[i] = min(d[2 * c - i], r - i);
        else d[i] = 1;
        while (t[i - d[i]] == t[i + d[i]]) d[i]++;
        if (i + d[i] > r) {
            c = i;
            r = i + d[i];
        }
        ans = max(ans, d[i] - 1);
    }
    return ans;
}
```

`^` 和 `$` 不相等，`while` 不会走出串。`d[i]` 在 `while` 结束后是「失配前」的半径：循环里先假定能扩到 `d[i]` 再 `++`，所以停下来时 `d[i]` 已经是最大且两端相等的半径。镜像转移来的初值要小于等于真实半径，`while` 负责补上没试过的部分。

每个位置的 `while` 成功次数，摊还到 `r` 的右移，总和 O(n)。

### 3. 要的不只是最长

最长回文长度：`max(d[i]-1)`。  
要输出子串：记录取到最大时的中心，再映射回原串下标。`t` 上去掉 `^` 之后，原串下标大约是 `(i - d[i] + 1) / 2` 这一类，手算 `abba` 对一下再交，不要背错映射。

回文自动机可以在线维护所有回文后缀。只要最长、或每个中心的半径，Manacher 更短。

## 常见坑 / 注意事项

- **不加 `#`，偶数回文漏掉。** `aa` 的最长是 2 不是 1。  
- **`d[i]-1` 写成 `d[i]`。** 多了分隔符。  
- **哨兵和串内字符相同。**  
- **镜像半径大于 `r-i` 仍全用镜像。** 不能超出已知的最右回文，所以要 `min`。  
- **空串。**  
- **下标从 `t` 的 0 开始扩，踩到没哨兵的位置。** 有 `^` `$` 才安全。

## 趣味课间：实验室经典翻车集

- **「回文就是正着反着哈希相等。」** 能做，要枚举中心或长度，多一个量级。Manacher 是线性的中心扩展。  
- **样例长度为 1。** 任何算法都返回 1。用 `abba` 和 `abcba` 各算一次。  
- **和后缀数组的 height 对拍最长重复子串。** 那是重复，不是回文。`aaa` 两者都大，`abcba` 才能分开。  
- **把 `#` 也输出进答案串。**

## 小结

插入 `#` 统一奇偶。最右回文给新中心一个镜像下界，再向外试。原串长度是 `d[i]-1`。单个模式用 KMP，全部后缀用后缀数组，回文用本篇。

建议练习：

- 洛谷 [P3805 【模板】manacher](https://www.luogu.com.cn/problem/P3805)
- 手算 `abba` 的 `t` 和每个 `d[i]`  
- 对拍中心扩展 O(n²)，n≤300
