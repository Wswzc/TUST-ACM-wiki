# 回文自动机：每插入一个字符，认一个新回文

> 读完你应该能：分清偶根和奇根；插入字符时用 fail 找到「还能当回文后缀」的状态；说出每个状态是一个本质不同的回文子串；用它统计出现次数，而不是只求最长——最长用 [Manacher](Manacher.md) 更短。
>
> 一句口号：**两个根：长度 0 和长度 -1。新回文 = 某个更短回文两边再贴同一个字符。**

## 背景 / 为什么要读这篇

[Manacher](Manacher.md) 给每个中心一个半径，最长回文子串足够。若要「有多少个本质不同的回文」「每个回文出现几次」「所有回文的长度和」，半径数组还得再加工。回文自动机（PAM，也叫回文树）每来一个字符，最多长出一个新状态，状态和本质不同的回文一一对应。

实验室有人只建一个根，偶数长度全部挂死；有人 `fail` 沿失配时忘了比较 `s[pos-len-1]`。本篇用奇偶两个根。

## 正文

### 1. 两个根

| 结点 | 含义 | `len` |
| --- | --- | --- |
| 0 | 偶根，空串 | 0 |
| 1 | 奇根 | -1 |

`fail[0]=1`，`fail[1]=0`。真正的回文从结点 2 开始。串的下标从 1 开始，`s[0]` 放一个不会出现的哨兵，避免回跳越界。

一个状态的 `len` 是它代表的回文长度。`fail` 指向它最长的回文真后缀（也是回文）。

### 2. 插入

已有前缀 `s[1..pos-1]`，现在在 `pos` 放下字符 `c`。

从 `last` 沿 fail 跳，直到某个状态 x 满足「x 代表的回文前面那一格也是 c」：`s[pos-len[x]-1]==s[pos]`。然后看 x 是否已有字符 c 的儿子。没有就新建：长度为 `len[x]+2`，新点的 fail 用同样的规则从 `fail[x]` 再找。

```cpp
const int N = 500005;
int ch[N][26], fail[N], len[N], cnt[N], tot, last;
char s[N];

int getfail(int x, int pos) {
    while (s[pos - len[x] - 1] != s[pos]) x = fail[x];
    return x;
}

void init() {
    tot = 1;
    fail[0] = 1;
    fail[1] = 0;
    len[1] = -1;
    s[0] = '#';
    last = 0;
}

void insert(int pos) {
    int c = s[pos] - 'a';
    int p = getfail(last, pos);
    if (!ch[p][c]) {
        int q = ++tot;
        len[q] = len[p] + 2;
        fail[q] = ch[getfail(fail[p], pos)][c];
        ch[p][c] = q;
    }
    last = ch[p][c];
    cnt[last]++;
}
```

全部插完后，按 `len` 从大到小把 `cnt` 加到 `fail` 上（和 SAM 一样）。`cnt[u]` 就是这个回文的出现次数。本质不同回文个数是 `tot-1`。

最长回文长度是所有 `len[u]` 的最大值。只要求这个数时，Manacher 更不容易写错。

### 3. 和 Manacher、SAM

| 工具 | 擅长 |
| --- | --- |
| Manacher | 每个中心的半径、最长 |
| PAM | 本质不同回文、次数、回文后缀 |
| SAM | 所有子串，不限回文 |

PAM 的结点数 ≤ n+2。空间比「每个中心存半径」更适合再在 fail 树上做 DP。

## 常见坑 / 注意事项

- **奇根 `len` 写成 0。** 单字符回文是 `(-1)+2=1`，偶根长不出奇数。  
- **`s[0]` 和真实字符相同。** 哨兵用 `'#'` 且题目只有小写字母。  
- **`getfail` 死循环。** `fail[0]`、`fail[1]` 必须互指，且 `len[1]=-1` 让 `pos-len-1=pos`，和自己比，从而停住。  
- **次数不沿 fail 推。** 长回文出现时，它的回文后缀也出现。  
- **`tot` 从 0 开始把根覆盖了。** `tot` 初始 1，新点从 2 起。  
- **多测不清 `ch`。** 结点只有 O(n)，按 `tot` 清。

## 趣味课间：实验室经典翻车集

- **「回文自动机就是 Manacher 的指针版。」** Manacher 没有 fail 树，也没有「本质不同」的结点。  
- **样例 `a`。** 只有一个奇回文。用 `aa` 看偶根能不能长出长度 2。  
- **`cnt` 直接当答案，没推后缀。** `aaa` 里长度为 1 的 `a` 出现 3 次，不是 1 次。  
- **和 SAM 的 `extend` 克隆抄进来。** PAM 没有克隆这一支。

## 小结

偶根长 0，奇根长 -1。新回文是旧回文两边贴同一字符。fail 是最长回文真后缀。次数从长推到短。只求最长就回 Manacher。
