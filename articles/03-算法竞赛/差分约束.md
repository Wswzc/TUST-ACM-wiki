# 差分约束：不等式变成最短路

> 读完你应该能：把 `x_i - x_j ≤ c` 建成有向边；用最短路（常 SPFA）求一组解；用负环判断无解；知道「求最大 / 最小」对应超级源连边的方向。
>
> 一句口号：**一条不等式是一条边；一组解就是各点到源点的距离。**

## 背景 / 为什么要读这篇

[高斯消元](高斯消元.md) 解的是等式。[2-SAT](2-SAT.md) 解的是真假。[Dijkstra](Dijkstra.md) / SPFA 解的是最短路。题面若是一堆 **`x_a - x_b ≤ c`**（间隔至少、最多、先后关系），不必单纯形，差分成图即可。

实验室有人边建反了（`i→j` 还是 `j→i`）；有人用 Dijkstra 跑负权；有人无超级源，图不连通当无解。本篇钉建边和负环。

## 正文

### 1. 一条边对应一条不等式

约定：`x_i - x_j ≤ w` 建边 **`j → i`，边权 w**。

理由：最短路三角不等式 `dis[i] ≤ dis[j] + w`，把 `dis` 当成 `x`，就是 `x_i - x_j ≤ w`。

常见翻译：

| 人话 | 不等式 | 边 |
| --- | --- | --- |
| i 比 j 最多大 c | `x_i - x_j ≤ c` | `j → i` 权 c |
| i 比 j 至少大 c | `x_j - x_i ≤ -c` | `i → j` 权 -c |
| i 与 j 差的绝对值 ≤ c | 两条：`≤c` 与 `≥ -c` | 两条边 |
| `x_i = x_j` | 两条 `≤0` | 双向权 0 |

下标从 1。常数项、前缀和变量（`s[r]-s[l-1]≤k`）同样化成两点差。

### 2. 超级源、求一组解

原图可能不连通。加 **超级源 S**，向每个变量连边权 0（或 1，看你要不要强制有限），再从 S 跑最短路。`x_i = dis[i]` 即一组可行解（相对 S）。

有负权，入门用 SPFA；正权才能 Dijkstra。差分约束几乎总有负边，**不要**抄 P4779 当板子。

负环：`x_i - x_i ≤ 负数`，自相矛盾，**无解**。SPFA 某点入队超过 n 次（或入队边数超限）判负环。

```cpp
vector<pair<int, int>> g[N];  // {to, w}
void add(int u, int v, int w) { g[u].push_back({v, w}); }

bool spfa(int n, int s, vector<long long>& dis) {
    vector<int> cnt(n + 1, 0), inq(n + 1, 0);
    queue<int> q;
    dis.assign(n + 1, 4e18);
    dis[s] = 0;
    q.push(s);
    inq[s] = 1;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        inq[u] = 0;
        for (auto [v, w] : g[u]) {
            if (dis[v] > dis[u] + w) {
                dis[v] = dis[u] + w;
                if (++cnt[v] > n) return false;  // 负环
                if (!inq[v]) {
                    q.push(v);
                    inq[v] = 1;
                }
            }
        }
    }
    return true;
}
```

`n` 含超级源时入队上限用点数。`cnt[v]>n` 是充分条件之一，竞赛够用。

### 3. 最大解还是最小解

只要可行解：上面即可。

要 **`x_i` 尽量大**（在差约束下）：求的是最短路那套 `dis`（上界紧）。要尽量小：改成最长路（边权取反或建图对偶）。入门题多数只要任意可行或判无解。先会判负环，再纠结最大最小。

有解时解不唯一：沿最短路松弛到紧的那些差被钉死，其它点可平移。题要输出任意一组，交 `dis` 即可。

### 4. 和别的约束系统

| 形态 | 做法 |
| --- | --- |
| `x_i - x_j ≤ c` | 差分约束 |
| `a_i x = b` 线性等式 | 高斯消元 |
| 每变量真/假 | 2-SAT |
| 容量 + 费用 | 费用流 |

看见「最多差几、至少隔几天」，先写成两点差，再画边。

## 常见坑 / 注意事项

- **边方向反了。** 用三角不等式默写一遍。  
- **负权上 Dijkstra。**  
- **无超级源，只从 1 跑，漏连通块。**  
- **负环当「有解、距离无限」。** 差分约束里负环 = 矛盾。  
- **SPFA 被卡。** 模板题通常可过；被卡换队列优化或差分约束专用建图检查。  
- **`int` 边权和距离。** 多条不等式叠起来。

## 趣味课间：实验室经典翻车集

- **「这不就是最短路模板吗。」** 模板是引擎，题在建边。边写反，SPFA 再快也是错的。  
- **样例无负边。** 测不出 Dijkstra 误用。造 `x1-x2≤-3`。  
- **两个不等式形成环权和为负，输出了一组数。** 先查负环。  
- **对拍随机构不等式，两边都无解。** 先造「链上全 ≤1」必有解。见 [对拍](../00-团队指南/对拍.md)。

## 小结

`x_i - x_j ≤ w` 建 `j→i` 权 w。超级源连所有点。SPFA 求 `dis`；负环无解。先会建边，再谈最大最小。

建议练习：

- 洛谷 [P5960 【模板】差分约束](https://www.luogu.com.cn/problem/P5960)
- 手画 `x1-x2≤2, x2-x3≤3, x1-x3≤4` 是否有负环（第三条多余但合法）  
- 把「至少大 1」翻成边权 -1
