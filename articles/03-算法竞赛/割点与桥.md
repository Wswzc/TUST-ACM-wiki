# 割点与桥：无向图上拆掉就断的点与边

> 读完你应该能：用 `dfn/low` 在无向图上找割点、找桥；说出根和非根的割点条件不一样；把这套和 [强连通分量](强连通分量.md) 的有向 Tarjan 分开记；重边时不用「不是父亲」这一句糊弄。
>
> 一句口号：**无向图的 low 看的是「能爬回多高」；爬不回去，这条树边就是桥，这个点就可能是割点。**

## 背景 / 为什么要读这篇

[并查集](并查集.md) 知道无向图通不通。[强连通分量](强连通分量.md) 的 Tarjan 是**有向图**、有栈、按 `dfn==low` 弹分量。无向图上的另一问：删一个点（或一条边）会不会使连通块变多。那是割点、桥。

实验室有人把 SCC 的 `ins[]` 抄过来；有人根节点也用 `low[v]>=dfn[u]`，根被误判或漏判；有人重边 `v!=fa` 把桥判没了。本篇只做无向、无向图的 dfn/low。

## 正文

### 1. 定义

无向连通图。

- **桥：** 删掉这条边，图不再连通。  
- **割点：** 删掉这个点和它连着的边，图不再连通。

不连通就对每个连通块各跑一遍，答案取并。

### 2. 树边和返祖边

DFS 生成树。`dfn[u]` 是访问时间。`low[u]` 是 u 以及 u 的子树，通过**一条返祖边**能触及的最小 dfn（含自己）。

无重边时：

```cpp
int dfn[N], low[N], ts;
bool cut[N];
vector<pair<int,int>> bridges;

void dfs(int u, int fa) {
    dfn[u] = low[u] = ++ts;
    int child = 0;
    for (int v : g[u]) {
        if (!dfn[v]) {
            child++;
            dfs(v, u);
            low[u] = min(low[u], low[v]);
            if (low[v] > dfn[u]) bridges.push_back({u, v});
            if (fa && low[v] >= dfn[u]) cut[u] = true;
        } else if (v != fa) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (!fa && child >= 2) cut[u] = true;
}
```

| 条件 | 含义 |
| --- | --- |
| `low[v] > dfn[u]` | v 的子树没有任何边能爬到 u 或 u 的祖先，树边 u–v 是桥 |
| `low[v] >= dfn[u]` 且 u 不是根 | 子树爬不到 u 的祖先，u 是割点 |
| 根的 DFS 子树个数 ≥ 2 | 根是割点 |

`>` 和 `>=` 差在：子树能回到 u 自己，桥不成立（还有别的路到 u），但删掉 u 仍然会把子树拆走，所以割点用 `>=`。

从每个 `!dfn[i]` 启动，`fa=0`。点编号不要用 0，否则根判断失败。

### 3. 重边

两条 u–v。`v!=fa` 会把第二条当成返祖边，`low` 被拉低，桥消失。给每条无向边一个编号，正反同一 id，返祖时忽略的是**同一条边**，不是同一个点：

```cpp
// 邻接表存 {v, id}
// if (id == from_edge) continue;
```

模板题若保证无重边，第一种写法够用。题面没说，就用边编号。

### 4. 和 SCC、边双

有向 SCC：栈、`ins`、弹出分量。无向割点：没有栈，看子树个数和 `low` 与 `dfn` 的大小。

边双：不走桥再 DFS 即可。点双要把割点算进每一块，用边栈，见 [点双连通](点双连通.md)。有向图不要调用本篇。

## 常见坑 / 注意事项

- **根用 `low[v]>=dfn[u]`。** 根的父亲不存在，条件会把根判错。根只看子树个数。  
- **点号从 0 开始，`fa=0` 和点 0 冲突。**  
- **`low` 用 `dfn[v]` 更新树边儿子。** 树边应等递归回来用 `low[v]`。返祖边才用 `dfn[v]`。  
- **重边。**  
- **桥的输出方向。** 题面要 u<v 就排序。  
- **多测 `dfn`、`ts`、`cut` 没清。**

## 趣味课间：实验室经典翻车集

- **「无向图 SCC 就是割点。」** 无向图整块强连通（边当双向）几乎是一块，割点信息全丢。  
- **样例一条链。** 中间点都是割点，端点不是，桥是每条边。再造一个环：环上没有桥、没有割点。  
- **`>=` 抄成 `>`，环上一个点挂一条链。** 链的上端应是割点，`>` 会漏。  
- **输出割点个数，点被标记两次仍当两个。** `cut[u]=true` 只计一次。

## 小结

无向 DFS：`low[v]>dfn[u]` 是桥，非根 `low[v]>=dfn[u]` 是割点，根看子树个数 ≥2。重边用边编号。不要和有向 SCC 的栈混用。
