# 中国剩余定理：几条同余方程合成一条

> 读完你应该能：在模数两两互质时用 CRT 合并方程组；模数不互质时用扩欧合并两条（exCRT）；知道解在模 lcm 意义下唯一（有解时）。
>
> 一句口号：**每条方程是一条「余数线索」。互质时用乘数把别的模「关掉」，只留下当前余数；不互质时两条合成一条更长的模。**

## 背景 / 为什么要读这篇

韩信点兵、孙子算经：三数余 2、五数余 3、七数余 2。这就是 CRT。赛题里「分别模 m_i 余 a_i，求 n」或把大模数拆成质数幂再合并（有时用来加速）。

[扩展欧几里得](扩展欧几里得.md) 已会解一条 `ax≡c (mod m)`。CRT 是多条联立。实验室有人模数不互质仍套互质公式，有解变无解或答案错一截。本篇先互质模板，再给 exCRT 的两两合并。

## 正文

### 1. 互质情形（教科书 CRT）

```text
x ≡ a1 (mod m1)
x ≡ a2 (mod m2)
...
x ≡ ak (mod mk)
```

`m_i` 两两互质。令 `M = m1*m2*...*mk`，`Mi = M/mi`。因 gcd(Mi, mi)=1，存在 `Mi` 模 mi 的逆 `ti`：

```text
x = Σ ai * Mi * ti   (mod M)
```

`Mi*ti ≡ 0 (mod mj)`（j≠i），`≡1 (mod mi)`，于是 x 模 mi 只剩 ai。

```cpp
long long CRT(const vector<long long>& a, const vector<long long>& m) {
    int k = (int)a.size();
    __int128 M = 1, x = 0;
    for (int i = 0; i < k; i++) M *= m[i];
    for (int i = 0; i < k; i++) {
        __int128 Mi = M / m[i];
        long long ti, tmp;
        exgcd(Mi % m[i], m[i], ti, tmp);  // Mi * ti ≡ 1 (mod m[i])
        ti = (ti % m[i] + m[i]) % m[i];
        x = (x + (__int128)a[i] * Mi % M * ti) % M;
    }
    x = (x % M + M) % M;
    return (long long)x;
}
```

`exgcd` 见上一篇。乘积用 `__int128`。M 超过 long long 时要按题面用 exCRT 逐步合并，不要先乘爆。

孙子例：m=3,5,7，a=2,3,2。M=105。答案 23。值得手算一遍 Mi 和 ti。

### 2. 模数不互质：两条合成一条

```text
x ≡ a1 (mod m1)
x ≡ a2 (mod m2)
```

即 `x = a1 + m1 * t`，代入第二条：

```text
m1 * t ≡ a2 - a1 (mod m2)
```

`exgcd` 解 t。无解 ⇔ `gcd(m1,m2)` 不整除 `(a2-a1)`。

有解后新模数是 `lcm(m1,m2)`，新余数是某个特解模 lcm。循环把 k 条两两并成一条。

```cpp
bool merge(long long a1, long long m1, long long a2, long long m2,
           long long& a, long long& m) {
    long long x, y;
    long long g = exgcd(m1, m2, x, y);
    long long diff = a2 - a1;
    if (diff % g) return false;
    m1 /= g;  // 下面用 m1/g
    long long t = (__int128)x * (diff / g) % m2;  // 小心溢出与符号
    t = (t % (m2 / g) + (m2 / g)) % (m2 / g);
    m = m1 * m2;  // 已经 /g 一次后 * m2 = lcm？等一下：lcm=m1*m2/g，此处 m1 已是原m1/g
    a = a1 + t * (m1 * g);  // 原 m1 * t
    a = (a % m + m) % m;
    return true;
}
```

实现时建议老老实实：

```text
g = gcd(m1,m2)
t0 满足 m1*t0 ≡ (a2-a1) (mod m2)
步长 m2/g
x0 = a1 + m1*t0
新 m = m1/g*m2
```

符号：`diff` 为负先加 m2。模板题 [P4777](https://www.luogu.com.cn/problem/P4777) 是 exCRT，模数不保证互质。

### 3. 什么时候用拆模

模数 1e9+7 是质数，一条方程就够，不必 CRT。CRT 常见于：

- 模数是 15=3*5 等，分别模 3 和 5 再合并  
- 题面直接给若干条同余  
- 计算 `n!` 一类在模数合数下拆质数幂（高阶，知道即可）

不要看见「余数」就 CRT：单条用扩欧。

### 4. 复杂度

k 个模数，互质 CRT 是 k 次扩欧。exCRT 两两合并 k-1 次。模数 1e18 时乘法全上 int128。

## 常见坑 / 注意事项

- **不互质套 Σ ai Mi ti。** Mi 与 mi 不互质，逆元不存在。
- **答案负数没加 M。**
- **M 溢出 long long。**
- **exCRT 的 t 没模到 `m2/g`。**
- **`a2-a1` 负数直接 `%`。** C++ 负余数。
- **只有一条方程还写 CRT。**
- **把 lcm 写成 m1*m2。** 不互质时要 /gcd。

## 趣味课间：实验室经典翻车集

- **「我背了 23。」** 孙子题答案是 23，下一组 a 一变就不会做。要会 Mi、ti。
- **Python `crt` 库。** 现场没有。两两合并二十行。
- **样例模数互质。** 抄 P1495 的代码交 P4777。
- **合并顺序从后往前与从前往前答案不同。** 模 lcm 后应相同；不同说明某次溢出或无解没判。

## 小结

两两互质：`x = Σ a_i M_i t_i (mod M)`。不互质：扩欧并两条，新模 lcm，先判 g|(a2-a1)。溢出用 int128，负数补模。
