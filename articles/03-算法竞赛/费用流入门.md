# 费用流入门：水流要收费

> 读完你应该能：在最大流网络的边上再挂一个「单位流量的费用」；用 SPFA 在残量网络上找最小费用增广路，求出最小费用最大流；解释反向边费用为什么是相反数；知道负圈和 Dijkstra 势能是进阶。
>
> 一句口号：**每次增广仍送尽量多的水，但走的是当前残量里「每单位最便宜」的路。**

## 背景 / 为什么要读这篇

[最大流入门](最大流入门.md) 只问吞吐量。题再加一句：「每条管道运送 1 单位要收过路费，流量最大的前提下费用最小」（或费用固定下流量最大，看题）。

匹配带权（任务与人有不同收益）可以建费用流，不必一上来 KM。实验室有人把费用加在容量上胡乱 `min`；有人反向边费用忘了取负，越增广越亏。本篇用 SPFA-MCMF 打穿，模板题 P3381。

## 正文

### 1. 边的两个数字

每条边：容量 `cap`，单位费用 `cost`。流 f 经过它，花费 `f * cost`。

残量：正向还剩 `cap-f`，费用仍是 `cost`；反向残量 f，费用 **`-cost`**。悔流把已经付的钱退回账上，所以费用相反。和最大流反向边是同一会计，多了一列符号。

```cpp
struct Edge { int to, rev; long long cap, cost; };
void add_edge(int u, int v, long long cap, long long cost) {
    g[u].push_back({v, (int)g[v].size(), cap, cost});
    g[v].push_back({u, (int)g[u].size() - 1, 0, -cost});
}
```

### 2. 算法：最小费用增广

只要还能从 s 到 t，就在残量网络上找一条 **单位费用之和最小** 的路（边权是 cost，与 cap 无关，但只能走 cap>0 的边），再按瓶颈容量增广。累加 `流量 × 路径费用`。

找最短路：cost 可能为负（反向边），入门用 SPFA。正权可用 Dijkstra。

```cpp
const long long INF = 4e18;
vector<long long> dis;
vector<int> par, pe, inq;

bool spfa(int s, int t) {
    int n = (int)g.size() - 1;
    dis.assign(n + 1, INF);
    par.assign(n + 1, -1);
    inq.assign(n + 1, 0);
    queue<int> q;
    dis[s] = 0;
    q.push(s);
    inq[s] = 1;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        inq[u] = 0;
        for (int i = 0; i < (int)g[u].size(); i++) {
            auto& e = g[u][i];
            if (e.cap > 0 && dis[e.to] > dis[u] + e.cost) {
                dis[e.to] = dis[u] + e.cost;
                par[e.to] = u;
                pe[e.to] = i;
                if (!inq[e.to]) {
                    q.push(e.to);
                    inq[e.to] = 1;
                }
            }
        }
    }
    return dis[t] < INF / 2;
}

pair<long long, long long> mcmf(int s, int t) {
    long long flow = 0, cost = 0;
    pe.assign(g.size(), 0);
    while (spfa(s, t)) {
        long long f = INF;
        for (int v = t; v != s; v = par[v])
            f = min(f, g[par[v]][pe[v]].cap);
        for (int v = t; v != s; v = par[v]) {
            Edge& e = g[par[v]][pe[v]];
            e.cap -= f;
            g[v][e.rev].cap += f;
        }
        flow += f;
        cost += f * dis[t];
    }
    return {flow, cost};
}
```

`dis[t]` 是这条增广路的单位费用和，乘瓶颈 f 就是本轮花费。

需要「费用最小、流量不必最大」时：持续增广直到下一条路费用 >0 或不可达，视题意。有的题费用可负，要一直增广到最大流。

### 3. 建模印象

| 题 | 思路 |
| --- | --- |
| 带权二分图最大权匹配 | 源-左-右-汇，匹配边费用 -收益（或求最大费用） |
| 运输：工厂到商店 | 供需当容量，运费当 cost |
| 每单位额外限制 | 拆边：一条便宜有限、一条贵无限 |

最大费用：所有 cost 取负，再求最小费用，答案再取负。

### 4. 复杂度与 SPFA 被卡

SPFA 最坏很差。竞赛费用流模板题通常可过。被卡换 Dijkstra + 势能（Johnson）。n 很小（≤200）先 SPFA。负圈：费用流若建图无负圈（或残量里不该有能无限刷的负圈），有负圈说明建图错了或题是消圈，入门当 bug 查。

## 常见坑 / 注意事项

- **反向边 cost 忘记取负。**  
- **`dis[t] * f` 用 int。**  
- **SPFA 用了 `vis` 只进队一次。** 负权必须能多次松弛，用 `inq`。  
- **容量 0 的边仍松弛。** `e.cap > 0`。  
- **最大流建图抄来忘加 cost。**  
- **费用为正却提前停。** 最大流约束下正费用路也要走满（除非题只要负费用）。

## 趣味课间：实验室经典翻车集

- **「费用就是容量。」** 两个独立字段。  
- **匈牙利能过的带权题上费用流。** n 小 KM 或费用流都行；n=1e3 左部费用流可能 TLE。  
- **样例费用 0。** 所有 cost=0 时退化成最大流，测不出反向费用。造一条贵直路和一条便宜绕路。  
- **SPFA 在最短路题被卡，费用流题照抄。** 模板题数据一般友好；CF 另说。

## 小结

边 = 容量 + 单位费用。反向费用取负。每次在残量上走最便宜的增广路（SPFA），累加 `f * dis[t]`。先会最大流再建费用。
