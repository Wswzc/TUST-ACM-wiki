# 线段树合并：两棵动态开点的树合成一棵

> 读完你应该能：动态开点地在值域线段树上单点加；把两棵树对应结点相加，空儿子直接接过来；用它在树上把儿子的信息并进父亲；说明总复杂度和 [启发式合并](启发式合并.md) 一样是 O(n log V)，因为空结点不用遍历。
>
> 一句口号：**有儿子就递归加，没有儿子就把对方的指针拿过来。不要复制整棵树。**

## 背景 / 为什么要读这篇

[线段树入门](线段树入门.md) 是一棵固定的树。[主席树](主席树.md) 是改一条链、历史版本都留着。还有一类：每个点有自己的一棵值域线段树（子树里某种颜色的个数），父亲要把儿子们并起来。若每次把小 `map` 插进大 `map`，就是启发式合并。线段树合并做的是同一件事，只是容器换成动态开点线段树，查询第 k 小、全局加一棵树，都比 `map` 好写。

实验室有人合并时新建全部结点，空间变成 O(n²)；有人 `sum` 忘了用左右儿子重算，父亲的个数是旧的。本篇值域先 [离散化](离散化.md) 到 1..m。

## 正文

### 1. 动态开点单点加

不必 `build`。`0` 表示空结点。

```cpp
const int N = 5000005;
int ls[N], rs[N], sum[N], tot;

int add(int p, int l, int r, int x, int v) {
    if (!p) p = ++tot;
    if (l == r) {
        sum[p] += v;
        return p;
    }
    int mid = (l + r) >> 1;
    if (x <= mid) ls[p] = add(ls[p], l, mid, x, v);
    else rs[p] = add(rs[p], mid + 1, r, x, v);
    sum[p] = sum[ls[p]] + sum[rs[p]];
    return p;
}
```

`sum[0]=0`。所以空儿子加出来是 0。

### 2. 合并

```cpp
int merge(int a, int b, int l, int r) {
    if (!a || !b) return a | b;
    if (l == r) {
        sum[a] += sum[b];
        return a;
    }
    int mid = (l + r) >> 1;
    ls[a] = merge(ls[a], ls[b], l, mid);
    rs[a] = merge(rs[a], rs[b], mid + 1, r);
    sum[a] = sum[ls[a]] + sum[rs[a]];
    return a;
}
```

`b` 在合并后不要再当独立的树使用：它的结点有的被挂到 `a` 下面，有的被丢掉（叶子上的值已经加进 `a`）。这是**破坏性合并**。主席树那种「两版都要留」不能调用这个 `merge`。

两边都有的结点才会递归。只有一边有，直接 `return a|b`，整棵子树指针被接过来，O(1)。每个插入的叶子最多被合并 O(log n) 次量级（每次合并所在的树至少变大），总时间 O(n log V)。

### 3. 挂在树上

dfs 儿子，`root[u] = merge(root[u], root[v], 1, m)`，再把 u 自己的颜色 `add` 进去。然后 `root[u]` 就是子树的值域树。询问子树第 k 小：在这棵树上按左儿子的 `sum` 往下走，和主席树的 `kth` 相同，只是只有一棵树，不用版本差。

和 [启发式合并](启发式合并.md) 的 DSU on tree 比：DSU on tree 用数组 `cnt`，省空间；线段树合并能同时保留每个子树的可查询结构，也方便「子树里 ≥ x 的数有几个」。颜色值域很大又只查出现次数，`map` 启发式往往更短。

## 常见坑 / 注意事项

- **`merge` 之后还用 `b` 查询。** 结构已经散了。  
- **叶子合并只 `return a`，没把 `sum[b]` 加进去。**  
- **`sum[a]=sum[ls]+sum[rs]` 写在空结点短路之前。** 短路时不必算。  
- **空间只开 4n。** 动态开点是 O(n log V)，按这个开。  
- **值域用原值 1e9 当 `r`。** 先离散化，或用动态开点但 `mid` 用 `long long` 且空间仍按 log 乘 n。  
- **多测 `tot` 不清，结点池耗尽。**

## 趣味课间：实验室经典翻车集

- **「合并就是把两棵主席树版本减一减。」** 版本差是不修改历史。合并是把两棵树揉成一棵。  
- **样例子树只有一个点。** `merge` 走 `!a||!b` 就返回。造一个点两个儿子、颜色不同，看父亲的 `sum` 是不是 2。  
- **和扫描线的覆盖标记混在一个 `merge` 里。** 这里的 `sum` 是个数，不是覆盖长度。  
- **递归合并爆栈。** 链状值域、深度 log，一般没事；自己写的 `mid` 算成永远偏向一边才会爆。

## 小结

空结点编号 0。合并时缺一边就接指针，两边都在就递归并把叶子的值相加。合并是破坏性的。子树信息要按值域查询时，把它挂在 dfs 上。

建议练习：

- 洛谷 [P4556 [Vani有约会] 雨天的尾巴](https://www.luogu.com.cn/problem/P4556)（树上差分 + 线段树合并，先会合并再看差分）  
- 两棵只有一个叶子的树，手算 `merge` 后根的 `sum`  
- 和 DSU on tree 选同一道「子树颜色数」，比哪份更好写
