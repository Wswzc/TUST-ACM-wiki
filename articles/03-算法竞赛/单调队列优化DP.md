# 单调队列优化 DP：窗口里的最优转移

> 读完你应该能：认出 `dp[i] = a[i] + min/max(dp[j])`（j 在 `[i-k, i-1]`）这种转移；用 [单调队列](单调栈与单调队列.md) 把内层从 O(k) 降到均摊 O(1)；弹出过期下标、弹出更差的队尾。
>
> 一句口号：**转移像滑动窗口最值，只是窗口里装的是 dp 值。**

## 背景 / 为什么要读这篇

[01 背包](01背包.md) 的一维是 O(nM)。有一类 DP：走到 i，只能从前面长度不超过 k 的一段里选最优。暴力枚举 j 是 O(nk)，n=1e5、k=1e5 不行。

[单调队列](单调栈与单调队列.md) 已经会窗口最小值。把「窗口」换成合法转移区间，队头就是当前最优 `dp[j]`。实验室有人队里存值不存下标，过期弹不掉；有人先插入 i 再转移，用了 `dp[i]` 自己；有人队列单调方向反了，min 写成 max。本篇钉一种最常见的形状。

## 正文

### 1. 标准形状

```text
dp[0] = 0 或 dp[1] = 初值
dp[i] = A[i] +  min_{i-R ≤ j ≤ i-L} dp[j]
```

L、R 是「至少跳 L、最多跳 R」或「窗口长度 k」（此时 L=1, R=k）。下标按题 0-based / 1-based。

若没有 `A[i]`、只是 `min(dp[j])+1`，同样办。关键是：**对固定 i，候选 j 是一段连续下标，且随着 i 增加这段窗口整体右移。**

不是这种：j 的范围依赖 `a[i]` 无规律、或决策斜率交叉——那是斜率优化 / 决策单调，不是单调队列。

### 2. 队列里放下标

维护下标 `q`，使得对应 `dp` **单调递增**（求 min 时）。队头永远是窗口内最小 `dp`。

对每个 i：

1. 队头 `j < i-R`（或 `j < i-k`）则弹出——过期。  
2. 用队头转移：`dp[i] = A[i] + dp[q.front()]`（队列空则非法，按题）。  
3. 插入 i 之前，弹掉队尾 `dp[q.back()] >= dp[i]` 的——它们不可能比 i 更优还更老。  
4. `i` 入队。

求 max 则队列 `dp` 递减，弹尾条件改成 `<=`。

```cpp
int n, k;
long long A[N], dp[N];
int q[N], hh, tt;  // [hh, tt)

void solve() {
    hh = tt = 0;
    dp[0] = 0;
    q[tt++] = 0;
    for (int i = 1; i <= n; i++) {
        while (hh < tt && q[hh] < i - k) hh++;  // 窗口 (i-k, i-1]
        dp[i] = A[i] + dp[q[hh]];
        while (hh < tt && dp[q[tt - 1]] >= dp[i]) tt--;
        q[tt++] = i;
    }
}
```

窗口开闭要和公式一致。若 j 只能到 `i-1`、不能用 `dp[i]`，插入必须放在转移**之后**（上面就是）。若 `dp[i]` 不入队、入队的是 `i-1`，也要写清。

### 3. 和滑动窗口模板的差别

P1886 窗口最值：数组 `a[i]` 已知，队列比的是 `a`。  
本篇：比的是 **`dp`，而 `dp[i]` 刚算出来**。顺序错就会用到未定义或自己。

多项代价 `dp[j] + (i-j)*x` 若展开后仍能写成「只依赖 j 的值 + 只依赖 i 的值」，有时也能单调队列；多一个 `j` 与 `i` 交叉项，通常要斜率。入门只吃「纯 min(dp[j]) + f(i)」。

### 4. 复杂度

每个下标进队出队至多一次，O(n)。比线段树维护窗口少一个 log，码也短。能 BIT/线段树也能做，单调队列更贴这个模型。

## 常见坑 / 注意事项

- **先入队再转移。** 用了 `dp[i]` 当自己的 min。  
- **队列存 `dp` 值不存下标。** 过期无法判断。  
- **求 min 却维护递减。**  
- **`hh==tt` 还取队头。** 窗口空，按题是不合法或从边界起跳。  
- **`k=0` 或 `i-k` 下溢。**  
- **多组数据 `hh,tt` 没重置。**

## 趣味课间：实验室经典翻车集

- **「不就是单调队列模板换个数组名。」** 差在 `dp` 边算边进队。抄 P1886 不改顺序会 WA。  
- **样例 k=n。** 窗口永远覆盖全部，任何实现都像前缀 min。造 k=2。  
- **对拍暴力枚举 j，自己 `>=` 弹尾弹光。** 相等时留下更右边（更新）还是左边，要看是否影响——求 min 时相等可弹，下标更新。  
- **把斜率优化题硬套单调队列。** 交叉项在，队头不是最优。

## 小结

合法 j 是滑动窗口，队头就是最优历史 dp。先弹过期，再转移，再弹尾、入队。先会窗口最值，再换 dp。
