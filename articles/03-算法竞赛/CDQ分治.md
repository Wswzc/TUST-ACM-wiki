# CDQ 分治：左边对右边的贡献，归并时算

> 读完你应该能：把三维偏序拆成「先按第一维排序，再分治第二维，树状数组做第三维」；在归并时只让左半边对右半边产生贡献；说清它和 [树状数组](树状数组.md) 逆序对是同一只手，只是多了一维分治。
>
> 一句口号：**递归把一维排掉。跨过中点的那一刀，才是这一层要算的贡献。**

## 背景 / 为什么要读这篇

逆序对是二维：下标有序，值用树状数组。三维偏序：数点 `(a,b,c)` 有多少个点在它左下方（每一维都 ≤）。直接排序只能消掉一维。CDQ 分治再消一维，剩下的一维交给树状数组。

离线的「按时间修改 + 询问」也常被看成一维时间。和 [主席树](主席树.md) 比：主席树在线、多一个 log 的空间；CDQ 离线、常数和写法不同。实验室有人左右两边都插进树状数组；有人归并破坏了「左边的 a 都不大」却继续查询。本篇按三维偏序写。

## 正文

### 1. 三维偏序在分治什么

点已按 `a` 升序排好，相同 `a` 时再按 `b`、`c`。数组下标区间 `[l,r]` 分成左右。左半每一个点的 `a` 都不大于右半每一个点的 `a`（排序稳定地切）。于是「a 这一维」在跨中点时自动满足。

还要 `b_left ≤ b_right` 且 `c_left ≤ c_right`。把左右按 `b` 归并：右点查询时，树状数组里只放已经扫过的、`b` 更小或相等的左点，查询 `c` 的前缀和。

区间内部的点对由递归负责。这一层只加**跨中点**的贡献。

### 2. 归并

```cpp
struct Node {
    int a, b, c, ans;
};
vector<Node> p, tmp;

void cdq(int l, int r) {
    if (l >= r) return;
    int mid = (l + r) >> 1;
    cdq(l, mid);
    cdq(mid + 1, r);
    int i = l, j = mid + 1, k = 0;
    while (i <= mid && j <= r) {
        if (p[i].b <= p[j].b) {
            bit_add(p[i].c, 1);
            tmp[k++] = p[i++];
        } else {
            p[j].ans += bit_sum(p[j].c);
            tmp[k++] = p[j++];
        }
    }
    while (j <= r) {
        p[j].ans += bit_sum(p[j].c);
        tmp[k++] = p[j++];
    }
    for (int t = l; t < i; t++) bit_add(p[t].c, -1);
    while (i <= mid) tmp[k++] = p[i++];
    for (int t = 0; t < k; t++) p[l + t] = tmp[t];
}
```

`b` 相等时先放左边，这样 `≤` 成立。树状数组在第三维上，值域要 [离散化](离散化.md)。清空用成对的 `-1`，不要 `memset` 整棵树。

递归返回后，左右两段各自已经按 `b` 排好，但**元素集合**仍是原来的左右半。所以「左边的 a 整体更小」还在，只是顺序变成了 `b`。

### 3. 自己不算自己

`ans` 初始 0。跨边贡献不会把点自己算进去。左半内部、右半内部在子递归里加上。若有多点完全相同，它们的 `ans` 应相同（每个都看到同样多的「严格在三维意义下不超过它」的其它点，是否含相同点看题）。做法：排序后把相同 `(a,b,c)` 合成一串，查询时先把这一串的左边贡献算完，再一起赋值。模板题 P3810 要处理相同点。先在 a、b、c 互不相同的数据上把分治跑通，再补相同点。

时间 O(n log² n)。n=1e5 是这道题的量级。

### 4. 和归并逆序对

只按值、下标天然有序：归并时右边遇到一个点，左边已经放进「已输出」的那些都是逆序。CDQ 是这件事的高维版。二维不要上 CDQ，树状数组够了。

修改和询问按时间混在一个序列里、操作对后面的询问有贡献：时间当第一维，CDQ 时只让修改走左边、询问走右边。结构相同，桶要分成「改」和「问」两类，不要让询问也 `bit_add`。

## 常见坑 / 注意事项

- **左右都插入树状数组。** 右点会统计到右点。  
- **撤销时下标已经是归并后的。** 在拷回 `p` 之前，用还没被覆盖的 `p[l..i)` 撤销。  
- **`b` 相等却先查询右边。** `≤` 丢了。  
- **第三维没离散化，树状数组开 1e9。**  
- **递归里排序用了全局 `a`，把左右集合搅乱。** 只在当前 `[l,r]` 归并。  
- **相同点没处理就对拍 P3810。**

## 趣味课间：实验室经典翻车集

- **「CDQ 就是归并排序。」** 归并只是顺便把 `b` 排好。贡献在树状数组。  
- **样例按 a 已经有序且 n=3。** 造一个 a 小但 b 大的点，它不该被右边 a 更小的点统计——那种点不应该出现在左边。若统计错了，多半左右插反。  
- **和斜率优化搞混。** 斜率优化是凸壳；CDQ 是偏序。都叫分治时再看贡献是「左对右的点」还是「决策点斜率」。  
- **在线把每个询问立刻回答，却套 CDQ。** CDQ 要离线。在线第 k 小用 [主席树](主席树.md) 或 [整体二分](整体二分.md)。

## 小结

第一维排序，第二维归并，第三维树状数组。只统计左对右。撤销要成对。二维用树状数组就够。相同点单独说。
