# 卡特兰数：合法括号有多少种

> 读完你应该能：写出递推 `C_n = Σ C_i C_{n-1-i}` 和通项 `C(2n,n) - C(2n,n-1)`；用「任何前缀里左括号不少于右括号」解释它为什么对；在质数模下用阶乘或 [Lucas](Lucas定理.md) 算出数值。
>
> 一句口号：**先选一个平衡点把序列劈成两段独立的合法结构，段与段的方案相乘再相加。**

## 背景 / 为什么要读这篇

栈的出栈顺序、合法括号、二叉树形态、圆上互不相交的连线，数出来是同一列数：1, 1, 2, 5, 14, …。这是卡特兰数。竞赛里它经常披着「进出栈」或「括号」出现，n≤30 时用递推，n 大且要取模时用组合数。

实验室有人背了 `C(2n,n)/(n+1)` 但模数不是质数，除法没有逆元；有人递推从 `C_0=0` 开始，后面全是 0。本篇 `C_0=1`。

## 正文

### 1. 两套公式

第 n 个卡特兰数（n 对括号，或 2n 个人的不相交握手）：

```text
C_0 = 1
C_n = Σ_{i=0}^{n-1} C_i * C_{n-1-i}
C_n = C(2n, n) - C(2n, n-1) = C(2n, n) / (n+1)
```

最后一格除法只在整除有意义时使用。模质数 p 且 `n+1` 与 p 互质时，乘 `n+1` 的逆元。p 整除 `n+1` 时不要硬除，改用差式 `C(2n,n) - C(2n,n-1)`，减法在模意义下仍然成立。

```cpp
long long cat[40];
void init_small() {
    cat[0] = 1;
    for (int n = 1; n < 40; n++) {
        cat[n] = 0;
        for (int i = 0; i < n; i++) cat[n] += cat[i] * cat[n - 1 - i];
    }
}
```

n≥35 时 `C_n` 超出 64 位。要么用 `__int128` 看到边界，要么取模。取模且 n 到 1e6、模 1e9+7：预处理阶乘，

```text
C_n ≡ fact[2n] * invfact[n] % p * invfact[n] % p * inv(n+1) % p
```

`inv(n+1)` 用 [数论入门](数论入门.md) 的费马或扩展欧几里得。n 到 1e18 且模小质数，走 [Lucas](Lucas定理.md)，再处理除以 `n+1` 是否合法。

### 2. 括号为什么是这个递推

n 对括号的合法序列：第一个左括号必有一个匹配的右括号，中间夹着一段合法序列（i 对），匹配右括号后面再接一段合法序列（n-1-i 对）。两段独立，所以是乘积；i 从 0 加到 n-1。

等价条件：任意前缀里左括号不少于右括号，总数相等。不满足的用反射原理变成 `C(2n, n-1)`，于是合法数是两者之差。反射原理记不住时，交题用递推或「组合数减组合数」，不要背错反射的那一格。

同一列数还数：n 个结点的二叉树形态、n+1 个叶子的满二叉树、凸 n+2 边形的三角剖分、栈混洗出栈序列。认出来就套公式，认错模型会差 1（叶子数还是内部结点数）。用 n=2 应得到 2、n=3 应得到 5 对一下。

### 3. 和普通组合数

`C(2n,n)` 是不要求前缀合法的括号串（只要求总数相等）。卡特兰是其中合法的那部分。题面若允许任意进出、不要求中途栈非空，那是组合数，不是卡特兰。

## 常见坑 / 注意事项

- **`C_0=0`。** 空结构一种。  
- **模意义下写 `/ (n+1)`。** 要乘逆元，且逆元不存在时改用差式。  
- **递推 `cat[n] += cat[i]*cat[n-i]` 下标错成 n 而不是 n-1-i。**  
- **n 对括号却套了 `C_{n+1}`。** 用 1,2,5 对齐。  
- **`long long` 乘积溢出后再取模。** 递推大 n 必须边乘边模；不取模就换组合数公式并估计位数。  
- **Lucas 直接除 n+1。** 先确认模与 n+1 互质。

## 趣味课间：实验室经典翻车集

- **「出栈序列一共 n! 种。」** 那是栈不限制、或把排列全算进去。合法出栈是卡特兰。  
- **样例 n=1。** 只有 1。n=3 应是 5，口算：`(()())`、`((()))`、`(())()`、`()(())`、`()()()`。  
- **模 1e9+7 用递推到 n=1e5，每次内层 O(n)。** 总 O(n²) 会超时。换阶乘。  
- **多边形三角剖分用 `C_n` 去套 n 条边。** 凸 n 边形是 `C_{n-2}`。先画四边形（2 种）和五边形（5 种）。

## 小结

`C_0=1`，卷积递推，或 `C(2n,n)-C(2n,n-1)`。括号的第一对匹配把序列劈成两段。取模用逆元或差式。模型差一个下标就用 n=2、n=3 校正。
