# 分块：根号大小的那一截暴力

> 读完你应该能：把长度为 n 的数组切成大约 `√n` 的块；整块打标记，零碎的两端暴力改；用它做区间加、区间和；说明 [线段树](线段树入门.md) 能做的很多事分块也能做，只是多一个根号，换来更好写的「不那么整齐」的信息。
>
> 一句口号：**整块 O(1)，散块 O(√n)。询问次数再乘上去，总是 O(n√n)。**

## 背景 / 为什么要读这篇

[前缀和](前缀和与差分.md) 不能改。[树状数组](树状数组.md) 和线段树能改能查，但信息必须能合并。有些题的块内信息很怪（区间众数、块内排序后二分），线段树难写，把数组切成根号块，块内暴力、整块用一个结论，就够 n=1e5。

实验室有人块长取 n，退化成暴力；有人整块标记了但查询忘记加标记；有人最后一块不足 `B` 仍访问到 n 以外。本篇用区间加、区间和把标记和重建说清楚。

## 正文

### 1. 切块

`B = sqrt(n)`，大约 `n/B` 块。下标从 1。点 `i` 属于块 `(i-1)/B`。最后一块可以不满。

```cpp
int B, bl[N], tag[N];
long long a[N], sum[N];

void init(int n) {
    B = max(1, (int)sqrt(n));
    for (int i = 1; i <= n; i++) {
        bl[i] = (i - 1) / B;
        sum[bl[i]] += a[i];
    }
}
```

块 `id` 的元素下标范围：`id*B+1` 到 `min(n, (id+1)*B)`。

### 2. 区间加、区间和

整块：`tag[id] += v`，不改每个 `a[i]`。  
散块：落在区间端点、不满一块的，直接改 `a[i]` 和 `sum[id]`。

```cpp
void add(int l, int r, int v, int n) {
    if (bl[l] == bl[r]) {
        for (int i = l; i <= r; i++) a[i] += v, sum[bl[i]] += v;
        return;
    }
    int L = bl[l], R = bl[r];
    for (int i = l; i <= (L + 1) * B; i++) a[i] += v, sum[L] += v;
    for (int id = L + 1; id <= R - 1; id++) tag[id] += v;
    for (int i = R * B + 1; i <= r; i++) a[i] += v, sum[R] += v;
}
```

查询一段和：散块加 `a[i]`，整块加 `sum[id] + tag[id] * 块内元素个数`。

```cpp
long long ask(int l, int r, int n) {
    long long ans = 0;
    if (bl[l] == bl[r]) {
        for (int i = l; i <= r; i++) ans += a[i] + tag[bl[i]];
        return ans;
    }
    int L = bl[l], R = bl[r];
    for (int i = l; i <= (L + 1) * B; i++) ans += a[i] + tag[L];
    for (int id = L + 1; id <= R - 1; id++) {
        int len = min(n, (id + 1) * B) - id * B;
        ans += sum[id] + 1LL * tag[id] * len;
    }
    for (int i = R * B + 1; i <= r; i++) ans += a[i] + tag[R];
    return ans;
}
```

整块的 `sum` 不加 `tag`，查询时现加。若你在打标记时就把 `sum[id] += v*len`，查询就不要再乘 `tag`，两套选一套，不要加两次。

上面代码是「`sum` 不含 tag」。散块改的是 `a` 和 `sum`，不改 `tag`。

### 3. 什么时候用

| 题 | 选择 |
| --- | --- |
| 区间加、区间和 / 最值 | 线段树更短、更快 |
| 块内需要排序、二分、另类统计 | 分块 |
| 只查不改的区间最值 | [ST 表](ST表.md) |
| n√n 能过、线段树写不出来 | 分块保底 |

n=1e5，√n≈317，q=1e5 时操作量大约 1e5×317，卡常但常能过。不要用分块去卡 n=1e6 且时限很紧的线段树题。

## 常见坑 / 注意事项

- **最后一块 `i<=(id+1)*B` 超出 n。**  
- **`tag` 和 `sum` 各加一次。**  
- **`B=0`。** n≥1 时 `max(1, sqrt)`。  
- **块编号从 0，循环 `id<=R-1` 在 L+1>R-1 时不进入。** 这是对的：中间没有整块。  
- **区间加的散块右端写成 `L*B`。** 和「块 id 覆盖 `[id*B+1, (id+1)*B]`」对一下。  
- **修改散块忘了更新 `sum`。** 整块查询会漏。

## 趣味课间：实验室经典翻车集

- **「分块是线段树的低配，所以我从不写。」** 区间众数、在线莫队的某些部分，低配才是正解。  
- **样例 n 小于 B。** 永远走「同一块」分支。把 B 改成 2 再跑。  
- **`sqrt` 用整数，`B` 取太大，TLE 还以为算法错。** 块长大约 √(n) 或按时限试 √(n/log)。  
- **和莫队比谁更「根号」。** [莫队](莫队.md) 是询问排序；分块是把数组切开。可以同时出现，不是同一个板子。

## 小结

块长 √n。整块标记，两端暴力。区间和不要把 tag 加两次。线段树能干净合并时优先线段树；合并很丑时想起分块。
