# ST 表：预处理区间最值，查询 O(1)

> 读完你应该能：用倍增预处理 `st[i][k] = 从 i 开始长度为 2^k 的最值`；用两个重叠块覆盖任意区间；说明它为什么不能做区间修改；和 [线段树](线段树入门.md) 选边。
>
> 一句口号：**静态区间最值：先花 n log n 建表，再花常数时间问。**

## 背景 / 为什么要读这篇

[线段树](线段树入门.md) 能改能查。很多题只问、不改：区间最小、区间最大、区间 GCD。ST 表（Sparse Table）用倍增，和 [LCA 倍增](LCA倍增.md) 是同一只手。查询时两段 `2^k` 可以重叠，因为 min/max/gcd 重复算不改变结果。

实验室有人查询写成线段树那种不重叠拼接，长度对不上；有人 `st[i][k]` 的第二维当成右端点。本篇只做 RMQ。

## 正文

### 1. 建表

`st[i][k]`：下标区间 `[i, i+2^k - 1]` 的最小值。

```text
st[i][0] = a[i]
st[i][k] = min(st[i][k-1], st[i+2^{k-1}][k-1])
```

k 从 1 到 `floor(log2(n))`。i 的上界要保证 `i+2^k-1 ≤ n`。

```cpp
int st[N][20];  // 2^19 > 5e5，按 n 留够
int lg2[N];

void build(const vector<int>& a) {  // a[1..n]
    int n = (int)a.size() - 1;
    lg2[1] = 0;
    for (int i = 2; i <= n; i++) lg2[i] = lg2[i / 2] + 1;
    for (int i = 1; i <= n; i++) st[i][0] = a[i];
    for (int k = 1; (1 << k) <= n; k++)
        for (int i = 1; i + (1 << k) - 1 <= n; i++)
            st[i][k] = min(st[i][k - 1], st[i + (1 << (k - 1))][k - 1]);
}
```

`lg2[len]` = 不超过 len 的最大 2 的幂的指数。`__lg` 在 gcc 里可用，自己递推更稳。

### 2. 查询

区间 `[l,r]` 长度 `len=r-l+1`，`k=lg2[len]`。两块：从 l 起的 `2^k`，和贴着 r 往左的 `2^k`。它们覆盖 `[l,r]`，中间可能重叠。

```cpp
int qry(int l, int r) {
    int k = lg2[r - l + 1];
    return min(st[l][k], st[r - (1 << k) + 1][k]);
}
```

min、max、gcd 可以重叠。**区间和不行**：重叠部分会加两次。区间和用前缀和或线段树。

### 3. 和线段树、单调队列

| 题 | 选择 |
| --- | --- |
| 静态区间 min/max/gcd，查询很多 | ST，O(1) 或 O(1) 次 gcd |
| 有修改 | 线段树 |
| 滑动窗口定长最值 | [单调队列](单调栈与单调队列.md) 更短 |
| 在线、又要历史版本 | 别用 ST |

空间 O(n log n)。n=1e5、20 列的 `int` 大约几 MB，正常。

LCA 的欧拉序 + RMQ 可以把倍增 LCA 换成 ST。先会本篇的表，再换那条链。

## 常见坑 / 注意事项

- **`k` 用长度本身。** `st[i][5]` 不是「右端点 5」，是长度 32。  
- **查询只取 `st[l][k]`，右端没盖到 r。** 必须两块。  
- **区间和套 ST。**  
- **`i+(1<<k)` 越界仍去取。** 建表的 i 上界写对。  
- **`lg2[0]`。** 空区间别查。  
- **下标 0-based 和 `N` 维搞混，`st[n][k]` 写爆。**

## 趣味课间：实验室经典翻车集

- **「ST 就是线段树的数组版。」** 没有 pushdown，没有单点改。  
- **样例全区间。** `k` 取满，两块起点可能相同，测不出重叠。造 `[2,4]` 在 n=8 上。  
- **gcd 的 ST 查询写了三次 `gcd` 还取中段。** 两块就够，中段是重复。  
- **修改一个点就 `build` 全表。** 改一次 O(n log n)，q 次修改会 TLE。换线段树。

## 小结

倍增预处理 2 的幂长度最值。查询用两个重叠块。只适用于可重叠的运算。要改就回线段树。

建议练习：

- 洛谷 [P3865 【模板】ST 表](https://www.luogu.com.cn/problem/P3865)
- 手算 `a=[3,1,4,2]` 的 `st[*][0]` 和 `st[*][1]`，再查 `[2,4]`  
- 把 min 换成 max，对拍暴力
