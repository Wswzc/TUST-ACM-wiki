# 树上差分：把路径修改变成几点加减

> 读完你应该能：用点差分给路径上每个点 +1；用边差分给路径上每条边 +1；DFS 子树求和还原；知道为什么 LCA 和 LCA 的父亲要减。
>
> 一句口号：**链上加，等价于两端 +1，在分叉处把多算的减掉。树上的差分，LCA 就是那个分叉。**

## 背景 / 为什么要读这篇

[前缀和与差分](前缀和与差分.md) 在数组上：区间加 → 两点改差分数组。树上「路径」是唯一的，同样能差分，只是「两点」变成路径两端和 LCA。

[LCA 倍增](LCA倍增.md) 已经会求交点。运输计划、路径覆盖计数、多次「u 到 v 的路径全体 +1 最后问某点/某边」都是这个板子。

实验室经典：点差分少减了 `fa[lca]`，根没父亲时减到 0 没问题，减错点则整棵子树偏。本篇只打穿**静态多次改、最后一次性查询**（先改完再 DFS 还原）。改查交替要树剖 + 线段树，那是下一座山。

## 正文

### 1. 点差分：路径上的点都加 v

路径 u—v 经过的点（含 u、v、lca）都 +v。差分数组 `d[]` 上：

```text
d[u] += v
d[v] += v
d[lca] -= v
d[fa[lca]] -= v    // 根的父亲是 0，d[0] 丢弃即可
```

为什么：从叶子往根想，子树和 `sum(x)` = x 的子树内所有 `d` 之和，还原后应等于「有多少条被标记的路径覆盖了 x」。

每条 u—v 路径在 u、v 各 +v，沿父指针上传时，从 u 和 v 两路走到 lca 都带上了 v，lca 被加了两次，所以 `d[lca]-=v` 变成一次；还不能继续传给 lca 的父亲，故 `d[fa[lca]]-=v` 抵消。

还原：

```text
DFS 后序：val[x] = d[x] + Σ val[son]
```

`val[x]` 即点 x 被覆盖的总加值。

```cpp
void dfs(int u, int p) {
    for (int v : g[u]) if (v != p) {
        dfs(v, u);
        d[u] += d[v];
    }
}
```

这里直接把儿子的 `d` 累进父亲，后序遍历后 `d[u]` 就是答案（覆盖次数）。注意与「边差分」累加位置不同，见下。

### 2. 边差分：路径上的边都加 v

路径 u—v 上的**边** +v，点本身不加。常见记在「较深的那个端点」上：边 (p,x) 的权记在 x。

```text
d[u] += v
d[v] += v
d[lca] -= 2 * v
```

不减 `fa[lca]`：lca 这个点不应带着边权往上。两路加到 lca 时各算了「通向 lca 的最后一条边」，lca 上减 2v 后，这两条边仍在儿子侧……更稳的理解：

边差分标准板：

```text
d[u] += v; d[v] += v; d[lca] -= 2v
还原后 d[x] 表示边 (fa[x], x) 的权
```

根没有父边，`d[root]` 应还原为 0。

和点差分差在：点差分减 lca 一次再减父亲一次；边差分在 lca 减两次、不动父亲。画三条点的链 1-2-3，路径 1—3，手算一遍 `d`，比背口诀强。

### 3. 和 LCA 一起的最小流程

1. 建树，`dfs` 求 `fa[][0]`、`dep`、倍增  
2. 读 q 条路径，按点或边公式改 `d`  
3. 再 DFS 子树求和  
4. 输出每个点或每条边的值  

不要边改边查 `d[x]`——此时还没还原。全部标记完再第二遍 DFS。

### 4. 例：统计每条边被多少路径覆盖

```cpp
// 读入若干 (u,v)
int w = lca(u, v);
d[u]++; d[v]++; d[w] -= 2;
// dfs 累加后
// 边 (fa[x],x) 的覆盖次数是 d[x]（x != root）
```

洛谷 [P3128](https://www.luogu.com.cn/problem/P3128) [USACO15DEC] Max Flow 是点差分：路径点 +1，问最大点权。公式用第一节。

### 5. 何时不够用

| 操作 | 树上差分 |
| --- | --- |
| 先一堆路径加，最后问点/边 | 够 |
| 加完再问子树和 | 还原后还要再树上前缀 / 树剖 |
| 改与查交错 | 树链剖分 + 线段树 |
| 子树加、点查 | 另一种 DFS 序差分（dfn 区间），不是路径差分 |

子树加：在 DFS 序上 `[dfn[u], dfn[u]+sz[u]-1]` 做序列差分，那是 [DFS 序](https://oi-wiki.org/graph/dfs-tree/) + 序列差分，和路径公式不同。

## 常见坑 / 注意事项

- **点差分漏 `fa[lca]`。**  
- **边差分减了 `fa[lca]`。** 两套公式不要混。  
- **根的父亲当 1。** 必须 0。  
- **还没第二遍 DFS 就输出。**  
- **无向树只 dfs 一次方向。** `p` 防回头。  
- **u=v 的路径。** 点差分：该点 +v，`d[u]+=v; d[v]+=v; d[lca]-=v; d[fa]-=v` → 即 `d[u]+=v; d[fa[u]]-=v`，仍对。边差分 u=v 应不加边。  
- **多组 `d` 未清。**

## 趣味课间：实验室经典翻车集

- **「我树上前缀和从根加到点。」** 那是点到根的链，不是任意 u—v。任意路径必须 LCA。
- **样例是菊花图。** 路径都经过根，公式对错看不出来。造一条链。
- **运输计划没差分先二分。** 那题是二分答案 + 差分验证，先会本篇再叠 [二分答案](lower_bound与二分.md)。
- **树剖第一天。** 静态路径加用差分就结束了，别把代码写成 150 行。

## 小结

路径点加：`u,v +v`，`lca -v`，`fa[lca] -v`。路径边加：`u,v +v`，`lca -2v`，答案记在「朝向父亲的边」。改完再 DFS 累儿子。交错查询请 [树链剖分](树链剖分入门.md)。
