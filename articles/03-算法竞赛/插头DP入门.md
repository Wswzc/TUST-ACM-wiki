# 插头 DP 入门：骨牌沿着轮廓线铺

> 读完你应该能：把「当前格被上一行竖骨牌占住」收成一个 m 位的轮廓；在格子上决定放竖骨牌还是横骨牌，并把新的轮廓写进下一行；说出连通性插头（哪几个插头属于同一条路径）是下一档，m 仍然只能到大约 10。
>
> 一句口号：**轮廓是已经铺好的区域和还没铺的区域之间那一截。每走一格，只改这一截上的一个比特。**

## 背景 / 为什么要读这篇

[状压 DP](状压DP.md) 把集合压进整数。棋盘若有 n 行 m 列，m≤11，用 1×2 骨牌铺满，方案数和「这一行哪些格子已经被上一行伸下来的竖骨牌占住」有关。这个占住的集合就是轮廓。逐格转移轮廓，就是插头 DP 最干净的一种：插头只有「有」或「没有」，没有「这两根插头是否同一连通块」。

实验室有人一行一个状态、在行内不逐格，横骨牌跨两列时把状态写乱；有人铺完 n 行仍要求轮廓非 0，竖骨牌伸到了棋盘外面。本篇答案是 `dp[n][0]`：铺完后不能再有伸出去的插头。

## 正文

### 1. 状态

`dp[r][s]`：前 r 行都铺好了，第 r 行交给第 r+1 行的竖骨牌轮廓是 s。`s` 的第 j 位为 1 表示第 j 列有一块竖骨牌从第 r 行伸进第 r+1 行，所以第 r+1 行这一格已经不能再铺。

初始 `dp[0][0]=1`：第 0 行不存在，没有伸下来的骨牌。

铺第 r 行（0-based）时，从左到右看每一列。进入格子 `(r,c)` 时：

- 若轮廓 s 的第 c 位是 1：这一格已被上一行的竖骨牌占用。不能再放，直接走到下一列，并且**不要**把这个位写进「伸向下一行」的新轮廓。  
- 若是 0：这一格空着，必须放一块骨牌。  
  - 竖放：盖住 `(r,c)` 和 `(r+1,c)`，新轮廓的第 c 位置 1。前提是还有下一行。  
  - 横放：盖住 `(r,c)` 和 `(r,c+1)`。两格当前都必须空着，然后列号跳两格，新轮廓这两位都不置位。

```cpp
int n, m;
long long dp[15][1 << 12];

void go(int row, int col, int state, int nxt) {
    if (col == m) {
        dp[row + 1][nxt] += dp[row][state];
        return;
    }
    if (state >> col & 1) {
        go(row, col + 1, state, nxt);
        return;
    }
    if (row + 1 < n) go(row, col + 1, state, nxt | (1 << col));
    if (col + 1 < m && !(state >> (col + 1) & 1))
        go(row, col + 2, state, nxt);
}

long long solve() {
    memset(dp, 0, sizeof dp);
    dp[0][0] = 1;
    for (int r = 0; r < n; r++)
        for (int s = 0; s < (1 << m); s++)
            if (dp[r][s]) go(r, 0, s, 0);
    return dp[n][0];
}
```

`n` 和 `m` 里较小的那个放在状态维上。2×2 应有 2 种（两横或两竖）。1×2 应有 1 种（一块横骨牌；若 m=1、n=2，则只有竖的一种）。先用这两个数对拍。

复杂度大约 O(n · 2^m · 转移)。m≤11、n≤11 的量级可以换一下谁当列。两边都大于 12 就不是这种轮廓。

### 2. 真正的「多连通插头」

骨牌的插头只有占位。若题是「棋盘上若干条路径，插头要配对、不能交叉」，轮廓上每个位置是「无插头 / 左括号 / 右括号」一类，状态变成 3^m 或最小表示。转移时要合并、拆开连通块。m 通常 ≤ 8 或 10。那是插头 DP 的本体，代码比骨牌长一个数量级。

入门先把骨牌的 `dp[n][0]` 写对。连通性插头以骨牌的「逐格、旧轮廓进、新轮廓出」为骨架，不要跳过骨牌直接抄括号状态。

### 3. 和状压棋盘

互不侵犯、放国王，是「这一行的放置 mask 与上一行兼容」，一行一个状态，见 [状压 DP](状压DP.md)。骨牌的横放会在**同一行里吃掉相邻格**，用「整行 mask 一次枚举」容易漏掉放置顺序，所以改成逐格轮廓。两种都是状压，循环形状不同。

## 常见坑 / 注意事项

- **最后一行还能竖放。** `row+1<n` 才能竖。否则轮廓非 0，`dp[n][0]` 不会收下。  
- **横放时下一格已被上一行占用仍放。** 要看 `state` 的下一位。  
- **`go` 里把 `dp[row][state]` 加了多次，因为对每个起点重复调用且没判断 `dp[row][s]` 为 0。** 代码里有判断；去掉就会爆。  
- **n、m 读反，2^n 爆内存。** 把小的一维当成 m。  
- **答案用 int。** 方案数增长很快。  
- **多测 `dp` 只清了第一行。** `memset` 全表，或滚动数组时两行都清。

## 趣味课间：实验室经典翻车集

- **「插头就是状压的另一种说法。」** 状压是集合。插头强调轮廓上伸出来的线，逐格改。  
- **2×1 的棋盘（两行一列）算成 0。** 竖骨牌应有 1 种。横骨牌放不下。  
- **2×2 只算出两竖，没有两横。** 横放分支的 `col+2` 没走到行尾。  
- **连通性插头的代码用骨牌数据对拍通过，就拿去交回路题。** 占位和配对不是同一个状态。

## 小结

轮廓的一位表示「有一根竖骨牌伸到下一行」。空格上竖放就把下一位轮廓置 1，横放就吃掉右边空格。铺完的答案在 `dp[n][0]`。连通性插头是同一条轮廓，状态从比特变成括号。

建议练习：

- 用 2×2、2×1、1×3 对拍手算（1×3 铺不满，答案 0；1×2 答案 1）  
- 经典题：n×m 骨牌覆盖方案数（Mondriaan's Dream 一类，列数 ≤ 11）  
- 读 [状压 DP](状压DP.md) 的互不侵犯，对比「整行枚举」和「逐格轮廓」
