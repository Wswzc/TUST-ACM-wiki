# 树形 DP：子树算完，再决定根上选不选

> 读完你应该能：在树上 DFS，用子树答案拼出当前点的答案；写出「选或不选当前点」的两类状态；把树上背包（子树里选若干）的循环方向写对；知道它和 [启发式合并](启发式合并.md) 的差别：这里信息能合并成几个数，不必保留整份集合。
>
> 一句口号：**叶子先有答案；父亲等所有儿子回来，再做一次决策。**

## 背景 / 为什么要读这篇

[01 背包](01背包.md) 的决策在一条序列上。[LCA](LCA倍增.md)、[树剖](树链剖分入门.md) 问的是路径和子树区间。有一类题：每个点选或不选，选了相邻不能选，或者子树里最多选 k 个。状态挂在点上，转移沿边走，这就是树形 DP。

实验室有人把父亲边也当儿子扫进去，答案算两遍；有人 `dp[u][1]` 用了儿子的 `dp[v][1]`，相邻都选了。本篇用「没有上司的舞会」钉住选与不选，再用选课看树上背包。

## 正文

### 1. 没有上司的舞会

一棵树（或森林）。点 u 有快乐值 `h[u]`。选 u 就不能选它的直接下属（儿子）。求最大快乐和。

`dp[u][0]`：不选 u，子树最大。  
`dp[u][1]`：选 u，子树最大。

```text
dp[u][0] = Σ max(dp[v][0], dp[v][1])
dp[u][1] = h[u] + Σ dp[v][0]
```

根的答案 `max(dp[root][0], dp[root][1])`。森林就对每个根的并再取 max，或加一个虚根。

```cpp
vector<int> g[N];
int h[N], dp[N][2];

void dfs(int u, int p) {
    dp[u][0] = 0;
    dp[u][1] = h[u];
    for (int v : g[u]) {
        if (v == p) continue;
        dfs(v, u);
        dp[u][0] += max(dp[v][0], dp[v][1]);
        dp[u][1] += dp[v][0];
    }
}
```

无向树必须传父亲。有向「上司→下属」则没有回头边，`p` 可省。

### 2. 树上背包：选课

每个点有学分，选一门课必须先选先修（父亲）。在子树里选恰好 / 至多 m 门，学分最大。

`dp[u][j]`：在 u 的子树里选 j 门（含 u 自己时 j≥1）的最大学分。

合并儿子像分组背包：儿子 v 是一组物品，体积是「在 v 子树里再选几门」。

```cpp
// 先 dfs 儿子，dp[v][*] 已好
// 选 u 自己占 1 门
for (int j = m; j >= 1; j--) {
    for (int k = 0; k < j; k++)  // v 子树再选 k 门，u 这边已有 j-k
        dp[u][j] = max(dp[u][j], dp[u][j - k] + dp[v][k]);
}
```

体积倒序，和 [01 背包](01背包.md) 同一理由：每个儿子只用一次。`k` 从 0 到 `j-1`，别让 `j-k` 和 `k` 都含同一门。先把 `dp[u][1] = 学分[u]`，`dp[u][0]` 按题（不选 u 则整棵子树都不能选，常常是 0）。

复杂度：每个点的子树大小相乘，树上背包总的是 O(n m²)，m 小才可做。

### 3. 和别的树上工具

| 问 | 更可能 |
| --- | --- |
| 每个点一个小状态，能用几个数合并 | 树形 DP |
| 子树颜色种数、众数 | [启发式合并](启发式合并.md) |
| 路径点权、带修改 | [树链剖分](树链剖分入门.md) |
| 路径条数 | [点分治](点分治.md) |

换根 DP（每个点当根的答案）是树形 DP 的下一档：先算向下，再父亲把「除自己以外」传下来。入门先把「指定根、只向下」写对。

## 常见坑 / 注意事项

- **无向边扫回父亲。**  
- **选了 u 还加 `dp[v][1]`。**  
- **多测 `dp` 和 `g` 没清。**  
- **树上背包正序，一个儿子被选多次。**  
- **森林只 dfs(1)。** 还有别的根。  
- **快乐值负仍强制选根。** 不选的状态要留着。

## 趣味课间：实验室经典翻车集

- **「树形 DP 就是 DFS。」** DFS 是遍历。DP 是子树最优值。遍历可以不返回数。  
- **样例是一条链。** 和序列 DP 一样。造一个点三个儿子，看不选根时能不能从不同儿子里各取选。  
- **背包循环 `for k = 0; k <= j` 把 u 自己的学分加了两次。** `k` 的上界是「还没占用 u 那一门」之后剩下的。  
- **换根题用本篇只 dfs 一次。** 只有根的答案对，别的点是「以原根为根」的子树，不是以该点为根的整棵树。

## 小结

子树先算，父亲再合并。选 u 就只能接儿子的不选。树上背包按儿子做分组，体积倒序。信息收不进几个数时，换启发式或点分治。
