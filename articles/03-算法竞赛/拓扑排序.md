# 拓扑排序：有向无环图上的先修课表

> 读完你应该能：用入度 + 队列（Kahn）求出一组拓扑序；用它判断有向图有没有环；知道拓扑序不唯一时队列换成优先队列可以要字典序最小；分清「有向无环」才能排。
>
> 一句口号：**没有入边的课先上；上完，后继的入度减一。上不完 n 门，说明有环。**

## 背景 / 为什么要读这篇

先修关系：学完线性代数才能学机器学习，学完机器学习才能上某门实验。排课表就是拓扑排序。工程里任务依赖、编译依赖、题目里的「A 必须在 B 前出现」，都是同一张有向图。

图必须是 **DAG（有向无环图）**。有环就存在「谁都得在谁前面」的死结，课表不存在。算法顺手还能**判环**——比 DFS 找回边更好讲给队友听。

[BFS](BFS网格最短路.md) 的队列在这里换了语义：不是距离，是「当前可以选的点」。实验室有人把无向图拿来拓扑，入度对称减完全是 0 或全不是；有人有环仍输出半截序列当答案。

## 正文

### 1. 定义

有向图，点 1..n。拓扑序是点的一个排列 `p1, p2, ..., pn`，每条边 `u → v` 都满足 u 在 v **前面**（先 u 后 v）。

不是最短路，不是遍历顺序的随意 DFS。DFS 的结束时间反序也是一种拓扑（后文），入门先掌握 Kahn。

### 2. Kahn：入度 + 队列

```text
计算每个点的入度 indeg
把所有 indeg==0 的点入队
当队列非空：
    取出 u，放进答案
    对 u 的每个后继 v：indeg[v]--
    若 indeg[v]==0，v 入队
若答案长度 < n：有环
```

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<vector<int>> g(n + 1);
    vector<int> indeg(n + 1, 0);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;  // u → v：u 先于 v
        g[u].push_back(v);
        indeg[v]++;
    }

    queue<int> q;
    for (int i = 1; i <= n; i++)
        if (indeg[i] == 0) q.push(i);

    vector<int> ord;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        ord.push_back(u);
        for (int v : g[u]) {
            if (--indeg[v] == 0) q.push(v);
        }
    }

    if ((int)ord.size() != n) {
        cout << "有环\n";
        return 0;
    }
    for (int i = 0; i < n; i++) {
        if (i) cout << ' ';
        cout << ord[i];
    }
    cout << '\n';
    return 0;
}
```

边 `u → v` 的方向要和题意一致：「u 是 v 的先修」则箭头 u→v。反了，序就反。

### 3. 字典序最小：队列换成堆

题面「若有多种顺序，输出字典序最小」。`queue` 改 `priority_queue` 小根堆，每次取编号最小的入度为 0 的点。复杂度多一个 log。

```cpp
priority_queue<int, vector<int>, greater<int>> q;
```

不要 sort 最后的 `ord`——那会破坏拓扑约束。必须在「当前可选集合」里取最小。

### 4. 有环、重边、自环

自环：`indeg` 至少 1 且后继是自己，永远减不掉，`ord.size() < n`。正确拒绝。

重边：入度加多次，减多次，通常仍对；建图时可去重。

输出「任意合法序」时 Kahn 的顺序取决于入队顺序。不要假设唯一。

### 5. DFS 拓扑：结束时间从晚到早

再递归进入后继，回溯时把 u 压栈。最后栈从顶到尾是拓扑序。若存在回边（访问到「正在栈上的祖先」），有环。和 [DFS 回溯](DFS回溯.md) 的三色标记是亲戚：灰点再碰到就是环。

入门赛 Kahn 更不容易写错。DFS 版在需要「反图 + 拓扑」的 DP 里也会出现。

### 6. 拓扑序上的 DP

DAG 上最长路、最少时间（关键路径）：按拓扑序推 `dp[v] = max(dp[v], dp[u] + w(u,v))`。因为没有环，每个点的前驱都已经算完。这是「图上 DP」的入场券，比二维网格 DP 更图论。

不能拓扑的图不要硬 DP 一遍——可能有环，需要最短路或其他。

### 7. 复杂度

O(n+m)。每个点入队一次，每条边减一次入度。n、m = 1e5 常规。

## 常见坑 / 注意事项

- **边方向反了。**
- **有环仍输出 `ord`。** 必须比长度。
- **无向图拓扑。** 定义在有向上。无向环更常见，那是另一类。
- **字典序去 sort 答案。**
- **入度数组忘了点 0 或点 n。**
- **`--indeg[v] == 0` 写成 `indeg[v]--` 再另判，中间插了别的代码改了 indeg。** 一行完成最干净。
- **多组数据 `indeg` 残留。**

## 趣味课间：实验室经典翻车集

- **「我 DFS 一遍输出访问顺序。」** 那是先序，不是拓扑。先序可能把后继打在祖先前面。
- **样例是一条链。** 任何算法都对。造一个叉：1→3，2→3，字典序应先 1 再 2 再 3 或先 2——看编号和堆。
- **判环用拓扑，找环上的点。** `ord` 里没有的点在环里或能走到环。要输出环本身需要 DFS 记栈。
- **课程表题用 BFS 最短路。** 边无权「距离」没意义，入度才有。

## 小结

入度为 0 的先取出，减后继入度，长度不到 n 就是有环。字典序用小根堆。DAG 上 DP 按这张序推。
