# 整体二分：一群询问一起砍答案

> 读完你应该能：把「每个询问各自二分答案」收成「对答案值域做一次分治，询问分成左右两堆」；用树状数组当作 `check(mid)` 的工具，并在进入下一层前撤销；说明它和 [主席树](主席树.md) 都能做静态区间第 k 小，一个离线、一个可持久化。
>
> 一句口号：**不是每个询问砍自己的 mid。是同一个 mid 把所有还没确定的询问一起砍开。**

## 背景 / 为什么要读这篇

[lower_bound 与二分](lower_bound与二分.md) 是单个答案的二分。若有 m 个询问，每个都在值域上二分，每次 `check` 是一次树状数组或扫描，总复杂度多一个能接受的 log，但写出来是「外层询问、内层二分、最内再清空结构」，常数和代码都容易乱。

整体二分把结构倒过来：值域 `[vl,vr]` 取 `mid`，按时间顺序扫当前这批操作。修改的值 `≤ mid` 就插入结构；询问根据结构里的计数决定自己的答案落在左边还是右边。然后撤销，两堆分别递归。同一层的插入被所有还活着的询问共享。

实验室有人每个询问各开一棵树状数组；有人左边递归没撤销，右边看到左边的残值。本篇用「带单点修改的区间第 k 小」这个离线模型。

## 正文

### 1. 操作序列

时间顺序的操作只有两种：

- 修改：在位置 `pos` 把一个数 `val` 加进来（静态数组就是一开始按位置插入）。  
- 询问：区间 `[L,R]` 的第 `k` 小是多少。

值域 `[vl,vr]`。`mid = (vl+vr)/2`。从左到右扫当前队列：

- 修改：若 `val≤mid`，树状数组 `pos` 加 1，并把这个修改分到**左**子问题；否则分到右，现在不插入。  
- 询问：设当前树状数组在 `[L,R]` 的和是 `cnt`（也就是「已经插入的、值 ≤ mid 的个数」）。若 `k≤cnt`，答案 ≤ mid，询问进左边；否则答案 > mid，`k -= cnt`，询问进右边。

左子问题值域 `[vl,mid]`，右子问题 `[mid+1,vr]`。进入递归前把树状数组撤销干净。

`vl==vr` 时，队列里剩下的询问答案就是 `vl`。

### 2. 为什么是对的

`check` 对答案单调：值域上界变大，区间里 ≤ 上界的个数只增不减。第 k 小是使这个个数第一次 ≥ k 的那个值。整体二分只是把同一层、同一个上界的 check 合并了。询问带去右边时减掉 `cnt`，是因为左边那些 ≤ mid 的数已经确定比答案小，第 k 小在右边变成第 `k-cnt` 小。

静态区间第 k 小：没有「后来的修改」，就把数组里每个 `a[i]` 当成时间 i 的一次插入，询问时间放在所有插入之后，或插入和询问按位置交织——只要「询问之前，位置上该有的数都已插入」。最省事的静态做法是：先按位置 1..n 依次出现插入操作，询问不占用位置，在分治扫的时候插入仍然按位置顺序。实现时用一个操作数组，类型字段区分。

### 3. 复杂度和撤销

设值域和 n 同阶。层数 O(log V)。每一层每个操作被扫常数次，树状数组 O(log n)。总 O((n+m) log V log n)。

撤销：记录这一层 `add` 过的下标，递归前逐个 `add(pos,-1)`。不要为了省事重建树。也不要在左递归返回后忘记当时是在进入左之前就该清空——清空发生在**把操作分进左右之后、递归之前**，左右两支看到的树都是空的，它们自己再插入。

```text
solve(vl, vr, ops):
    if ops 空: return
    if vl == vr: 给 ops 里所有询问填 vl; return
    mid = (vl+vr)/2
    扫 ops，边插入边分类到 L、R
    撤销本层所有插入
    solve(vl, mid, L)
    solve(mid+1, vr, R)
```

和 [CDQ 分治](CDQ分治.md) 的差别：CDQ 按时间或第一维把点集切开，贡献是左对右。整体二分按**答案**切开，操作序列的相对顺序在每一层保持不变。不要写成先递归左半段下标。

### 4. 和主席树

| | 整体二分 | 主席树 |
| --- | --- | --- |
| 在线 | 否 | 静态前缀可以在线 |
| 带修改的第 k 小 | 离线方便 | 带修主席更难写 |
| 空间 | 树状数组 | O(n log n) 个结点 |

两种都该会认。模板题 P3834 用主席树更直接；整体二分用来确认你真的理解「第 k 小 = 值域上的二分」。

## 常见坑 / 注意事项

- **右边的 k 没有减 cnt。**  
- **`val≤mid` 的修改被分到右边又插入了。** 分类和插入是同一条件。  
- **撤销漏了，下一层从脏树开始。**  
- **询问和修改的时间顺序在分类时被 sort 掉。** 必须按原时间扫。  
- **`mid` 用 `(vl+vr)>>1` 在负数溢出。** 值域若可能负，先离散化成正的名次，答案再映射回去。见 [离散化](离散化.md)。  
- **空的 ops 仍去访问树。**

## 趣味课间：实验室经典翻车集

- **「整体二分就是 parallel binary search 这个英文，所以和普通二分代码一样。」** 普通二分的 mid 属于一个询问。整体二分的 mid 属于值域，询问是被 mid 劈开的货物。  
- **样例只有一次询问、数组有序。** 第 k 小就是 `a[k]` 若区间是全体。改成乱序、两次不同区间。  
- **和 CDQ 共用一个函数名 `solve(l,r)`，下标和值域混用。** 参数名叫 `vl,vr`。  
- **对拍用 n≤8 的 `nth_element`，大 n 才发现没撤销。** 小 n 也要把「两层递归」跑到，不要只测 `vl==vr` 一开始就命中。

## 小结

值域取 mid，按时间扫：小的修改插入并进左边，询问按树状数组计数决定左右，右边的 k 减去已经比答案小的个数。递归前撤销。离线第 k 小用它；在线静态用主席树。

建议练习：

- 把 [主席树](主席树.md) 的 P3834 再用整体二分写一遍，对拍  
- 手算三个数、一次「全体第 2 小」，看 mid 把询问分到哪边  
- 读 [CDQ 分治](CDQ分治.md)，在纸上写「切开的是下标还是答案」
