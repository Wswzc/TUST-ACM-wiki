# 欧拉路：一笔画走完所有边

> 读完你应该能：分清欧拉路（走完每条边恰好一次）和哈密顿路（走完每个点恰好一次）；用度数判断有向 / 无向图是否存在；写出 Hierholzer（删边 DFS，后序记录）并得到边序或点序。
>
> 一句口号：**哈密顿管点，欧拉管边。点可以重复踩，边不能重复走。**

## 背景 / 为什么要读这篇

[状压 DP](状压DP.md) 的 TSP 是哈密顿回路：每个城市一次。欧拉是另一件事：七桥问题、一笔画、把所有边用掉。复杂度也不是 2^n，是 O(m)。

实验室有人把「经过所有点」做成欧拉；有人 Hierholzer 写成先记录点再递归，路径在岔路口抄近路漏边；有人无向图边没标记，一条边走两回。本篇把判定和那一次后序 DFS 钉死。

## 正文

### 1. 路还是回路，有向还是无向

**欧拉路：** 每条边恰好经过一次的通路（点可重复）。  
**欧拉回路：** 起点终点相同的欧拉路。

先忽略度数为 0 的孤立点（没有边就不用走）。下面「所有点」指有边的点所在的那个连通块——还要先确认**边都在同一个连通块**（无向看连通；有向看弱连通，且该走的边互相达得到）。

| 图 | 欧拉回路 | 欧拉路（非闭） |
| --- | --- | --- |
| 无向 | 所有点度数为偶数 | 恰好 2 个奇度点（作起终点），其余偶 |
| 有向 | 每个点入度 = 出度 | 恰好一个点出度 = 入度 + 1（起点），一个点入度 = 出度 + 1（终点），其余相等 |

0 个奇度点的无向图，回路也是路。起点可任选一个有边的点。有向非闭：必须从「出度多 1」的点开始。

哈密顿：n! / 状压 2^n。欧拉：线性。题面「所有边 / 所有街道 / 所有单词接龙用掉」才是欧拉；「所有城市一次」不是。

### 2. Hierholzer：走到走不动，回溯时记账

朴素想法：贪心走，死胡同了才发现前面岔路还有边。Hierholzer 的修正在：**递归时先把边删掉并走完，回到本点再记本点**（后序）。这样死胡同先被记在路径末端，回溯时再补上没走完的环。

有向图，邻接表用栈式删除（`pop_back`）：

```cpp
vector<int> g[N];  // 出边终点；若要字典序最小，先把每条 g[u] 降序排，再 pop
vector<int> path;

void hierholzer(int u) {
    while (!g[u].empty()) {
        int v = g[u].back();
        g[u].pop_back();
        hierholzer(v);
    }
    path.push_back(u);
}

// 从起点 s 调用后，reverse(path) 得到点序列
// 边数 m 的欧拉路应有 m+1 个点（回路则首尾相同，点数 m+1）
```

从正确的 s 跑完，`path` 反转后应含 m+1 个点。若更少，说明有边不在这个弱连通里，或不该从 s 起——先判度数再跑。

无向图每条边只能走一次，邻接表要带边编号：

```cpp
struct E { int to, id; };
vector<E> g[N];
vector<int> vis;  // 边是否用过
vector<int> path;

void hierholzer_undirected(int u) {
    while (!g[u].empty()) {
        E e = g[u].back();
        g[u].pop_back();
        if (vis[e.id]) continue;
        vis[e.id] = 1;
        hierholzer_undirected(e.to);
    }
    path.push_back(u);
}
```

加边时正反各插一条、同一 `id`。`continue` 掉已用边后，可能 `g[u]` 里还有没用的，所以是 `while` 不是一次 `if`。

### 3. 输出边还是点、字典序

题目要点序：反转 `path`。要边序：在递归里记下被删的边，同样后序，再反转。

字典序最小：出边按终点从大到小排序，每次 `pop_back` 取出当前最小；或用 `priority_queue` / `multiset`。排序是 O(m log m)，别每次找最小却写成 O(m²)。

单词接龙、点是 26 个字母、边是单词：26 个点，边带字符串。先按字典序排边，再 Hierholzer。

### 4. 和 DFS 遍历的差别

[DFS 回溯](DFS回溯.md) 的 vis 多半在**点**上。欧拉的 vis 在**边**上。点会多次进入 `hierholzer`——这是合法的，因为还要从这个点出去走剩下的边。不要看见 `dfs(u)` 第二次就 `return`。

## 常见坑 / 注意事项

- **先序压路径。** 岔路漏边。必须后序。  
- **无向图边走两次。** 缺 `id`/`vis`。  
- **不判连通，只判度数。** 两个圈不相连，度数都对，没有一条路能走完。  
- **起点选错。** 有向非闭必须从出度多 1 的点起。  
- **`path` 长度不对仍输出。** 和 m+1 比一下。  
- **当成哈密顿用状压。** n 大 m 小才是欧拉的舒适区。  
- **递归 m=1e6 爆栈。** 扩栈或改成显式栈模拟。

## 趣味课间：实验室经典翻车集

- **「一笔画不就是 DFS 吗。」** 是 DFS，但记账时间点和 vis 对象都换了。  
- **样例是一条链。** 先序后序都对。造一个「中点长出一只环」：只有后序能先走完环再回头。  
- **TSP 模板改两行当欧拉。** 2^n 对 m=1e5 是事故。  
- **字典序：每次 `sort` 整个邻接表。** TLE。排一次，或用可弹出最小值的结构。

## 小结

欧拉走边、哈密顿走点。度数给存在性，Hierholzer 给方案：删边 DFS，回溯时记点，最后反转。无向边打编号，有向边 `pop` 出边。先判连通再跑。
