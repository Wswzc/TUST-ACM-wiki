# 树状数组：前缀和会动的时候

> 读完你应该能：用 `lowbit` 写出单点加、前缀和查询；用两次前缀和得到区间和；知道它和 [静态前缀和](前缀和与差分.md) 的分界：数组会改就上树状数组；以及为什么下标要从 1 开始。
>
> 一句口号：**每个下标管一段长度为 lowbit(i) 的和。改一个点，跳着改祖先；问前缀，跳着减下标。**

## 背景 / 为什么要读这篇

[前缀和](前缀和与差分.md) 问区间和是 O(1)，但改一个 `a[i]` 要重建整段 s，O(n)。题面若 q 次混合「给某点加 v」和「问 [l,r] 之和」，n、q = 1e5，暴力是 1e10。

线段树能做，代码长。树状数组（Fenwick / BIT）只管「单点改、前缀查」这一类，**十几行**，常数小，竞赛里极常见。新人指南把它和线段树并列放在第 1 年末——先会 BIT，线段树好接受得多。

实验室有人 `c[0]` 死循环（`lowbit(0)=0`），有人查询写了 `i += lowbit` 更新写了 `i -=`，方向反了。本篇把两个 while 的方向钉死。

## 正文

### 1. lowbit：最低的 1 和它代表的长度

```cpp
int lowbit(int x) { return x & -x; }
```

二进制里最低的那个 1，以及它右边的 0。例如 12 是 `1100`，lowbit=4。

树状数组 `c[i]` 存的是 `a` 上区间 `(i-lowbit(i), i]` 的和，即 **以 i 为右端、长度 lowbit(i) 的一段**。i 管一小段，i 加上 lowbit 跳到更大的段。不必会画那张经典二叉树，会用两段循环即可；想理解时再翻 OI Wiki 的图。

**下标必须从 1 到 n。** `i=0` 时 `lowbit(0)=0`，`i += 0` 死循环。开 `n+1`，浪费 `c[0]`。

### 2. 模板：加与前缀和

```cpp
struct BIT {
    int n;
    vector<long long> c;
    BIT(int n) : n(n), c(n + 1, 0) {}

    void add(int i, long long v) {      // a[i] += v
        for (; i <= n; i += lowbit(i)) c[i] += v;
    }
    long long sum(int i) {              // a[1]+...+a[i]
        long long s = 0;
        for (; i > 0; i -= lowbit(i)) s += c[i];
        return s;
    }
    long long range(int l, int r) {     // a[l]+...+a[r]
        return sum(r) - sum(l - 1);
    }
};

int lowbit(int x) { return x & -x; }
```

记住方向：

| 操作 | i 怎么走 |
| --- | --- |
| 修改 `add` | `i += lowbit(i)`，走向更大的管辖者 |
| 查询 `sum` | `i -= lowbit(i)`，拆成几段已经存好的块 |

`range(l,r) = sum(r)-sum(l-1)`，`l=1` 时 `sum(0)=0`，循环不进，安全。

建树：读入 `a[i]` 后 `add(i, a[i])`，总 O(n log n)。不要先填 `c` 再幻想它自动合法。

### 3. 完整例：动态区间和

```cpp
#include <bits/stdc++.h>
using namespace std;

int lowbit(int x) { return x & -x; }

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    BIT bit(n);  // 把结构体放文件前面
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        bit.add(i, x);
    }
    while (q--) {
        int op;
        cin >> op;
        if (op == 1) {
            int i;
            long long v;
            cin >> i >> v;
            bit.add(i, v);
        } else {
            int l, r;
            cin >> l >> r;
            cout << bit.range(l, r) << '\n';
        }
    }
    return 0;
}
```

上面 `BIT` 需贴在 `main` 前。操作编号随题面。

### 4. 差分树上：区间加、单点查

要「给 [l,r] 全体 +v，问某点值」，对差分数组建 BIT：`add(l,v); add(r+1,-v);` 查询 `sum(i)` 即 `a[i]`。和前缀和篇的差分是同一对偶，只是差分会改。

区间加 + 区间和需要维护两个 BIT 或上线段树。入门先单点加+区间和，再差分版区间加+单点查。两套都要「区间加+区间和」时，承认 BIT 别扭，换线段树。

### 5. 求逆序对：权值树状数组

经典：有多少对 i<j 但 a[i]>a[j]。从左到右（或从右到左）扫，BIT 里按下标是**值**（离散化后）。

```text
离散化 a 到 1..m
ans = 0
从左到右：
    ans += 已经出现的、比 a[i] 大的个数   // sum(m) - sum(id)
    add(id, 1)
```

值域 1e9 必须离散化，否则开不下。这是 [sort unique](../01-编程语言/vector与sort.md) + BIT 的组合题，比纯模板更常考。

### 6. 和线段树、前缀和怎么选

| 需求 | 选 |
| --- | --- |
| 静态区间和 | 前缀和 |
| 单点加，前缀/区间和 | **树状数组** |
| 区间加，单点查 | BIT 维护差分 |
| 区间加，区间和 / 最值 / 各种合并 | 线段树 |
| 可持久化、动态开点 | 线段树 |

能 BIT 就 BIT。赛时十分钟写完区间和，别上 80 行线段树给自己找 CE。

### 7. 复杂度

每次 add/sum 都是 O(log n)，最多大约 `log2(n)` 次跳。n=1e6、q=1e6 常规。空间 O(n)。

## 常见坑 / 注意事项

- **下标从 0。** `lowbit(0)` 死循环。
- **add 用 `-=`，sum 用 `+=`。** 方向反，答案像随机数。
- **`l-1` 在 l=1 时。** `sum(0)` 必须返回 0。
- **n 和数组大小。** `i<=n` 里 n 是 BIT 容量，点编号不能超。
- **`int` 存和。** 1e5 × 1e9。
- **区间加直接 `for l..r add(i,v)`。** 那是 O(n log n) 每次，用差分。
- **权值 BIT 忘离散化。**
- **多组数据 `c` 没清空。** 重新构造 BIT。

## 趣味课间：实验室经典翻车集

- **「lowbit 我背成 `x & (x-1)`。」** 那是去掉最低 1，用来判 2 的幂、枚举子集。方向反了。Fenwick 要的是最低 1 本身：`x & -x`。`x-1` 那版在 `add` 里会跳去奇怪的地方。
- **调试打印 `c` 当 `a`。** `c[i]` 不是 `a[i]`。查 `a[i]` 用 `range(i,i)`。
- **线段树抄半截和 BIT 混用。** 两套下标变换不一样。
- **逆序对 n² 过了样例。** 数据范围 1e5 是来查这个的。

## 小结

`lowbit` 跳着改、跳着查。`add` 往大走，`sum` 往小走，下标从 1。静态用前缀和；会改用 BIT；又要区间最值再线段树。逆序对 = [离散化](离散化.md) + 权值 BIT。
