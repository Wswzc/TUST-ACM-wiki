# 带权并查集：点到根的差分

> 读完你应该能：在 `find` 压缩路径时把「到父亲的权」加成「到根的权」；合并两个集合时改写一条边的权；用模 3 的关系做食物链那类题；说清它和 [差分约束](差分约束.md) 都是在维护差，一个在线、一个是图。
>
> 一句口号：**每个点记它到父亲的关系；找根时把关系累加。同一棵树里，两点的关系是两条到根的关系之差。**

## 背景 / 为什么要读这篇

[并查集](并查集.md) 只回答在不在同一集合。食物链、品种、真假话：还要回答「x 比 y 大 1」或「同类 / 捕食 / 被捕食」。关系可以合并，就在并查集边上加权。

实验室有人路径压缩只改 `fa` 不改 `d`，压缩一次关系全乱；有人合并时用了压缩前的父亲。本篇按「先 find 再读 d」来写。

## 正文

### 1. 权是到父亲的差

`d[x]`：x 到 `fa[x]` 的关系。食物链用模 3：0 同类，1 吃父，2 被父吃（约定写在注释里，全篇不要换）。

路径压缩：x 到根的关系 = x 到旧父的关系 + 旧父到根的关系。

```cpp
int fa[N], d[N];

int find(int x) {
    if (fa[x] == x) return x;
    int p = find(fa[x]);
    d[x] = (d[x] + d[fa[x]]) % 3;
    fa[x] = p;
    return p;
}
```

必须先递归，让 `d[fa[x]]` 变成「旧父到根」，再加到 `d[x]` 上，最后才把 `fa[x]` 改成根。顺序反了就会用到已经不是父亲的那一格，或者还没更新的 0。

两点同根时，x 相对 y 的关系是 `(d[x] - d[y] + 3) % 3`（在「到根」的定义下）。先把两边都 `find` 过。

### 2. 合并

已知「x 与 y 的关系是 r」（0 同类，1 x 吃 y，按你的题面翻译成模 3）。

```cpp
void merge(int x, int y, int r) {
    int fx = find(x), fy = find(y);
    if (fx == fy) return;  // 调用前已经查过是否矛盾
    fa[fx] = fy;
    // d[x]、d[y] 已是到各自根
    // 要让 (d[x] - d[y]) ≡ r (mod 3) 在新结构下成立
    // x -> fx -> fy，y -> fy
    // d[x]_new_to_fy = d[fx] + d[x] 应 ≡ d[y] + r
    d[fx] = (d[y] - d[x] + r + 3) % 3;
}
```

同一根上再来一条关系：看 `(d[x]-d[y]+3)%3` 是否等于 r。不等就是假话，这句话丢掉，不合并。

食物链的语句要先翻译成 r。例如「x 吃 y」对应哪一个余数，用样例第一句对一下，不要凭记忆对调 1 和 2。

### 3. 和差分约束

| | 带权并查集 | 差分约束 |
| --- | --- | --- |
| 关系 | 等式模 m，或确定的差 | `≤` 不等式 |
| 矛盾 | 同根但差不对 | 负环 |
| 在线 | 适合一句句来 | 通常离线建完图 |

全是 `x-y=c` 的等式，并查集更短。出现「最多大 3」，去差分约束。

## 常见坑 / 注意事项

- **压缩时先 `fa[x]=find(fa[x])` 再加 `d`。** 此时 `d[fa[x]]` 已经不是旧父。用上面的 `p` 写法。  
- **余数写成 1 和 2 反了。** 用一句话对拍。  
- **没 `find` 就读 `d[x]`。** `d` 可能还是到旧父，不是到根。  
- **模数不是 3 仍 `%3`。**  
- **合并公式抄反，`d[fx]` 多一个负号。** 用两个点手算。  
- **矛盾的句子仍 merge。** 食物链假话不能并进去，否则污染后面。

## 趣味课间：实验室经典翻车集

- **「带权就是按秩。」** 按秩是启发式，权是关系。两件都可以有，不要用秩数组存食物链。  
- **样例全是「同类」。** `d` 全 0 也对。造一句「x 吃 y」再问一次。  
- **路径压缩关着能过小数据，一开就 WA。** 几乎一定是 `d` 没累加。  
- **把关系存成矩阵 n=1e5。** 这就是并查集存在的理由。

## 小结

`d[x]` 是到父亲的关系。`find` 时累加到根。同根用差检验，不同根用一条边把两根接上并解出 `d[根]`。不等式别硬塞进来。

- 洛谷 [P2024 [NOI2001] 食物链](https://www.luogu.com.cn/problem/P2024)

- 再加一句矛盾的，确认没有 merge
