# 博弈论入门：Nim 与 SG，先手会不会赢

> 读完你应该能：说出公平组合游戏的规则假设；用 Nim 堆的 XOR 判断先手胜负；用 mex 定义 SG 函数，并把一堆游戏拆成若干独立子游戏再 XOR；知道「看样例猜奇偶」不是证明。
>
> 一句口号：**必败态走一步只能到必胜态的邻居？反了。必败态是：所有走法都进必胜；必胜态是：存在一步进必败。**

## 背景 / 为什么要读这篇

ICPC / CCPC 里的博弈题，多数不是象棋残局，而是：**两个人轮流、信息完全、没有平局、不能的人输**（公平组合游戏，Impartial）。石子、取火柴、删边、在 DAG 上挪棋子。

实验室有人把「先手拿 1 必胜」当成所有取石子的答案；有人会 Nim 的 XOR 却把多堆规则记成加起来；有人 SG 写成「当前能拿的个数」。本篇从 Nim 钉到 SG，复杂图游戏用同一套。

## 正文

### 1. 必胜与必败，从叶子往回推

一个局面：

- **必败（P-position）**：轮到你时，无论怎么走，对手都能让你继续输。没有合法走法（0 堆石子）通常是必败。
- **必胜（N-position）**：存在**一步**走到必败局面。

不要背「奇数先手赢」。先画小局面：0 必败；能走到 0 的必胜；只能走到必胜的必败。

### 2. Nim：多堆石子，一堆里随便拿

若干堆，每步选**一堆**，拿走至少 1 枚（可以整堆）。不能拿的人输。

结论：把每堆石子数 XOR 起来，结果为 **0 则先手必败，非 0 则先手必胜**。

```cpp
int nim(const vector<int>& a) {
    int s = 0;
    for (int x : a) s ^= x;
    return s;  // 0 先手败，否则先手胜
}
```

直觉（不必当证明背）：最高位为 1 的那一堆，可以拿走若干使总 XOR 变 0；对手再动，你再调回 0。直到全 0。

一堆 Nim 就是：n=0 败，n>0 胜。两堆相等则 XOR 为 0，先手动哪堆，后手在另一堆拿同样多。

变体「每堆最多拿 k 个」不是裸 Nim，是下面的 SG。

### 3. SG：给每个局面一个 nimber

有向图游戏：点是局面，边是走法。公平：两人可走的边一样。

`mex(S)` = 不在集合 S 里的最小非负整数。`mex({0,1,3})=2`。

```text
SG(x) = mex { SG(y) | x 能一步走到 y }
```

没有出边：`SG=mex{}=0`，必败。`SG≠0` 必胜：能走到一个 SG=0 的后继。

**和游戏（两局并列，一步只动其中一局）：** 总 SG = 各子游戏 SG 的 XOR。这就是 Nim 的来历：一堆 n 个、可拿到 0 的 SG(n)=n。

```cpp
const int N = 10005;
int sg[N];
bool vis[N];
vector<int> go;  // 一步能减的数目，例如 {1,2,3}

int get_sg(int x) {
    if (sg[x] != -1) return sg[x];
    memset(vis, 0, sizeof(bool) * 32);  // mex 通常很小，按题开
    for (int d : go) {
        if (x >= d) vis[get_sg(x - d)] = 1;
    }
    int m = 0;
    while (vis[m]) m++;
    return sg[x] = m;
}
```

多堆独立同样规则：每堆算 SG，再 XOR。全 0 先手败。

`memset` 每次递归里清 vis 会慢，竞赛里常用 `bool vis[]` 加时间戳，或对 x 从 0 到 n 递推。

```cpp
void build(int n) {
    for (int i = 0; i <= n; i++) {
        vector<char> seen(64, 0);
        for (int d : go)
            if (i >= d) seen[sg[i - d]] = 1;
        int m = 0;
        while (m < 64 && seen[m]) m++;
        sg[i] = m;
    }
}
```

### 4. 什么时候不是 SG

| 形态 | 做法 |
| --- | --- |
| 公平、可拆成独立堆 | Nim / SG |
| 两人能走的不一样（棋子分颜色） | partizan，入门先别套 SG |
| 有平局、同时行动 | 另一套模型 |
| 最优分数不是输赢 | DP / 博弈 DP，不是 mex |

看见「每次从**一堆**拿」，先想 XOR。看见「从两堆同时拿」或棋盘，先画后继再写 SG，不要硬 Nim。

## 常见坑 / 注意事项

- **Nim 写成求和。**  
- **SG 的 vis 没清，mex 永远 0。**  
- **递归 SG 不记忆化，指数爆炸。**  
- **`go` 漏了「可拿整堆」。** 读题。  
- **输出 `Yes` 当先手胜，题面要 `Alice`。**  
- **三堆样例全 0。** 任何实现都说先手败。造 `1,2,3`（XOR=0）和 `1,2,4`。

## 趣味课间：实验室经典翻车集

- **「博弈就是找规律。」** 规律可以当猜想，交之前用小 n 打表对 SG。  
- **石子 1,2,3 先手拿完一堆以为必胜。** `1^2^3=0`，先手必败。  
- **把 SG 理解成「能拿几个」。** mex 是后继集合的缺口，不是步数。  
- **对拍两份都写 `n%2`。** 见 [对拍](../00-团队指南/对拍.md)：暴力应是完整搜索胜负，不是同一句奇偶。

## 小结

叶子必败。能走进必败则必胜。Nim 是 XOR。一般公平游戏是 SG，子游戏 XOR。先打表再猜公式。
