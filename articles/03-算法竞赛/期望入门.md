# 期望入门：走到下一步的平均值

> 读完你应该能：写出 `E = Σ p_i (代价_i + E_i)`；在 DAG 上按拓扑逆序求期望；说明有环时要列方程，交给 [高斯消元](高斯消元.md)；不要把期望当成「最可能的那一条路径」。
>
> 一句口号：**期望是加权平均，不是取 max。终点是 0，往回推。**

## 背景 / 为什么要读这篇

最短路问的是最坏或最优的一条。期望问的是：每步按概率乱走，平均要多少代价。绿豆蛙、玩彩票、随机游走，都是这个式子。

实验室有人在 DAG 上取最大边当期望；有人从起点正着推，后继的 E 还没算；有人概率用 `int` 除法变成 0。本篇只做 DAG 上的期望长度，环状的方程点到为止。

## 正文

### 1. 定义就这一行

从状态 u 出发，以概率 `p_i` 走到 v_i，这一步付出 `w_i`，则

```text
E[u] = Σ p_i * (w_i + E[v_i])
E[终点] = 0
```

若每条出边等概率，`p_i = 1/出度`。

线形例子：必须往右走，1→2→…→n，每步代价 1。`E[n]=0`，`E[i]=1+E[i+1]`，所以 `E[1]=n-1`。这和「最短路长度」数值相同，因为没有随机。随机一出现，就要平均，不能改成 min。

### 2. DAG 上倒着算

后继的 E 必须先有。DAG 上按拓扑序的**逆序**（先终点，后起点）：

```cpp
vector<pair<int, long long>> g[N];  // 出边 {v, w}
int out[N];
double E[N];

void solve_dag(int n, const vector<int>& topo) {
    // topo[0] 是源侧，topo.back() 含汇
    for (int i = n - 1; i >= 0; i--) {
        int u = topo[i];
        if (out[u] == 0) {
            E[u] = 0;
            continue;
        }
        E[u] = 0;
        for (auto [v, w] : g[u]) E[u] += (double)w + E[v];
        E[u] /= out[u];
    }
}
```

拓扑用 [拓扑排序](拓扑排序.md)。汇点出度 0，期望 0（已经在终点）。若题目终点是 n 且保证能走到，从 n 开始的逆序会把用得到的点都算到。

输出一般要小数。`printf("%.2f\n", E[1])` 看题面位数。比较时不要用 `==` 对 double。

洛谷 P4316「绿豆蛙的归宿」就是：DAG、出边等概率、边权为长度，求 1 到 n 的期望长度。式子与上面一致。

### 3. 有环：列方程

无向图随机游走、或有向图有环，后继可能指回自己，逆序不存在。每个点一个方程，未知数是 `E[u]`，移项后是线性方程组，用 [高斯消元](高斯消元.md)。n≤100 量级可以消元。n=1e5 的期望几乎总是 DAG、树，或有数学闭式。

概率 DP（`dp[i]` = 到达 i 的概率）和期望 DP 相邻：概率常常正着推，期望常常倒着推。不要把到达概率乘路径长度再求和时漏掉「路径不止一条」——用上面的一步方程更不容易漏。

### 4. 和最短路

| 问 | 做法 |
| --- | --- |
| 最小代价 | Dijkstra / DAG 上的 min |
| 平均代价、等概率出边 | 本篇 |
| 方案数 | 计数 DP，取模 |

同一张 DAG，min 和期望的循环可以长得很像，差在 `min` 还是 `+=` 再除。抄错一个运算符就是另一道题。

## 常见坑 / 注意事项

- **从源点正着循环，E[v] 还是 0。**  
- **出度用 int 除。** `(w+E)/out` 若左边是 int，小数没了。全程 double，或最后再除并保持分数（少见）。  
- **终点 E 设成 1。**  
- **有环仍拓扑。** 拓扑长度不够就说明有环，换方程。  
- **概率和不是 1 仍除掉总出度。** 先读题：有的边概率给定，不是等概率。  
- **无路可达仍输出 0。** 0 和「到不了」要按题面区分。

## 趣味课间：实验室经典翻车集

- **「期望就是最可能的那条。」** 那是众数，不是期望。掷骰子期望 3.5，没有一面是 3.5。  
- **样例是一条链。** 期望等于唯一路径。造一个点分出两条边，一条权 1 一条权 100，期望应是 50.5 而不是 1。  
- **double 输出默认 6 位，题面要 2 位，被判 WA。**  
- **高斯消元用整数模数去解期望。** 题面没说取模就用 double，并选主元。

## 小结

`E[u]` 是出边的平均「一步代价 + 后继期望」。终点为 0。DAG 按拓扑逆序。有环列方程消元。不要写成最短路的 min。
