# 数论入门：gcd、快速幂、质数筛

> 读完你应该能：写出辗转相除和 `lcm`；用快速幂算 `a^b` 和模意义下的幂（注意 `long long` 与取模）；用埃氏筛 / 线性筛在 1e6～1e7 内打出质数表；知道费马小定理求逆元的前提是模数为质数。
>
> 一句口号：**能递归的除法叫 gcd；能二分的乘法叫快速幂；能划掉合数的纸叫筛。**

## 背景 / 为什么要读这篇

[新人指南](../00-团队指南/新人指南.md) 写过：课内高数不等于竞赛数论。区域赛签到里，gcd、快速幂、判质数出现的次数不比 LIS 少。

课内「质数」停在试除；赛时 n=1e7 要筛。课内 `pow` 是浮点；赛时 `a^b mod p` 必须整数快速幂，`pow(2,60)` 已经不是你想的那个整数。

实验室有人 `a*a%mod` 先乘爆 `int`；有人筛写成 `for(j=i;j<=n;j+=i)` 从 i 起漏了倍数或重复划。本篇三块最小工具箱，扩欧、中国剩余、原根以后单开。

## 正文

### 1. gcd 与 lcm

辗转相除：`gcd(a,b) = gcd(b, a%b)`，`gcd(a,0)=a`。

```cpp
long long gcd(long long a, long long b) {
    return b ? gcd(b, a % b) : a;
}
long long lcm(long long a, long long b) {
    return a / gcd(a, b) * b;  // 先除后乘，防溢出
}
```

STL：`std::gcd` / `std::lcm` 在 C++17 `<numeric>`。负号：竞赛里先 `abs`。`lcm` 先 `/gcd` 再 `*`，`a*b/gcd` 可能中间爆。

更相减损也能，慢。扩展欧几里得求 `ax+by=gcd` 的一组整数解，逆元、线性同余用它。入门记住：模数为质数时用费马，模数任意且互质时用扩欧。

**裴蜀定理：** `ax+by` 能凑出的最小正整数是 `gcd(a,b)`。题面「能否凑 k」先看 k 是否为 gcd 的倍数。

### 2. 快速幂

求 `a^b`，b 到 1e18。二进制拆 b：

```cpp
long long qpow(long long a, long long b, long long mod) {
    long long r = 1 % mod;
    a %= mod;
    while (b) {
        if (b & 1) r = (__int128)r * a % mod;
        a = (__int128)a * a % mod;
        b >>= 1;
    }
    return r;
}
```

不用 `__int128` 时：`r = r * a % mod` 必须保证 `r*a` 不爆。`mod=1e9+7`，两边都 `< mod`，乘积 < 1e18+，`long long` 够。`mod` 更大上 `__int128` 或龟速乘。

无模整数幂：b 很小才返回 `long long`，否则溢出。矩阵快速幂是同一骨架，乘法改成矩阵乘，见 [矩阵快速幂](矩阵快速幂.md)。

**逆元（mod 为质数 p）：** 费马 `a^{p-2} ≡ a^{-1} (mod p)`，前提 `gcd(a,p)=1`。`qpow(a, p-2, p)`。`p=1e9+7` 天天见。

```cpp
long long inv(long long a, long long p) { return qpow(a, p - 2, p); }
```

组合数 `n! / k! / (n-k)!` 预处理阶乘和逆元阶乘，O(n + log p)。n=1e6 常规。

### 3. 试除判质 vs 筛

```cpp
bool is_prime(long long x) {
    if (x < 2) return false;
    for (long long i = 2; i * i <= x; i++)
        if (x % i == 0) return false;
    return true;
}
```

`i*i` 用 `long long`，`i <= sqrt(x)` 浮点会哭。单个 x ≤ 1e12 试除够；很多次查询或要全部质数，筛。

**埃氏筛：** 每个质数划掉它的倍数。

```cpp
vector<int> primes;
vector<char> vis;  // 1 表示合数

void eratosthenes(int n) {
    vis.assign(n + 1, 0);
    vis[0] = vis[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (vis[i]) continue;
        primes.push_back(i);
        if ((long long)i * i > n) continue;
        for (int j = i * i; j <= n; j += i) vis[j] = 1;  // 从 i*i 起
    }
}
```

从 `i*i` 起：更小的倍数已被更小质数划过。O(n log log n)。n=1e7 可过。

**线性筛（欧拉筛）：** 每个合数只被最小质因子划一次，O(n)。

```cpp
void linear_sieve(int n) {
    vis.assign(n + 1, 0);
    for (int i = 2; i <= n; i++) {
        if (!vis[i]) primes.push_back(i);
        for (int p : primes) {
            if ((long long)i * p > n) break;
            vis[i * p] = 1;
            if (i % p == 0) break;  // p 是 i 的最小质因子，后面不划
        }
    }
}
```

线性筛顺便求欧拉函数、最小质因子 `mindiv[i*p]=p`。入门先埃氏，写对再换线性。两者质数表一样。

### 4. 三块怎么拼进题

| 题面 | 工具 |
| --- | --- |
| 最大公约、能否整除线性组合 | gcd / 裴蜀 |
| a^b mod p、逆元、快速乘方 | qpow |
| 1..n 质数、质因子分解多次 | 筛 + 最小质因子 |
| 单次大数是否质 | 试除或 Miller-Rabin（进阶） |

分解 n：有筛时用 `mindiv` 一路除；单次 n 对 `i*i<=n` 试除。不要每次分解都筛到 1e7。

### 5. 复杂度速查

| 算法 | 复杂度 |
| --- | --- |
| gcd | O(log min(a,b)) |
| 快速幂 | O(log b) 次乘 |
| 埃氏筛 | O(n log log n) |
| 线性筛 | O(n) |
| 试除判质 | O(√x) |

## 常见坑 / 注意事项

- **`a*a%mod` 用 `int`。** 先乘后模，中间爆成负数。
- **`lcm` 先乘后除。**
- **`pow(a,b)` 浮点。**
- **筛 `j=i; j<=n; j+=i` 且 i=2 时把 2 划掉。** 从 `i*i` 起，或 `j=i+i`。
- **`vis[1]` 当质数。** 1 不是质数。
- **费马逆元模数合数。** 错。
- **`b=0` 快速幂应返回 1（mod 意义 `1%mod`）。** `0^0` 竞赛常当 1。
- **线性筛漏 `i%p==0` 的 break。** 失去线性，仍正确但慢、或 mindiv 错。

## 趣味课间：实验室经典翻车集

- **「我用 Python 幂。」** ICPC 现场 C++。`qpow` 十五行，背下来。
- **样例 n=10 的筛。** 写错从 i 起划掉 i 自己，2 不是质数了。看 `primes[0]` 是不是 2。
- **`__int128` 评测机拒。** 少数老 OJ。改手写快乘或保证模数平方进 long long。
- **组合数每问一次阶乘。** 预处理。
- **gcd 递归深度。** 最坏 Fibonacci，log 级别，没事。

## 小结

gcd 辗转相除，lcm 先除后乘。快速幂拆二进制，乘用 long long / int128，质数模下 `a^{p-2}` 是逆元。1..n 的质数用筛，单个大数用试除。下一步：[扩展欧几里得](扩展欧几里得.md)。递推加速：[矩阵快速幂](矩阵快速幂.md)。
