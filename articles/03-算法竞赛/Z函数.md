# Z 函数：整串和每个后缀的最长公共前缀

> 读完你应该能：写出 `z[i]` 的定义；用「已匹配到的最右段」线性求出 Z 盒；用 `模式 + 分隔符 + 文本` 做匹配；分清它和 [KMP](KMP.md) 的 `pi`、[后缀数组](后缀数组.md) 的 `height` 各管哪一段。
>
> 一句口号：**`z[i]` 是 `s[i..]` 和 `s` 本身比，能对上的最长前缀。**

## 背景 / 为什么要读这篇

[KMP](KMP.md) 的 `pi[i]` 是前缀 `s[0..i]` 的最长 border（既是前缀又是后缀）。Z 函数问的是另一句：从位置 i 开始的后缀，和**整个串的前缀**能对多长。模式匹配、周期、最小表示的一些写法，用 Z 盒比用 border 更直。

实验室有人把 `z[i]` 当成和前一个字符的 LCP；有人最右段更新时 `r` 用了开区间却按闭区间 `min`。本篇按闭区间 `[l,r]` 写。

## 正文

### 1. 定义

`z[0]` 通常定为 0（和自己比没有意义，或有人定成 n，查询时不要用 `z[0]`）。对 `i>0`：

```text
z[i] = max { k | s[0..k-1] == s[i..i+k-1] }
```

`aaaa` 的 z 大约是 `[0,3,2,1]`。`aaabaac` 在 i=4（`a`）能对上 `aa`，再下去 `b` 对 `a` 失败。

### 2. 线性求

维护当前最右的匹配段 `[l,r]`，满足 `r` 最大且 `s[l..r] == s[0..r-l]`。于是 `s[i..r]` 等于 `s[i-l..r-l]`，`z[i]` 至少是 `min(z[i-l], r-i+1)`，然后再暴力向右扩。扩过 `r` 就更新 `l,r`。

```cpp
vector<int> z_function(const string& s) {
    int n = (int)s.size();
    vector<int> z(n);
    for (int i = 1, l = 0, r = 0; i < n; i++) {
        if (i <= r) z[i] = min(r - i + 1, z[i - l]);
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) z[i]++;
        if (i + z[i] - 1 > r) {
            l = i;
            r = i + z[i] - 1;
        }
    }
    return z;
}
```

每个位置的 `while` 成功次数摊到 `r` 的右移上，总和 O(n)。初值如果已经大于真实 LCP，`while` 不会帮你缩小——所以 `min(r-i+1, z[i-l])` 不能写成只抄 `z[i-l]`。

### 3. 匹配

模式 `p`，文本 `t`。构造 `p + '#' + t`，`'#'` 不出现在两边。若某个 `z[i] == p.size()`，且 `i` 落在文本区（`i > p.size()`），则文本在 `i - p.size() - 1` 处出现模式。

这和 KMP 一样能做匹配。KMP 一边读文本一边跳；Z 函数先把拼接串扫完。多个模式不要各拼一次，那是 [AC 自动机](AC自动机入门.md)。

周期：若 `i + z[i] == n` 且 `n % i == 0`，则 `i` 是一个周期。用小串 `abcabcabc` 对一下再当定理用。

## 常见坑 / 注意事项

- **`z[0]` 拿去当 n。** 本篇约定是 0。  
- **`r` 当开区间，`min` 却用 `r-i+1`。** 和代码里的闭区间对齐。  
- **分隔符出现在模式里。**  
- **匹配下标忘了减掉 `p.size()+1`。**  
- **`while` 用 `s[z[i]]` 和 `s[i+z[i]]` 写反。** 左边是前缀的下一位。  
- **最右段不更新，退化成 O(n²) 还以为是 Z。**

## 趣味课间：实验室经典翻车集

- **「Z 和 KMP 输出同一个数组。」** `aaaa` 上 `pi` 是 `[0,1,2,3]`，`z` 是 `[0,3,2,1]`。一个往前看 border，一个和整串前缀比。  
- **样例模式在文本开头。** 任何下标公式碰巧对。把模式放在文本中间再算 `i`。  
- **和后缀数组的 height 对拍 LCP。** height 是相邻后缀；Z 只和**起点为 0 的前缀**比。  
- **n=1e6 用二重循环填 z。** 最右段就是为了避免这个。

## 小结

`z[i]` 是后缀 i 和整串的 LCP。最右匹配段给出下界，再向右试。模式匹配用分隔符拼接。border 仍读 KMP，全部后缀的 LCP 仍读后缀数组。
