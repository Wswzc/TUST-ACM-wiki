# 扩展欧几里得：ax + by = gcd 的一组整数解

> 读完你应该能：写出 `exgcd` 求出 `ax + by = gcd(a,b)` 的一组 `(x,y)`；用它解线性同余 `ax ≡ c (mod m)`；在模数不一定是质数时求乘法逆元；知道无解当且仅当 gcd 不整除 c。
>
> 一句口号：**普通 gcd 只问最大公因数；扩欧把「辗转相除的每一步」记下来，倒着凑出系数。**

## 背景 / 为什么要读这篇

[数论入门](数论入门.md) 用费马小定理求逆元，前提是模数为质数。题面 `mod = 1e9+6` 或任意 m、只保证 `gcd(a,m)=1` 时，费马会错。扩欧不在乎 m 是否质数。

裴蜀定理说过：`ax+by` 能表示的就是 gcd 的倍数。扩欧给出**一组具体系数**，其余解有通项。

实验室有人递归回来 `x,y` 写反；有人有解却输出了未模到最小正剩余。本篇把递归那两行讲成人话。

## 正文

### 1. 倒推系数

`gcd(a,b) = gcd(b, a%b)`。若已有

```text
b * x1 + (a%b) * y1 = g
```

而 `a%b = a - (a/b)*b`，代入：

```text
a * y1 + b * (x1 - (a/b)*y1) = g
```

于是 `x = y1`，`y = x1 - (a/b)*y1`。边界 `b=0` 时 `g=a`，`x=1`，`y=0`（`a*1 + b*0 = a`）。

```cpp
long long exgcd(long long a, long long b, long long& x, long long& y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}
```

返回 g，同时写入 x、y。`a`、`b` 先取绝对值或保证非负，负号自己往系数上乘。竞赛输入若为负，先规范化。

手算 `a=14, b=10`：`gcd=2`，一组解 `14*(-2)+10*3=2`。程序应给出某组，不一定是最小正 x。

### 2. 通项

一组特解 `(x0,y0)` 后，

```text
x = x0 + (b/g)*t
y = y0 - (a/g)*t
```

t 为任意整数。要最小非负 x：对 `b/g` 取模，注意负数。

```cpp
void shift_x_nonneg(long long& x, long long& y, long long a, long long b, long long g) {
    long long dx = b / g, dy = a / g;
    long long t = (x % dx + dx) % dx;  // 先把 x 调到 [0, dx)
    long long k = (t - x) / dx;
    x += k * dx;
    y -= k * dy;
}
```

按题面要 x 最小正、或 |x|+|y| 最小，在通项上调 t。

### 3. 线性同余 ax ≡ c (mod m)

即 `ax - my = c`，`ax + m*(-y) = c`。令 `g=gcd(a,m)`：

- `g` 不整除 c → 无解  
- 否则有 g 组模 m 的解（模 `m/g` 下唯一）

```cpp
bool solve_congruence(long long a, long long c, long long m,
                      long long& x, long long& mod) {
    long long y, g = exgcd(a, m, x, y);
    if (c % g) return false;
    x = (x * (c / g)) % m;  // 特解放大 c/g；注意溢出用 int128
    mod = m / g;            // 通解模
    x %= mod;
    if (x < 0) x += mod;
    return true;
}
```

`x * (c/g)` 可能爆 `long long`，`a,m ~ 1e18` 时用 `__int128`。

### 4. 乘法逆元

`ax ≡ 1 (mod m)` 有解 ⇔ `gcd(a,m)=1`。扩欧求出 x，再模到 `[0,m)`。

```cpp
long long inv_exgcd(long long a, long long m) {
    long long x, y;
    long long g = exgcd(a, m, x, y);
    if (g != 1) return -1;  // 无逆元
    x %= m;
    if (x < 0) x += m;
    return x;
}
```

和费马对照：

| 条件 | 方法 |
| --- | --- |
| m 质数 | `qpow(a,m-2,m)` 或扩欧 |
| m 合数且 gcd(a,m)=1 | **只能扩欧**（或欧拉定理 φ(m)，要先求 φ） |
| gcd≠1 | 无逆元 |

欧拉定理 `a^{φ(m)}≡1` 也能幂，但求 φ 要分解 m。扩欧更直接。

### 5. 和普通 gcd、CRT

普通 `gcd` 是扩欧扔掉 x、y。CRT（中国剩余定理）把多个同余方程联立，每一步常调用扩欧求逆。本篇不展开 CRT，会 `ax≡c` 后再去看。

## 常见坑 / 注意事项

- **`x = y1` 与 `y = x1 - (a/b)*y1` 写反。**
- **`a/b` 写成浮点。** 整数除法。
- **无解仍输出 x。** 先判 `c%g`。
- **逆元返回负数。** 加 m。
- **`x * (c/g)` 溢出。**
- **费马套合数模。**
- **`b=0` 时 y 未赋值。** 边界写 `y=0`。

## 趣味课间：实验室经典翻车集

- **「扩欧就是 gcd 多两个参数。」** 是的。不会倒推就画 `14,10,4,2,0` 那列余数，从下往上填 x、y。
- **样例只要 gcd。** 你的 x、y 测 `a*x+b*y==g` 才算过。
- **最小正 x 用 `while(x<0) x+=b`。** g≠1 时步长是 `b/g` 不是 b，死循环或跳过解。
- **Python 的 `pow(a,-1,m)`。** 现场 C++，扩欧十五行。

## 小结

递归 gcd，回来时 `x=y1, y=x1-(a/b)*y1`。同余有解 iff g|c。逆元在 gcd=1 时就是 `ax≡1`。模数非质数不要费马。
