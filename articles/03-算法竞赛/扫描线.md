# 扫描线：从左往右，只保留竖着的那一刀

> 读完你应该能：把矩形并面积拆成「从左到右的竖线事件」；用 [离散化](离散化.md) 压 y 坐标；用线段树维护「当前被覆盖的 y 长度」；知道事件要按 x 排序，并且同一 x 上先加后减还是先减后加取决于你是否把边界算进面积。
>
> 一句口号：**二维的并，扫成一维的覆盖长度，再乘上两根竖线之间的宽度。**

## 背景 / 为什么要读这篇

若干矩形可能重叠，求并的面积。逐对切割是 O(n²) 还容易漏。扫描线把 x 方向看成时间：遇到矩形的左边，这段 y 的覆盖 +1；遇到右边，覆盖 -1。两根事件竖线之间，覆盖长度不变，面积加上 `长度 × 宽度`。

实验室有人事件按 x 排了，同一 x 的右边界先删掉，竖线宽度为 0 的那一刀把面积剪掉；有人线段树建在点上而不是「相邻离散 y 之间的段」上，长度永远差一截。本篇按「段」来建树。

## 正文

### 1. 事件

矩形 `[x1,x2) × [y1,y2)`。两条事件：

| x | 类型 | y 区间 |
| --- | --- | --- |
| x1 | +1 | [y1, y2) |
| x2 | -1 | [y1, y2) |

所有 x 排序。`x` 相同：先处理 +1 再处理 -1，这样贴边的矩形不会在同一竖线上先被拆开。若坐标系是闭区间，先想清楚边是否面积为 0——竖线本身没有宽度，关键是**相邻两个不同的 x 之间**才累加面积。

### 2. 离散化的是段，不是点

把所有 y 排序去重，得到 `ys[0..m-1]`。线段树的叶子 i 表示纵坐标区间 `[ys[i], ys[i+1])`，长度 `ys[i+1]-ys[i]`。树上共 `m-1` 段。

不要把叶子当成一个 y 点。点没有长度。

### 3. 线段树维护覆盖长度

结点存 `cover`（被完整覆盖的次数）和 `len`（这个结点代表的 y 方向上、当前覆盖次数 >0 的总长度）。

```cpp
struct Seg {
    vector<long long> ys;
    vector<int> cover;
    vector<long long> len;
    explicit Seg(vector<long long> y) : ys(std::move(y)) {
        int n = max(1, (int)ys.size() - 1);
        cover.assign(n * 4 + 5, 0);
        len.assign(n * 4 + 5, 0);
    }
    void pull(int p, int l, int r) {
        if (cover[p]) len[p] = ys[r] - ys[l];
        else if (r - l == 1) len[p] = 0;
        else len[p] = len[p << 1] + len[p << 1 | 1];
    }
    void upd(int p, int l, int r, int ql, int qr, int v) {
        if (ql >= qr) return;
        if (ql <= l && r <= qr) {
            cover[p] += v;
            pull(p, l, r);
            return;
        }
        int m = (l + r) >> 1;
        if (ql < m) upd(p << 1, l, m, ql, qr, v);
        if (qr > m) upd(p << 1 | 1, m, r, ql, qr, v);
        pull(p, l, r);
    }
};
```

`upd` 的区间是离散后的下标 `[ql, qr)`，对应 `ys` 里的一段。`cover>0` 时整段长度都算，不必下传标记——因为我们只问根的 `len`，不下放到「部分覆盖的叶子值」以外的查询。这是扫描线线段树和普通区间加的差别：标记可以不下推，`pull` 时优先看自己的 `cover`。

### 4. 扫

```cpp
struct Ev { long long x; int y1, y2, d; };
// y1, y2 已是离散下标，区间 [y1, y2)
sort(ev.begin(), ev.end(), [](const Ev& a, const Ev& b) {
    if (a.x != b.x) return a.x < b.x;
    return a.d > b.d;  // +1 先于 -1
});
long long area = 0, prev = ev[0].x;
int leaves = (int)ys.size() - 1;
for (auto& e : ev) {
    area += seg.len[1] * (e.x - prev);
    seg.upd(1, 0, leaves, e.y1, e.y2, e.d);
    prev = e.x;
}
```

`len[1]` 是根。第一刀之前长度为 0，乘出来是 0。

矩形边从闭区间改成半开：`x2` 是右边界事件，y 的 `upper_bound` 要和建树一致。建议全部先变成半开区间再离散，避免「点在不在段里」来回改。

## 常见坑 / 注意事项

- **叶子是点不是段。** `m` 个坐标只有 `m-1` 段。  
- **同一 x 先减后加。** 贴边面积丢或重。  
- **`cover` 加在部分区间上却用整段 `ys[r]-ys[l]`。** 只有结点被查询完全覆盖时才能这样；代码里 `ql<=l && r<=qr` 才 `cover+=v`。  
- **忘了 `pull`。** 根的 `len` 是旧的。  
- **y 用 double 离散还去重失败。** 几何题先读精度要求；整数坐标用 `long long`。  
- **面积用 int。** 坐标 1e9，两个矩形就能爆。

## 趣味课间：实验室经典翻车集

- **「扫描线就是排序。」** 排序只决定竖线顺序。面积在线段树的长度里。  
- **两个不相交矩形样例。** 覆盖次数永远是 0 或 1，测不出 `cover` 叠加。造一个完全包含另一个。  
- **离散化用 `lower_bound` 得到点号，直接当叶子长度。** 相邻点相减才是长度。  
- **把这棵线段树拿去写区间赋值。** 标记语义不同，不要和 [线段树入门](线段树入门.md) 的懒标记混成一份代码。

## 小结

事件是矩形左右边。y 离散成段。线段树记覆盖次数和被盖住的长度。竖线之间用长度乘宽度。同一 x 先加后减。

建议练习：

- 洛谷 [P5490 【模板】扫描线](https://www.luogu.com.cn/problem/P5490)
- 一个矩形手算：只有 +1 和 -1，面积应等于宽×高  
- 两个重叠矩形，对拍「面积相加再减交」
