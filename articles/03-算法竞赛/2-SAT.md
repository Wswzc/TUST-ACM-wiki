# 2-SAT：两个选项的约束，交给 SCC

> 读完你应该能：把「A 或 B 至少成立」建成蕴含图；用 [强连通分量](强连通分量.md) 判断有没有解；在有解时从 SCC 编号读出一组赋值；认出 3-SAT 不是同一套（那是 NPC，竞赛里别硬 Tarjan）。
>
> 一句口号：**每条子句两个文字；建边「若不是这个，就必须是那个」；x 和 ¬x 进了同一块 SCC，就无解。**

## 背景 / 为什么要读这篇

SAT：一堆布尔变量，一堆「或」起来的子句，问能否同时满足。[DFS 回溯](DFS回溯.md) 能搜，指数爆炸。子句里**恰好两个文字**时叫 2-SAT，有多项式算法。

区域赛包装成：n 对夫妻只去一个、两条路选一条、灯开或关、第 i 个位置放 A 或放 B。约束长得像「不能两个都真 / 至少一个真」。实验室有人把 3 个选项硬塞进 2-SAT；有人建了边却用并查集判，把单向蕴含当成对称。引擎是 SCC，本篇只讲建图和读答案。

## 正文

### 1. 文字、子句、蕴含

变量 `x0, x1, ..., x_{n-1}`。文字：`xi` 或 `¬xi`。

子句 `(a ∨ b)` 的意思：a、b 至少一个真。逻辑等价：

```text
¬a → b
¬b → a
```

「若 a 假，则 b 必须真」。每条蕴含是有向边。整张图叫**蕴含图**。

每个变量拆成两个点：`xi` 与 `¬xi`。常用编号：`2*i` 表示 `xi`，`2*i+1` 表示 `¬xi`。于是 `p ^ 1` 就是 p 的反文字。

```cpp
int pos(int i) { return i << 1; }      // xi
int neg(int i) { return i << 1 | 1; }  // ¬xi
void add_imp(int a, int b) { g[a].push_back(b); }  // a → b
void add_or(int a, int b) {            // (a ∨ b)
    add_imp(a ^ 1, b);
    add_imp(b ^ 1, a);
}
```

常见约束翻译（a、b 已经是文字编号，带反用 `^1`）：

| 人话 | 建边 |
| --- | --- |
| a、b 至少一个真 | `add_or(a, b)` |
| a 真 | `add_or(a, a)`，即 `¬a → a` |
| a 假 | `add_or(a^1, a^1)` |
| a、b 不能都真 | 等价 `(¬a ∨ ¬b)` → `add_or(a^1, b^1)` |
| a 真则 b 真 | 直接 `add_imp(a, b)`，再补不补对称看题；通常还要 `(¬b → ¬a)` 已由逆否包含在「若只加这一条」里——**蕴含只要这一条**，逆否是同一件事，不要加反边当无向图 |

只加 `a → b` 时，逻辑上已含逆否 `¬b → ¬a`。漏写逆否边会错。`add_or` 的两条正好是一对逆否。自己加单条蕴含时，把逆否也加上最省心：

```cpp
void add_imp_both(int a, int b) {
    add_imp(a, b);
    add_imp(b ^ 1, a ^ 1);  // 逆否
}
```

### 2. 有解：x 与 ¬x 不在同一 SCC

在蕴含图上跑 Tarjan（模板见 [强连通分量](强连通分量.md)）。

若某个 i 满足 `scc[pos(i)] == scc[neg(i)]`：从 `xi` 能推到 `¬xi` 且反过来也能，矛盾，**无解**。

否则有解。赋值：在缩点 DAG 上，同一分量里的文字必须同真同假（能互相推到）。`xi` 与 `¬xi` 分属两块，只能选「拓扑序上更靠后 / 更靠前」的那一块为真——两套编号约定相反，**必须和自己的 Tarjan 弹栈编号一致**。

本库 SCC 文的编号：弹出时 `++scc_cnt`，**先弹出的分量 id 更小**，先弹出的是汇点。蕴含边在缩点图上从 id 大指向 id 小。若 `¬x` 能走到 `x`，则必须 `x` 为真。于是：

```cpp
bool two_sat(int n) {
    int m = n * 2;
    ts = scc_cnt = 0;
    stk.clear();
    fill(dfn, dfn + m, 0);
    for (int i = 0; i < m; i++)
        if (!dfn[i]) tarjan(i);
    for (int i = 0; i < n; i++)
        if (scc[pos(i)] == scc[neg(i)]) return false;
    for (int i = 0; i < n; i++)
        val[i] = scc[pos(i)] < scc[neg(i)];  // 与「先弹 id 小」配套
    return true;
}
```

网上模板若写 `scc[x] > scc[¬x]` 为真，那是 **id 编号相反** 的 Tarjan。抄编号时连赋值一起抄，不要混。用 n=1、强制 `x` 为真的图对一下：边 `¬x → x`，应得到 `val[0]=true`。

### 3. 什么时候不是 2-SAT

| 形态 | 做法 |
| --- | --- |
| 每条约束两个选项 | 2-SAT |
| 三个选项「至少一个」 | 3-SAT，指数；n 小搜，或换建模 |
| 线性不等式、最大权 | 可能费用流 / 最大权闭合子图，不是 SCC |
| 无向图连通 | 并查集 |

看见「选 A 或选 B」先数每个约束涉及几个变量。两个，建图；三个，停手想。

## 常见坑 / 注意事项

- **文字编号和 `^1` 用乱。** 变量从 1 编号时不要和 `2*i` 混。  
- **只建 `a → b` 忘逆否。**  
- **赋值比较符和 SCC 编号不配套。** 用强制真的单变量测。  
- **3 个文字的子句拆成两次 2-SAT。** 不等价。  
- **多组数据 `g`、`dfn` 没清。** 点数是 `2n`。  
- **无解仍输出方案。** 先判 `scc` 相等。

## 趣味课间：实验室经典翻车集

- **「SAT 不就是爆搜吗。」** 2 和 3 差一个字母，复杂度差一个 NPC。  
- **样例全是「x 必须为真」。** 测不出逆否漏边。造 `(x ∨ y)` 且 `x` 假，看 y 会不会被迫真。  
- **并查集把 `x` 和 `¬x` 分到两集。** 蕴含不是等价，单向到不了的可以各真各假。  
- **输出 `val` 用 `scc[i]` 而不是 `scc[pos(i)]`。** 点号和变量号差一倍。

## 小结

`(a ∨ b)` → `¬a → b` 与 `¬b → a`。Tarjan 后 `x` 与 `¬x` 同分量则无解。赋值比较 SCC 编号，必须和弹栈顺序配套。先会 SCC 再写本篇。

建议练习：

- 洛谷 [P4782 【模板】2-SAT](https://www.luogu.com.cn/problem/P4782)
- 把「n=1，x 必须真」手跑 SCC 编号，对照 `val`  
- 找一道「两人一组只去一个」的建图题，先在纸上写文字再写边
