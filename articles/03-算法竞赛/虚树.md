# 虚树：只把关键点和它们的 LCA 留下

> 读完你应该能：按 DFS 序排序关键点，用栈和 LCA 拼出一棵只有 O(k) 个点的树；在这棵树上做树形 DP，而不是每次在整棵 n 个点的树上跑；说清虚边上的权一般是原树两点的距离或边权。
>
> 一句口号：**关键点之间的路径会经过它们的 LCA。把这些分叉点补上，其余的链缩成一条边。**

## 背景 / 为什么要读这篇

[LCA 倍增](LCA倍增.md) 能回答两点。题若给一棵 n=1e5 的树，再给 q 组、每组 k 个关键点，问关键点之间的某种路径代价，每组都 DFS 整棵树是 O(nq)。同一组里真正改变形状的，是关键点和它们两两 LCA。这些点只有 O(k) 个。虚树就是只保留它们的一棵树。

实验室有人按编号排序而不是按 `dfn`；有人栈里弹出时连错父亲；有人虚树边权忘了用原树距离，DP 全是 0。本篇只建树。

## 正文

### 1. 点集

一组关键点 `h[1..k]`。虚树的点集 = 关键点 + 它们在原树上作为分叉的 LCA。只加关键点、不加 LCA，链会接错父。

先有原树的 `dfn` 和 `lca(u,v)`（倍增或欧拉序 + RMQ 都行）。复杂度每组 O(k log n)，加上排序。

### 2. 栈

按 `dfn` 从小到大处理。栈里是当前虚树最右链上、还没确定右儿子的点，从根到当前，`dfn` 递增。

```cpp
vector<int> gvt[N];  // 用完要按点清空，不要 memset 全图
int st[N], top;

void add_edge(int u, int v) {
    if (u == v) return;
    gvt[u].push_back(v);
}

void build(vector<int> nodes) {
    sort(nodes.begin(), nodes.end(), [](int a, int b) {
        return dfn[a] < dfn[b];
    });
    nodes.erase(unique(nodes.begin(), nodes.end()), nodes.end());
    top = 0;
    st[++top] = nodes[0];
    for (int i = 1; i < (int)nodes.size(); i++) {
        int x = nodes[i];
        int w = lca(st[top], x);
        while (top >= 2 && dfn[st[top - 1]] >= dfn[w]) {
            add_edge(st[top - 1], st[top]);
            top--;
        }
        if (st[top] != w) {
            add_edge(w, st[top]);
            top--;
            st[++top] = w;
        }
        st[++top] = x;
    }
    while (top >= 2) {
        add_edge(st[top - 1], st[top]);
        top--;
    }
}
```

`w` 可能是新出现的 LCA，要插进栈。最后栈里剩下的点连成一条链，栈底是这棵虚树的根（不一定是原树的 1，除非 1 在点集里或是某个 LCA）。

若题目要求虚树包含原根 1：把 1 放进 `nodes` 再 build。

### 3. 边权与 DP

虚边 `u→v` 代表原树上 u 到 v 的那条链被压缩了。边权用 `dep[v]-dep[u]`（边权为 1）或预处理的距离。然后在虚树上跑 [树形 DP](树形DP.md)。DP 结束后，**只清空出现过的点的邻接表**，把这些点收进一个 vector。`memset` 全部 `gvt` 会 TLE。

总复杂度：若 Σk = O(n)，总时间 O(n log n)。这就是虚树能过、每组全树 DFS 不能过的原因。

### 4. 什么时候不用

关键点是全部点：虚树就是原树，白建。只有一次询问：直接 DFS。要带修改的路径和：[树链剖分](树链剖分入门.md)，不是虚树。

## 常见坑 / 注意事项

- **按点编号而不是 `dfn` 排序。** 栈的链条件全废。  
- **LCA 没有插进点集。**  
- **建完不清邻接表，下一组串边。**  
- **`add_edge` 在 `u==v` 时自成环。**  
- **距离用虚树上的边数，不是原树深度差。** 压缩过的链不止一条原边。  
- **栈空还取顶。** `nodes` 为空要直接返回。

## 趣味课间：实验室经典翻车集

- **「虚树是想象出来的，不用 LCA。」** 分叉点就是 LCA。不会 LCA 就先回去。  
- **样例关键点是整棵树的叶子且 k=2。** 虚树往往是两点加一个 LCA 的三条边里的两条。再加一个点才会分叉。  
- **每组 `vector<int> gvt[N]` 重新定义在函数里。** 栈爆炸。全局数组，按点清空。  
- **和点分治一起用，重心还在原树上找。** 虚树是询问的压缩，点分治是整树的分治，不要嵌套到自己也不知道根是谁。

## 小结

关键点按 DFS 序进栈，用 LCA 把右链收成虚边。点数 O(k)。边权是原树距离。清空只清用过的点。先会 LCA，再建虚树。

建议练习：

- 洛谷 [P2495 [SDOI2011] 消耗战](https://www.luogu.com.cn/problem/P2495)
- 三个点的链，关键点取两个端点，手画虚树应是两端加中间 LCA  
- 建完后 DFS 虚树点数，确认 ≤ 2k
