# 可撤销并查集：不合路径压缩，操作用栈记下来

> 读完你应该能：写出只按大小合并、不路径压缩的 `find`；每次合并把「谁认了谁、大小的旧值」压栈；`undo` 时弹栈恢复；说明它为什么能配时间分治，而普通路径压缩的 [并查集](并查集.md) 撤不干净。
>
> 一句口号：**父亲只改一个，大小只改一个。改之前记下来，撤销就是写回去。**

## 背景 / 为什么要读这篇

普通并查集路径压缩会把一整条链的父亲改掉，你并不知道改了哪些点，无法在删掉一条「后来加上的边」时恢复。边会按时间消失、或者在线段树的时间区间上存在时，需要撤销。做法是放弃路径压缩，只用按大小（或按秩）合并，把修改记在栈里。

实验室有人 `undo` 只改 `fa` 不改 `sz`，下一次启发式合并方向反了，复杂度退化成链；有人撤销时又 `find` 了一次，压缩把栈里的旧父亲弄脏。本篇 `find` 是纯循环，不写 `fa[x]`。

## 正文

### 1. 合并与撤销

```cpp
struct Op {
    int x, y, sx;  // fa[y] 被接到 x，x 的旧大小是 sx；x==-1 表示当时已经同根
};
vector<Op> st;
int fa[N], sz[N];

int find(int x) {
    while (fa[x] != x) x = fa[x];
    return x;
}

void init(int n) {
    st.clear();
    for (int i = 1; i <= n; i++) fa[i] = i, sz[i] = 1;
}

bool unite(int a, int b) {
    a = find(a);
    b = find(b);
    if (a == b) {
        st.push_back({-1, -1, 0});
        return false;
    }
    if (sz[a] < sz[b]) swap(a, b);
    st.push_back({a, b, sz[a]});
    fa[b] = a;
    sz[a] += sz[b];
    return true;
}

void undo() {
    Op t = st.back();
    st.pop_back();
    if (t.x == -1) return;
    fa[t.y] = t.y;
    sz[t.x] = t.sx;
}
```

同根的合并也要压一条空操作。这样「一段里调用了 k 次 `unite`」就对应 k 次 `undo`，调用方不用区分这次有没有真的连上。

`find` 是 O(log n)，因为按大小合并后树高是对数。一旦在 `find` 里写 `fa[x]=find(fa[x])`，撤销就错了。

### 2. 用在哪里

按时间的边：每条边在一段时间区间内存活。把时间轴建成线段树，边挂到覆盖它存活区间的 O(log T) 个结点上。DFS 线段树：进入结点就把这里的边 `unite`，递归左右儿子，回答完全落在该结点时间范围内的询问，离开时按入栈次数 `undo`。

这就是「线段树分治 + 可撤销并查集」。询问若是「此刻是否连通」，在叶子（或该时间点）上 `find` 即可。本篇先把栈写对；线段树每个结点一个 `vector` 存边，进入时合并、离开时撤销同样多次。

不能撤销的还有路径压缩以外的东西：带权并查集若压缩时改了权，也要改成不压缩、并把权的旧值放进 `Op`。先会无权版本。

### 3. 和删除边

真正任意删一条旧边，可撤销并查集并不擅长——撤销只能按**后进先出**。时间分治满足这个顺序：后挂上的边先撤销。若删除顺序乱，换离线或别的结构，不要在栈上跳着弹。

## 常见坑 / 注意事项

- **`find` 里压缩。**  
- **`undo` 恢复大小时用了 `sz[x]-sz[y]`，但 y 的大小后来又变过。** 栈里存的是旧的 `sz[x]`，原样写回。  
- **同根不压栈，撤销次数对不上。**  
- **`swap(a,b)` 之后栈里记反。** 先 swap 再记「b 接到 a」。  
- **多测栈残留。** `init` 里 `st.clear()`。  
- **递归撤销放在递归之前。** 应在子调用返回之后撤销，和入栈配对。

## 趣味课间：实验室经典翻车集

- **「按秩合并已经能撤销。」** 按秩只保证树高。撤销靠的是你把修改记下来了。  
- **样例只有合并没有撤销。** 和普通并查集一样。加「合并、询问、撤销、再询问」。  
- **空操作用 `pop` 时访问 `fa[-1]`。** 先判断 `x==-1`。  
- **时间分治里一条边挂到线段树后，在叶子上又合并一次。** 边只挂覆盖结点，不要沿途每个孩子再挂。

## 小结

不压缩，按大小合并。每次 `unite` 压栈，空合并也压。`undo` 写回父亲和旧大小。撤销顺序是栈序，配时间上的进入和离开。路径压缩的那份模板继续留给静态题。

建议练习：

- 手写三次 `unite`、两次 `undo`，看根和大小是否回到第二次合并之后  
- 洛谷上搜「可撤销并查集」或线段树分治模板，先只做「加边、撤销、询问连通」  
- 故意打开路径压缩，构造一条撤销后 `find` 仍指向旧根的数据
