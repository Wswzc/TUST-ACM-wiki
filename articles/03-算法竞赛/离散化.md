# 离散化：把 1e9 的值域收成 1..n

> 读完你应该能：对一批坐标 / 权值 `sort` + `unique`，再用 `lower_bound` 映射回 1..m；解释为什么树状数组不能开 `c[1000000000]`；知道「值相同要不要并成一个编号」取决于题目。
>
> 一句口号：**下标只关心相对大小。真正的数字太大，就先排个名次。**

## 背景 / 为什么要读这篇

[树状数组](树状数组.md) 的下标要从 1 开到「值域」。逆序对里 `a[i]` 可以到 1e9，`c[1e9]` 既没内存也没时间。[线段树](线段树入门.md)、[主席树](主席树.md) 同样：叶子按权值开，必须先把权值压到 O(n)。

[map](../01-编程语言/map与set.md) 能当动态离散化，常数大、代码短。静态先读完所有数，一次 `sort`/`unique` 更干净。实验室有人 `unique` 之后还用原来的 `n` 当值域；有人 `lower_bound` 减 `begin()` 得到 0-based，BIT 却从 1 开始，`add(0)` 死循环。本篇把这几行钉死。

## 正文

### 1. 名次，不是原数

数组 `a[1..n]`，只关心谁比谁大。把出现过的值排序去重，得到 `b[1..m]`。原值 `x` 的名次 = `x` 在 `b` 里的位置。

```cpp
vector<int> b = a;  // 下标 1..n 时先把 a[1]..a[n] 拷出来
sort(b.begin() + 1, b.end());  // 若 0-based 则整个 sort
b.erase(unique(b.begin() + 1, b.end()), b.end());
int m = (int)b.size() - 1;  // 1-based 去重后的个数

int id(int x) {
    return (int)(lower_bound(b.begin() + 1, b.end(), x) - b.begin());
}
```

0-based 更短：

```cpp
vector<int> b = a;
sort(b.begin(), b.end());
b.erase(unique(b.begin(), b.end()), b.end());
auto id = [&](int x) {
    return (int)(lower_bound(b.begin(), b.end(), x) - b.begin()) + 1;  // +1 给 BIT
};
```

`unique` 把相邻相同挤到前面，返回新逻辑末尾。必须先 `sort`。`erase` 把尾巴扔掉，否则 `size()` 仍是 n。

### 2. 什么时候不要去重

通常去重：权值线段树、值域 BIT，相同值同一叶子。

不要去重：需要「第 k 次出现」或每个元素单独占一个点——少见。两数相等在逆序对里不算逆序，去重后仍是同一名次，`add` 的顺序要先查再加（或严格 `<`）。

询问里的数也可能不在原数组：把询问值一并推进 `b` 再离散。主席树静态第 k 小一般只离散原数组。

### 3. 和 map 怎么选

| 做法 | 何时 |
| --- | --- |
| `sort` + `unique` | 离线、全部值已知 |
| `map` / 动态开点线段树 | 在线、值域假 1e18、不想预处理 |
| 不离散 | 值已经是 1..n 或很小 |

n=1e5 时 `map` 每次 log 能过，但值域 BIT + 离散化更短、更快。先会本篇。

### 4. 手算

`a = {9, 1, 9, 3}` → 排序 `{1,3,9,9}` → unique `{1,3,9}` → 名次 `{3,1,3,2}`。BIT 只开 3 个叶子。

## 常见坑 / 注意事项

- **忘了 `sort` 就 `unique`。** 只去相邻，不是全局去重。  
- **`unique` 后仍用 n。** `m = b.size()`。  
- **`id` 得到 0，丢进 BIT。** `lowbit(0)=0`。  
- **离散化只含 a，询问 x 不在里面。** `lower_bound` 指到错误位置或 `end()`。  
- **`int` 装不下原值，名次用 `int` 可以。** 原数组 `long long`，名次数组 `int`。

## 趣味课间：实验室经典翻车集

- **「开 `c[1e9]` 会不会 MLE？」** 会。名次最多 n 个。  
- **样例全是 1..n。** 测不出离散化。造 `{1e9, 1, 1e9}`。  
- **`lower_bound` 写成手写二分 `while(l<=r)` 死循环。** 用 STL，见 [lower_bound 与二分](lower_bound与二分.md)。  
- **去重后两段相同值的逆序对少算。** 先查询「比自己大的已出现」，再 `add` 自己。

## 小结

排序、去重、二分出名次。值域结构的下标用名次，不要用原值。0-based 的 `id` 给 BIT 时记得 +1。

建议练习：

- 同一组数据对拍：`map` 当键 vs 本篇 `id`
