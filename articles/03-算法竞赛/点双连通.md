# 点双连通：没有割点的那一块

> 读完你应该能：用栈保存树边和返祖边，在 `low[v] ≥ dfn[u]` 时弹出一个点双；说出割点可以属于多个点双，桥所在的块往往只有一条边；把它和 [割点与桥](割点与桥.md)、[强连通分量](强连通分量.md) 分成三份模板。
>
> 一句口号：**割点是分叉的关节。点双是关节之间、内部怎么删一个点都还连着的那一团。**

## 背景 / 为什么要读这篇

[割点与桥](割点与桥.md) 只问「删谁会断」。点双连通分量（点双，v-BCC）问「把图按割点切开之后，每一块里还有谁」。圆方树、一些「必经点」计数，都要先有这些块。

实验室有人用强连通的栈去弹点，无向图的返祖边没入栈，块里缺边；有人以为一个点只能在一个块里，割点被算丢。本篇栈里放的是**边**。

## 正文

### 1. 定义

无向图。一个点双是极大的一组点：点数至少 2，并且这块里没有割点（删掉块内任意一个点，块内其余点仍然连通）。只有两个点、一条边，也是一个点双——那条边如果是桥，这块里就这一条边。

割点属于它连出去的每一个点双。所以输出「每个点属于哪些块」时，割点会出现多次。不是割点的点只属于一个点双。

### 2. 栈里是边

DFS 时，树边和指向祖先的返祖边都压栈。从儿子 v 回来后，若 `low[v] ≥ dfn[u]`，说明 u 把 v 这侧封住了：不断弹栈，直到弹出边 `(u,v)`，弹出来的边上的点组成一个点双。

```cpp
int dfn[N], low[N], ts;
vector<int> g[N];
vector<pair<int, int>> stk;
vector<vector<int>> bcc;

void absorb(int u, int v) {
    vector<int> node;
    while (true) {
        auto e = stk.back();
        stk.pop_back();
        node.push_back(e.first);
        node.push_back(e.second);
        if (e.first == u && e.second == v) break;
    }
    sort(node.begin(), node.end());
    node.erase(unique(node.begin(), node.end()), node.end());
    bcc.push_back(node);
}

void dfs(int u, int fa) {
    dfn[u] = low[u] = ++ts;
    int child = 0;
    for (int v : g[u]) {
        if (!dfn[v]) {
            stk.push_back({u, v});
            child++;
            dfs(v, u);
            low[u] = min(low[u], low[v]);
            if (low[v] >= dfn[u]) absorb(u, v);
        } else if (v != fa && dfn[v] < dfn[u]) {
            low[u] = min(low[u], dfn[v]);
            stk.push_back({u, v});
        }
    }
}
```

根如果只有一个儿子，不会因为「子树个数 ≥ 2」成为割点，但 `low[v] ≥ dfn[根]` 仍然成立，根和那一侧会组成点双。这和割点判定不矛盾：点双照样弹出，根不一定是割点。

重边不能用 `v!=fa`。和割点篇一样，返祖边改成「不是来时的那条边编号」。模板题若保证简单图，上面的写法够用。

孤立点没有边，不会进入任何点双。题面若要求孤立点单独成块，要额外收集 `dfn` 之后度数为 0 的点。先读输出格式。

### 3. 和边双、SCC

| 对象 | 切开的东西 | 一个点能在几块 |
| --- | --- | --- |
| 点双 | 割点 | 割点可以多块 |
| 边双 | 桥 | 每个点一块 |
| 强连通 | 有向边 | 每个点一块 |

边双：不走桥再 DFS 即可，不必这套边栈。有向图不要调用本篇。

## 常见坑 / 注意事项

- **栈里只放点不放边。** 返祖边对应的点会丢。  
- **`low[v] > dfn[u]` 才弹。** 那是桥的条件。点双是 `≥`。  
- **割点只记录一次。** 题面要按块输出时，它应出现在每个相关块里。  
- **重边被当成返祖边。**  
- **`absorb` 把一条边弹成两个相同点又忘了 `unique`。**  
- **多测栈没清空。**

## 趣味课间：实验室经典翻车集

- **「点双就是没有桥的块。」** 那是边双。一个环上再共享一个割点的另一个环，边双可能是一整块，点双是两个环。  
- **样例是一条边。** 点双就是这两个点。再画两个环共一个点，割点应出现在两行输出里。  
- **用 SCC 的 `dfn==low` 弹点。** 无向图上几乎弹成一整块。  
- **孤立点算进点数却没有块，对拍时个数差 1。** 先看题要不要孤立点。

## 小结

边入栈。`low[v] ≥ dfn[u]` 时弹出直到树边 `(u,v)`，点去重后是一个点双。割点可以跨块。桥用严格 `>`，不要和本篇的 `≥` 调换。
