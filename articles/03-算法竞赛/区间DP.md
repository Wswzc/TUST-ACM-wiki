# 区间 DP：先短后长，断点在中间

> 读完你应该能：按区间长度从小到大填 `dp[l][r]`；枚举断点 k，用更短的两段拼出这一段；写出石子合并的代价；把环形区间拆成两倍长度的链。
>
> 一句口号：**短的区间已经最优；长区间只是选一个地方把它劈开。**

## 背景 / 为什么要读这篇

[01 背包](01背包.md) 的阶段是「前 i 件」。区间 DP 的阶段是「长度」。石子合并、矩阵链乘、括号匹配的最优代价，都是：一段 `[l,r]` 的最优，等于枚举最后一次合并发生在 k，加上两段已经算好的最优。

实验室有人 `for l; for r` 却先算长的，`dp[l][k]` 还是 0；有人环形只做一遍链，对面对的两堆没合并。本篇按长度循环钉死。

## 正文

### 1. 石子合并（链）

n 堆石子排成一行，每次合并相邻两堆，代价为两堆之和（或这一段的总和，看题）。求合并成一堆的最小代价。

`dp[l][r]`：把 `l..r` 合并成一堆的最小代价。  
`sum[r]-sum[l-1]`：这一段的总石子数，也就是最后一次合并的代价。

```text
dp[i][i] = 0
dp[l][r] = min_{l≤k<r} (dp[l][k] + dp[k+1][r]) + (sum[r]-sum[l-1])
```

```cpp
const long long INF = 4e18;
long long sum[N], dp[N][N];

void chain(int n) {
    for (int i = 1; i <= n; i++) dp[i][i] = 0;
    for (int len = 2; len <= n; len++) {
        for (int l = 1; l + len - 1 <= n; l++) {
            int r = l + len - 1;
            dp[l][r] = INF;
            long long cost = sum[r] - sum[l - 1];
            for (int k = l; k < r; k++)
                dp[l][r] = min(dp[l][r], dp[l][k] + dp[k + 1][r] + cost);
        }
    }
}
```

长度从 2 到 n：算 `[l,r]` 时，`[l,k]` 和 `[k+1,r]` 更短，已经填过。

最大代价把 `min` 换成 `max`，初值改成足够小（0 若代价非负）。

复杂度 O(n³)。n≤400 常规，n≤1000 看常数，n=1e5 不是区间 DP。

### 2. 环形

堆排成环：1 和 n 相邻。把数组复制一倍，`a[n+i]=a[i]`，在长度 n 的所有窗口里取最优：

```text
ans = min_{i=1..n} dp[i][i+n-1]
```

前缀和开到 `2n`。不要在环上取模下标硬写，两倍链更不容易漏。

### 3. 矩阵链、括号

矩阵链：`dp[l][r]` 是从第 l 个矩阵乘到第 r 个的最少乘法次数，断点是最后一次乘法切在哪。代价不是区间和，是 `row[l]*col[k]*col[r]` 这类。结构相同：**先短后长，枚举断点。**

能量项链、括号染色，也是这个骨架。先认「最后一次操作把区间劈成两段」，再写代价。

### 4. 什么时候不是

| 形态 | 做法 |
| --- | --- |
| 合并相邻、代价可加 | 区间 DP |
| 选或不选、与顺序无关的体积 | 背包 |
| 只和前一个位置有关 | 线性 DP / [单调队列优化](单调队列优化DP.md) |
| n=1e5 的区间最值 | 线段树 / ST，不是 O(n³) DP |

## 常见坑 / 注意事项

- **按左端点枚举，右端点跳跃，短区间未算。** 外层必须是长度。  
- **`k` 从 `l` 到 `r` 含 `r`，右段空。** `k < r`。  
- **`dp` 初值 0 拿去 `min`。** 未访问格是 0 会变成假最优。先赋 INF，对角线赋 0。  
- **环形答案取 `dp[1][n]`。** 要扫所有起点。  
- **`sum` 用 int，石子 1e4、段数 300，和的代价溢出。**  
- **最大最小混用同一个 INF。**

## 趣味课间：实验室经典翻车集

- **「区间 DP 就是二维数组。」** 二维谁都会开。顺序错了，数组里是垃圾。  
- **样例 n=2。** 只有一次合并。n=4 才出现断点选择。  
- **环形复制了数组，前缀和仍按 n 取模。** `sum[n+i]` 没建。  
- **四边形不等式优化还不会就拿去卡 n=1000。** 先 O(n³) 交模板；优化是下一档，对拍之后再上。

## 小结

按长度填表。`dp[l][r]` 枚举最后一刀 k。代价多半是整段的和或乘积尺寸。环变成 2n 的链再取窗口。n³ 心里有数。

建议练习：

- 洛谷 [P1880 [NOI1995] 石子合并](https://www.luogu.com.cn/problem/P1880)（环，要最小和最大）
- 链上 n=4 手填表，再对环形  
- 和 [树形 DP](树形DP.md) 对照：一个阶段是长度，一个阶段是子树
