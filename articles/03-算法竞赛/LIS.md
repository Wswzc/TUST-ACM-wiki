# LIS：最长上升子序列，n² 与 n log n 的两种诚实

> 读完你应该能：写出 O(n²) 的 `dp[i]` 定义；用「每个长度的最小结尾」+ `lower_bound` 写出 O(n log n)；分清严格上升和「不下降」时二分该用 `lower` 还是 `upper`；知道 LIS 求的是子序列不是子数组。
>
> 一句口号：**子序列可以跳着选，但顺序不能乱。每个位置记住「以我结尾的最长」，或记住「长度为 k 的上升列现在结尾最小能到谁」。**

## 背景 / 为什么要读这篇

[01 背包](01背包.md) 是「选或不选」的表。序列 DP 里最常出场的一张表是：给 n 个数，最长的严格递增子序列有多长。

子数组必须连续，子序列可以抽空。`3 1 2 4` 的 LIS 是 `1 2 4` 长度 3，不是 `1 2` 旁边那两格。实验室有人写成最长连续递增，那是另一道更简单的题。

n=1e3 用 n²；n=1e5 必须 n log n。后者用到 [二分](lower_bound与二分.md) 和「贪心维持最小结尾」——三条线在这里打结。

## 正文

### 1. 定义先说人话

下标 0-based，`a[0..n)`。一个子序列 `a[i1], a[i2], ..., a[ik]` 满足 `i1 < i2 < ... < ik` 且值严格递增 `a[i1] < a[i2] < ...`。求最大的 k。

不下降（`<` 改 `≤`）是姐妹题，二分时换一个边界，下面会标。

### 2. O(n²)：以 i 结尾

`dp[i]` = 以 `a[i]` 为**最后一个元素**的 LIS 长度。

```text
dp[i] = 1 + max{ dp[j] | j < i 且 a[j] < a[i] }
若没有这样的 j，dp[i] = 1
答案 = max dp[i]
```

```cpp
vector<int> dp(n, 1);
int ans = 1;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < i; j++) {
        if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
    }
    ans = max(ans, dp[i]);
}
```

手算 `3 1 2 4`：

```text
i    0 1 2 3
a    3 1 2 4
dp   1 1 2 3
```

`2` 接在 `1` 后；`4` 接在 `2` 后。清楚、好还原路径（记 `pre[i]=j`）。n=1e5 时 1e10 不行。

### 3. O(n log n)：tails 数组

贪心观察：同样长度的上升子序列，**结尾越小，越容易再接后面的数**。

令 `tails[k]` = 当前所有长度为 k+1 的 LIS 中，最小的那个结尾（k 从 0）。`tails` 本身是严格递增的。

新来一个 x：

- 若 x 比所有 `tails` 都大，可以接在最长的后面，`tails.push_back(x)`
- 否则，在 `tails` 里找第一个 ≥ x 的位置（严格 LIS 用 `lower_bound`），用 x 把它换掉——长度不变，但结尾变小了

```cpp
vector<int> tails;
for (int x : a) {
    auto it = lower_bound(tails.begin(), tails.end(), x);
    if (it == tails.end()) tails.push_back(x);
    else *it = x;
}
int lis = (int)tails.size();
```

`3 1 2 4`：

```text
x=3  tails = [3]
x=1  1 替换 3，tails = [1]
x=2  2 比 1 大，接上，tails = [1,2]
x=4  接上，[1,2,4]
```

长度 3。注意：`tails` **不是**某个真实 LIS 的内容，只是各长度的最优结尾。还原具体序列需要额外 `id` 或回 n² 的 `pre`。只要长度时，这段足够。

**不下降 LIS（最长不降）：** 相同值可以接在后面。二分要找第一个 **> x** 的位置去替换，即 `upper_bound`。口诀：

| 题目 | 二分 |
| --- | --- |
| 严格上升 `<` | `lower_bound`（第一个 ≥ x 换掉，等于也不让两个相同结尾共存） |
| 不下降 `≤` | `upper_bound`（等于时接到后面，换更后面的槽） |

写反：严格题会被 `{1,1,1}` 答成 3。自己测这组。

### 4. 和二分、贪心的关系

`tails` 有序，所以 `lower_bound` 合法，见 [lower_bound 与二分](lower_bound与二分.md)。替换结尾是贪心：同样长度保留更小结尾，交换论证可以做，入门记住例子即可。

这不是 [背包](01背包.md) 那种容量维，没有 M。状态是「长度」，值是「结尾」。

Dilworth 定理、最少不升划分 = LIS 长度，进阶题才会碰。先会求长度。

### 5. 复杂度

| 做法 | 时间 | 适用 |
| --- | --- | --- |
| n² DP | O(n²) | n ≤ 2000，要方案 |
| tails + 二分 | O(n log n) | n ≤ 1e5，只要长度 |
| 树状数组 / 线段树优化 DP | O(n log V) | 值域 DP、带权 LIS |

值域 1e9 先离散化再树状数组，那是「数据结构优化 DP」专题。n² 写不出来就不要跳去线段树。

## 常见坑 / 注意事项

- **做成连续递增。** 子数组 vs 子序列。
- **严格 / 不严格用错 bound。** `{1,1}` 测一遍。
- **`tails` 当成答案序列输出。** 它不是原序列的一个真实子序列（可能被替换得认不出）。要输出方案用 n² 记前驱，或额外维护每层下标。
- **`dp[i]` 初值忘了 1。** 单独一个数也是长度 1。
- **比较写成 `<=` 却用 `lower_bound`。**
- **n=0。** 长度 0。
- **`int` 存值，排序 / 二分没问题；长度也不会爆 int。**

## 趣味课间：实验室经典翻车集

- **「n log n 那版我看不懂，我 n² 过了。」** 样例 n=10。看数据范围再选。
- **「lower_bound 是二分查找有没有。」** 这里查找的是**该插在哪**，不是存在性。返回的迭代器用来赋值。
- **最长下降。** 序列取负，或比较反过来，或 `greater` 风格的 bound。不要复制上升代码只改一个符号却忘了 tails 单调方向。
- **和 LCS 搞混。** 最长公共子序列是两条序列、二维 DP。LIS 可以把「b 是 1..n 排列」时化成 LCS，那是题，不是定义。

## 小结

以 i 结尾的 n² 最清楚；只要长度就 `tails` + `lower_bound`。严格用 lower，不降用 upper。子序列可跳不可乱序。
