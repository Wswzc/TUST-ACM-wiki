# 莫比乌斯反演：把「整除」翻回「恰好」

> 读完你应该能：写出 μ 的定义并用线性筛求到 n；记住 `Σ_{d|n} μ(d) = [n=1]`；把「gcd 为 1 的点对数」写成 `Σ μ(d) floor(n/d)^2`；说明它是 [容斥](容斥原理.md) 在整除格上的打包，不是新的容斥符号游戏。
>
> 一句口号：**先数「d 整除 gcd」，再乘 μ(d) 把「至少」收成「恰好」。**

## 背景 / 为什么要读这篇

[容斥原理](容斥原理.md) 在条件不超过 20 个时枚举子集。[欧拉函数](欧拉函数.md) 数的是 1..n 里和 n 互质的个数。若要数 1..n 里所有数对 `(x,y)` 中 `gcd=1` 的对数，两两枚举太慢，按每个质数容斥又写不完。莫比乌斯函数把「所有质数」的容斥压成一个数论函数，线性筛一次，整除分块求和。

实验室有人 μ(1) 写成 0；有人平方因子仍赋 `-1`；有人反演方向反了，g 和 f 对调。本篇只钉筛和最常用的那一条式子。

## 正文

### 1. μ 是什么

把 n 质因数分解。

| n | μ(n) |
| --- | --- |
| 1 | 1 |
| 不同质数 k 个相乘 | (-1)^k |
| 某个质数平方整除 n | 0 |

于是

```text
Σ_{d|n} μ(d) = 1  当 n=1
             = 0  当 n>1
```

这就是「恰好等于 1」的开关。若 `g(n) = Σ_{d|n} f(d)`，则

```text
f(n) = Σ_{d|n} μ(d) g(n/d)
```

左边是「恰好」，右边是「整除意义下的前缀」乘 μ。竞赛里 f 往往难，g 往往是 `floor` 好算的。

### 2. 线性筛

和 [数论入门](数论入门.md) 的欧拉筛同一趟。`i` 的最小质因子是 `p` 时，`i*p` 有平方因子，μ 为 0。

```cpp
const int N = 10000005;
int mu[N], primes[N], cnt;
bool vis[N];

void sieve(int n) {
    mu[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (!vis[i]) {
            primes[++cnt] = i;
            mu[i] = -1;
        }
        for (int j = 1; j <= cnt && i * primes[j] <= n; j++) {
            int p = primes[j];
            vis[i * p] = true;
            if (i % p == 0) {
                mu[i * p] = 0;
                break;
            }
            mu[i * p] = -mu[i];
        }
    }
}
```

前缀和 `sumμ[i]=sumμ[i-1]+mu[i]`，后面整除分块要用。

### 3. gcd 为 1 的数对

`1≤x,y≤n`，`gcd(x,y)=1` 的对数（含顺序，(1,2) 与 (2,1) 都算）：

```text
Σ_{x=1}^n Σ_{y=1}^n [gcd=1]
= Σ_{x,y} Σ_{d|gcd} μ(d)
= Σ_d μ(d) floor(n/d)^2
```

d 只到 n。`floor(n/d)` 成段相同，整除分块 O(√n) 段，每段用 `sumμ` 的差。n=1e7 先筛再分块；多组询问 n≤1e7 就预处理 `sumμ`。

```cpp
long long coprime_pairs(int n, const vector<int>& summu) {
    long long ans = 0;
    for (int l = 1, r; l <= n; l = r + 1) {
        int v = n / l;
        r = min(n, n / v);
        ans += 1LL * (summu[r] - summu[l - 1]) * v * v;
    }
    return ans;
}
```

`[gcd=k]` 则令 `x=kx'`，变成 `n/k` 里 gcd 为 1 的对数。不要对 k 再套一层错误的 μ。

### 4. 和容斥、φ 的关系

φ(n) = n Σ_{d|n} μ(d)/d。筛 φ 和筛 μ 是亲戚。条件是任意子集的「整除」时用 μ；条件是题目列出的 10 个集合时用 [容斥](容斥原理.md) 枚举。不要看到「互质」就反演，n≤20 的位压容斥更短。

## 常见坑 / 注意事项

- **μ(1)=0。** 空积的符号是 +1。  
- **`i%p==0` 仍写成 `-mu[i]`。** 平方因子必须是 0，并且 `break`。  
- **反演抄反。** 用 n=1 检验：gcd 对只有 (1,1)，`μ(1)*1=1`。  
- **`v*v` 用 int。**  
- **分块 `r=n/(n/l)` 在 l>n 时死循环。** `l<=n`。  
- **多测重复筛 1e7。** 筛一次。

## 趣味课间：实验室经典翻车集

- **「μ 就是容斥的 (-1)^个数。」** 有平方因子时是 0，不是继续交替。  
- **样例 n=1。** 只有 μ(1)。用 n=2：对有 (1,1)(1,2)(2,1) 三对，不是四对。  
- **整除分块每一段都调用一次筛。**  
- **和欧拉函数题对拍，边界 n=1 差 1。** 先统一是否含 (1,1)。

## 小结

μ 在无平方因子时是 (-1)^k，否则 0。整除和为 `[n=1]`。gcd=1 的数对是 `Σ μ(d) floor(n/d)^2`。筛一次，分块求和。少量条件仍用普通容斥。
