# 欧拉函数：1 到 n 里有多少个数和 n 互质

> 读完你应该能：用公式 `φ(n) = n * Π (1-1/p)` 求单个 φ；在线性筛里顺带求出 1..n 的 φ；会用欧拉定理 `a^{φ(m)} ≡ 1 (mod m)`（前提 gcd(a,m)=1）把指数降下来；知道费马是欧拉在模数为质数时的特例。
>
> 一句口号：**φ(n) 数的是「小于等于 n 且与 n 互质」的个数。幂取模先看互质，再把指数模 φ(m)。**

## 背景 / 为什么要读这篇

[数论入门](数论入门.md) 的费马逆元 `a^{p-2}`，本质是 `φ(p)=p-1`。模数不是质数时，指数还想缩短，就要欧拉定理，于是必须会求 φ。

组合数、循环节、`a^b mod m` 里 b 大到 1e18 位数——都会碰到。实验室有人 `φ(p)=p-1` 套在合数上；有人筛 φ 写成 `phi[i]=i-1` 对所有 i。本篇公式 + 筛 + 降幂，扩欧求逆仍然留给 [扩展欧几里得](扩展欧几里得.md)。

## 正文

### 1. 定义与公式

`φ(n)` = 在 1..n 中与 n 互质的整数个数。`φ(1)=1`（1 与 1 互质）。

n 分解 `n = p1^{k1} ... pt^{kt}` 后：

```text
φ(n) = n * (1-1/p1) * ... * (1-1/pt)
     = n / p1 * (p1-1) / p2 * (p2-1) ...
```

实现时先除 p 再乘 (p-1)，避免分数。

```cpp
long long phi(long long n) {
    long long r = n;
    for (long long i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            r = r / i * (i - 1);
            while (n % i == 0) n /= i;
        }
    }
    if (n > 1) r = r / n * (n - 1);  // n 剩下一个大质因子
    return r;
}
```

性质（入门够用）：

- p 质数：`φ(p)=p-1`，`φ(p^k)=p^k - p^{k-1}`
- 积性：`gcd(a,b)=1` 则 `φ(ab)=φ(a)φ(b)`
- `Σ_{d|n} φ(d) = n`（证明留 OI Wiki，记结论可做反演入门）

### 2. 线性筛求 1..n 的 φ

每个数被最小质因子划一次时更新：

```cpp
void sieve_phi(int n) {
    vector<int> phi(n + 1), primes;
    vector<char> vis(n + 1, 0);
    phi[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (!vis[i]) {
            primes.push_back(i);
            phi[i] = i - 1;
        }
        for (int p : primes) {
            if ((long long)i * p > n) break;
            vis[i * p] = 1;
            if (i % p == 0) {
                phi[i * p] = phi[i] * p;  // p 是 i 的因子，φ(i*p)=φ(i)*p
                break;
            }
            phi[i * p] = phi[i] * (p - 1);
        }
    }
}
```

`i%p==0` 时乘 p 不是乘 (p-1)：因为 p 已经在 i 里出现过，φ 的公式里 `(1-1/p)` 只乘一次。写反则整表错。

### 3. 欧拉定理与降幂

若 `gcd(a,m)=1`：

```text
a^{φ(m)} ≡ 1 (mod m)
```

于是 `a^k ≡ a^{k mod φ(m)} (mod m)`。k 很大时先模 φ(m)。

**注意：** 指数不是简单 `k % phi` 在所有题里都对。当 k ≥ φ(m) 时常写成 `a^{φ(m) + (k % φ(m))}` 处理「模 φ 后变成 0 但原指数不是 0」——例如 `a^{φ}` 应是 1 不是 `a^0=1` 碰巧对，但有的底数 `a^0` 与 `a^{φ}` 在「未取模的指数为 0」时要特判。竞赛常见写法：

```cpp
// gcd(a,m)=1
long long e = k % phi_m;
qpow(a, e, m);  // k 已经很大且保证定理条件
```

若 k 以十进制超长字符串给出：一边读一边 `e = (e*10 + d) % phi_m`。

费马：m=p 质数，`φ(p)=p-1`，`a^{p-1}≡1`，逆元 `a^{p-2}`。

**gcd(a,m)≠1 时欧拉定理不成立。** 要用更一般的欧拉定理推广（指数 ≥ 某界后才能模 φ），入门题通常保证互质或模数为质。

### 4. 和扩欧、快速幂怎么选

| 需求 | 工具 |
| --- | --- |
| a^{-1} (mod p)，p 质数 | 费马或扩欧 |
| a^{-1} (mod m)，gcd=1，m 任意 | 扩欧（或 a^{φ(m)-1}） |
| a^k mod m，k 极大，gcd=1 | 欧拉降幂 + 快速幂 |
| 1..n 每个 φ | 线性筛 |

`a^{φ(m)-1}≡a^{-1}` 也是逆元，一次快速幂；扩欧常数更小、不要求先求 φ。

## 常见坑 / 注意事项

- **`φ(1)=0`。** 应是 1。
- **公式先乘后除爆了或除不尽。** 先 `/p*(p-1)`。
- **筛里 `i%p==0` 仍乘 `p-1`。**
- **合数模用 p-2。**
- **降幂在不互质时硬模 φ。**
- **`i*i<=n` 用 int 分解 1e12。** long long。
- **φ(n) 当「约数个数」。** 那是 d(n)，另一回事。

## 趣味课间：实验室经典翻车集

- **「欧拉函数就是质数减一。」** 只有 n 是质数。`φ(10)=4`（1,3,7,9）。
- **降幂把指数模成 0，输出 a^0=1，实际应是 a^{φ}。** 超长指数读入时，若中途已经 ≥ φ，有人用「是否发生过模」的 flag：发生过则指数至少 φ。模板题读清楚。
- **样例 m 是质数。** 费马蒙混过关，下一题 m=10 翻车。

## 小结

φ 用质因子公式或线性筛。欧拉定理在互质时降指数。费马是质数模特例。逆元优先扩欧，降幂优先先求 φ 再快速幂。
