# 树链剖分入门：把路径拆成 O(log n) 段区间

> 读完你应该能：两次 DFS 求出重儿子、重链顶、DFS 序；把树上 u—v 路径映射成若干段连续 dfn 区间；明白为什么重链剖分后路径段数是 O(log n)；静态路径加仍优先 [树上差分](树上差分.md)。
>
> 一句口号：**轻边跳一次深度至少减半。路径上轻边不超过 log 条，每条重链对应一段连续编号，丢给线段树。**

## 背景 / 为什么要读这篇

树上差分解决「先改完再问」。赛场更多是：**边改边查**——给 u 到 v 的路径加、问点权、改子树。这需要把树路径变成序列区间，然后套 [线段树](线段树入门.md)。

树链剖分（重链剖分，HLD）做的就是这层翻译。代码比差分长，但板子一旦过 P3384，路径问题会突然变「套序列模板」。

实验室有人第一次就写边权剖分 + 懒标记 + 子树加，CE 三小时。本篇只打穿：**点权、路径查询/单点改**，子树是 dfn 一段，路径是 while 跳链。边权记在深点子上即可。

## 正文

### 1. 重儿子与重链

`sz[u]`：子树大小。重儿子 `son[u]`：sz 最大的那个儿子（没有则 0）。连向重儿子的边叫重边，其余轻边。

重链：一直走重边形成的链。每条链有一个顶 `top[u]`。

关键引理：**从任意点向上走，每经过一条轻边，子树大小至少 ×2（更精确：深度方向上 sz 下降很快）。** 于是根到叶子轻边 O(log n) 条。u、v 路径拆成两条往 LCA 的链，总段数 O(log n)。

### 2. 两次 DFS

```cpp
int n, cnt;
vector<vector<int>> g;
vector<int> fa, dep, sz, son, top, dfn, rnk, val;
// rnk[dfn[u]] = u；val 点权

void dfs1(int u, int p) {
    fa[u] = p;
    sz[u] = 1;
    son[u] = 0;
    for (int v : g[u]) {
        if (v == p) continue;
        dep[v] = dep[u] + 1;
        dfs1(v, u);
        sz[u] += sz[v];
        if (sz[v] > sz[son[u]]) son[u] = v;
    }
}
void dfs2(int u, int tp) {
    top[u] = tp;
    dfn[u] = ++cnt;
    rnk[cnt] = u;
    if (!son[u]) return;
    dfs2(son[u], tp);  // 先走重儿子，重链 dfn 连续
    for (int v : g[u])
        if (v != fa[u] && v != son[u]) dfs2(v, v);  // 轻儿子新开链
}
```

先 `dfs1(root,0)` 再 `cnt=0; dfs2(root,root)`。重儿子优先编号，一条重链在 dfn 上是连续区间。

子树 u：`[dfn[u], dfn[u]+sz[u]-1]` 全部是它的子孙（含自己）。子树加/查直接线段树打这段。

### 3. 路径：跳链直到同一条

```cpp
void path_apply(int u, int v, long long w) {  // 路径点 +w，示意
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        // 区间 [dfn[top[u]], dfn[u]] 是 u 到链顶
        seg.rangeAdd(1, 1, n, dfn[top[u]], dfn[u], w);
        u = fa[top[u]];  // 跳到轻边另一端
    }
    if (dep[u] > dep[v]) swap(u, v);
    seg.rangeAdd(1, 1, n, dfn[u], dfn[v], w);  // 同一链，dfn 小的是 LCA 一侧
}
```

查询把 `rangeAdd` 换成 `qry` 即可。同一链上深度小的点 dfn 更小（因为先走重儿子、链顶 DFS 更早）——标准剖分保证链上 dfn 随深度递增。于是 `[dfn[u], dfn[v]]` 合法当 `dep[u]≤dep[v]`。

LCA 可以不单独写：跳完 `top` 相同后，深度较小的那个就是 LCA。需要 LCA 时直接返回它。

### 4. 和线段树对接

dfn 是 1..n 的排列，点权先 `build` 到 `a[dfn[u]]=val[u]`。之后所有路径/子树操作只说区间，不再说树。

边权：把边权放在**子结点**上，路径 u—v **不含 LCA**（最后一段 `dfn[lca]+1` 到深的一端），或查询时减掉 LCA 上的点权。入门题多为点权，P3384 是点权路径/子树。

### 5. 什么时候不要上剖分

| 需求 | 选 |
| --- | --- |
| 静态路径加，最后问 | 树上差分 |
| 只问 LCA / 距离 | 倍增 |
| 改查交错的路径/子树 | **树剖 + 线段树** |
| 子树只加只查、点不改路径 | DFS 序 + 树状数组 可能更短 |

复杂度：每次路径 O(log² n)（O(log n) 段 × 线段树 O(log n)）。n、q=1e5 常规。

## 常见坑 / 注意事项

- **`dfs2` 没先走重儿子。** dfn 不连续，区间是错的。
- **`son[u]=0` 时 `sz[0]` 要初始化 0。** 否则 `sz[v]>sz[0]` 乱认。
- **跳链比较 `dep[u]` 而不是 `dep[top[u]]`。** 应比链顶深度，否则可能跳错。
- **同一链 `swap` 后区间反了。** 小 dfn 在左。
- **边权忘了去掉 LCA。**
- **线段树 n 用点数，下标用 dfn 不是原编号。**
- **根 fa=0，跳 `fa[top]` 跳出树。** 根链顶是根，`top` 相同后结束，不要再跳。

## 趣味课间：实验室经典翻车集

- **「树剖就是 LCA。」** LCA 是副产品。主产品是区间。
- **差分能过的题硬上剖分。** P3128 用差分二十行，剖分 + 线段树一百行。
- **样例是一条链。** 整棵树一条重链，任何错误跳链都看不出来。造一个平衡的二叉树。
- **`while(u!=v)` 而不是 `top[u]!=top[v]`。** 同一链上 u≠v 会死循环或漏区间。

## 小结

dfs1 认重儿子，dfs2 先重后轻编号。路径：浅链顶的那侧整段打区间，跳父亲，直到一条链。子树就是 `[dfn,dfn+sz-1]`。静态题先差分；动态再剖分。
