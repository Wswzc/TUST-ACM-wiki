# DFS 回溯：全排列、选或不选，以及记得把棋子拿回来

> 读完你应该能：写出全排列和子集（选或不选）两块模板；理解「改状态 → 递归 → **改回去**」为什么缺一不可；会用 `vis` 和简单剪枝把 n=9 的搜索从超时拉回来；知道网格最短路不要用 DFS 硬刚。
>
> 一句口号：**回溯不是神秘递归，是走迷宫时把脚印擦掉，好让下一条路还能走。**

## 背景 / 为什么要读这篇

[BFS](BFS网格最短路.md) 解决「最少步数」。赛场上另一类题完全不在乎最短：

- 1～n 的所有排列
- n 个数里选出和为 k 的子集
- n 皇后、数独、把棋子放满某种规则

这类题的图往往是**隐式的**：结点是「已经做了哪些选择」，边是「下一步选谁」。你不会先建邻接表，而是递归往下试。试错了要退回来——这就是回溯。

实验室有两种常见死法。一种是递归里改了 `vis[i]=1`，回来忘了置 0，于是全世界只剩一种排列。另一种是 n=20 的子集还在 2^20 上再套一层 20!，评测机直接睡过去。本篇把模板写短，把「何时能搜、何时必须剪」写清楚。

## 正文

### 1. 先建立图像：一棵决策树

求 `{1,2,3}` 的全排列。第一层选谁当 `path[0]`，第二层选剩下的当 `path[1]`……树的每一条根到叶都是一个排列。

DFS 的动作永远是三步：

1. **做选择**（把 x 放进路径，标记已用）
2. **往下走**（`dfs(层+1)`）
3. **撤销选择**（拿出来，标记未用）

第三步漏了，树的左边枝条会把状态污染给右边。这不是风格问题，是正确性。

BFS 用队列，一层层掀；DFS 用调用栈，一条路走到黑再回头。最短路用前者；枚举方案用后者。

### 2. 模板 A：全排列

洛谷 [P1706 全排列问题](https://www.luogu.com.cn/problem/P1706) 一类。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
vector<int> path;
vector<int> vis;

void dfs(int filled) {
    if (filled == n) {
        for (int i = 0; i < n; i++) {
            if (i) cout << ' ';
            cout << path[i];
        }
        cout << '\n';
        return;
    }
    for (int x = 1; x <= n; x++) {
        if (vis[x]) continue;
        vis[x] = 1;
        path[filled] = x;
        dfs(filled + 1);
        vis[x] = 0;          // 撤销
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    path.assign(n, 0);
    vis.assign(n + 1, 0);
    dfs(0);
    return 0;
}
```

复杂度：n 个位置，第 k 层大约 n-k 个分支，总共 n! 个叶子。n=8 是 40320，能打；n=10 是 3628800，输出已经很痛；n=12 的 4.7 亿，没有剪枝或题面保证不要硬上。

输出格式按题面：有的要 `%5d` 宽，有的要空格。全排列题经常卡格式，先看样例空格。

### 3. 模板 B：选或不选（子集）

每个元素两岔：要或不要。这是背包暴力版，也是组合型 DFS 的骨架。

```cpp
vector<int> a, path;
int n, k;

void dfs(int i, int sum) {
    if (sum == k) {
        // 找到一组，记录或计数
        return;
    }
    if (i == n || sum > k) return;  // 剪枝：超了或没了

    // 选 a[i]
    path.push_back(a[i]);
    dfs(i + 1, sum + a[i]);
    path.pop_back();

    // 不选 a[i]
    dfs(i + 1, sum);
}
```

和全排列的差别：下标 `i` 单调增加，不会回头选已经跳过的，因此自动去重「顺序不同但集合相同」。若题面要的是排列（顺序算不同），用模板 A。

n=20 时 2^20 ≈ 100 万，常常刚好。n=40 必须折半、meet in the middle 或改 DP。看见 n=40 的子集和，不要写裸 DFS。

### 4. 剪枝：让树变瘦，而不是把错的剪掉

合法剪枝只扔掉**不可能变优 / 不可能合法**的枝。常见几种：

| 剪枝 | 做法 | 小心 |
| --- | --- | --- |
| 可行性 | `sum > k` 直接 return | 有负数时「超了」不再单调，这招失效 |
| 最优性 | 当前花费已 ≥ 已知答案 | 要求的是最小；求方案计数时不要乱剪 |
| 可行性预估 | 剩下全选也到不了 k | 先排序或预处理后缀和 |
| 对称 | 相同元素强制递增选取 | 防 `1,1` 的重复子集 |

**不要为了快把正解剪掉。** 剪完必须拿小 n 和暴力对拍。剪枝写错比不剪更阴，因为样例太小走不到被剪的那枝。

有负数时，先选或不选的顺序、以及 `sum > k` 剪枝都要重新想。入门题通常是正整数。

### 5. n 皇后：回溯的成年礼

n×n 棋盘放 n 个皇后，不同行、列、对角线。行作为层，列作为选择：

```cpp
int n, ans;
vector<int> col, d1, d2;  // 列、主对角线、副对角线占用

void dfs(int r) {
    if (r == n) {
        ans++;
        return;
    }
    for (int c = 0; c < n; c++) {
        if (col[c] || d1[r - c + n] || d2[r + c]) continue;
        col[c] = d1[r - c + n] = d2[r + c] = 1;
        dfs(r + 1);
        col[c] = d1[r - c + n] = d2[r + c] = 0;
    }
}
```

`r-c` 可能为负，加 `n` 平移成下标。n=8 是 92 解，手算不完但程序一眨眼；n=13 还能打；再大要位运算加速，那是进阶。

这题把「撤销」拍在脸上：同一列不能复用，退回来必须清标记，否则后面的行无列可放。

### 6. 和 BFS、DP 的边界

| 题在问 | 更可能是 |
| --- | --- |
| 最少步数、网格最短 | BFS |
| 所有方案 / 下一个排列 / 棋盘放置 | DFS 回溯 |
| n=20 子集，只关心能否、最大值 | [01 背包](01背包.md) 或 [状压 DP](状压DP.md) |
| n=1e5 | 不是搜索，换算法 |

回溯是指数级的诚实劳动。能 DP 就 DP：01 背包把「选或不选」做成数组，见下一篇。搜索用来：方案要输出、约束不规则、n 很小。

连通块、树的遍历也是 DFS，但通常**不需要撤销**——那是「遍历」不是「试错」。`vis` 一辈子盖章。回溯的 `vis` 是租的，用完还。

### 7. 递归深度与全局变量

竞赛里 n 皇后、排列 n≤15，默认栈够用。若递归层数到 1e5（深链树），可能栈溢出，改成显式栈或把递归改循环。网格 DFS 洪水填充，1000×1000 最坏链状，**可能爆栈**，改 BFS 更稳——又和上一篇握手。

`path`、`vis`、`ans` 放全局或引用参数都可以。不要每次 `dfs` 传入整份 `vector` 的拷贝：`dfs(path)` 按值传会把复杂度再乘上拷贝。传引用或全局。

## 常见坑 / 注意事项

- **忘了撤销。** 只得到部分排列，或 ans 偏小。
- **`vis` 下标用了 0-based 元素却开了 `n` 大小、访问 `vis[n]`。** 元素是 1..n 时开 `n+1`。
- **全排列用了子集模板，少了顺序。** 或反过来，子集被当成不同排列重复输出。
- **`sum > k` 遇到负数。**
- **输出全排列时 `endl` 刷了 n! 次。** 用 `'\n'`。
- **在 DFS 里求网格最短路。** 见 BFS 篇。
- **剪枝后不对拍。** 错剪比慢更坏。
- **多组数据 `ans`、`vis` 残留。** 每组重新 `assign`。
- **`dfs` 按值传 `vector`。** 又慢又容易以为撤销了其实撤的是副本。

## 趣味课间：实验室经典翻车集

- **「递归好高级。」** 它就是 for 循环长了深度。把 n=3 的树画在草稿纸上，每个框写当前 `path`，比看视频有用。
- **「我把 `vis[x]=0` 写在 `if (filled==n)` 里面。」** 那只在叶子撤销，中间层的脏脚印还在。撤销跟在递归调用后面，和「做选择」成对，像括号匹配。
- **「n=12 全排列 TLE，我加了 `ios::sync_with_stdio`。」** 加速输不出救 4 亿次递归。换题或换算法。
- **数独用 DFS，一个格子 9 种，81 格。** 没有剪枝（行列表）就是 9^81。先填约束最多的格（启发），这和 n 皇后「一行一层」是同一类聪明。
- **队友问「回溯和 DFS 什么区别」。** 回溯是带撤销的 DFS。不撤销的是遍历。

## 小结

决策树 + 做选择 + 递归 + 撤销。全排列用 `vis` 扫可选数字；子集用下标 `i` 选或不选。n! 和 2^n 心里要有数。网格最短路请回 BFS；能 DP 的「选或不选」请看背包。
