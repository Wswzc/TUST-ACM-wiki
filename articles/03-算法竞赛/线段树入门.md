# 线段树入门：区间最值，以及懒标记在偷懒

> 读完你应该能：写出单点修改 + 区间求和 / 最值的线段树；知道每个结点管 `[l,r]`、左右儿子在 `p<<1` 和 `p<<1|1`；理解懒标记为什么能把区间修改做成 O(log n)；在 [树状数组](树状数组.md) 和线段树之间会选题。
>
> 一句口号：**满二叉树套在数组区间上。问一段，最多拆成 O(log n) 个整结点；改一段，把账记在标记里，真正用到再往下推。**

## 背景 / 为什么要读这篇

树状数组擅长「单点加、前缀和」。题目改口：「区间全体加，再问区间和 / 区间 min」——BIT 开始别扭，线段树是正餐。

它比 BIT 通用：只要信息能**合并**（和、最值、gcd、按位或），就能挂在结点上。代价是代码长、下标容易写飞、懒标记漏推会 WA 得像随机数。

实验室有人 `new` 动态结点却忘记回收；竞赛入门用**静态数组开 4n** 即可。有人查询时 `mid` 写反，左儿子管到 r。本篇先打穿无标记的单点改，再加区间加的懒标记——两段都要能默写。

## 正文

### 1. 树长什么样

叶子对应 `a[1], a[2], ..., a[n]`。每个内部结点 = 左右儿子合并（求和就是加，求 min 就是 `min`）。根管 `[1,n]`。

结点编号：根是 1，左儿子 `p<<1`，右儿子 `p<<1|1`。数组 `tr[1..4n]` 够用（不是 2n，最坏差一个常数，4n 省心）。

`mid = (l+r) >> 1`：左儿子 `[l,mid]`，右儿子 `[mid+1,r]`。查询区间和结点区间的关系只有三种：全含、全无、相交再往下。

### 2. 单点改 + 区间和（先会这个）

```cpp
struct Seg {
    int n;
    vector<long long> tr;
    Seg(int n) : n(n), tr(4 * n + 4, 0) {}

    void build(int p, int l, int r, const vector<long long>& a) {
        if (l == r) {
            tr[p] = a[l];
            return;
        }
        int mid = (l + r) >> 1;
        build(p << 1, l, mid, a);
        build(p << 1 | 1, mid + 1, r, a);
        tr[p] = tr[p << 1] + tr[p << 1 | 1];
    }
    void upd(int p, int l, int r, int x, long long v) {  // a[x] += v
        if (l == r) {
            tr[p] += v;
            return;
        }
        int mid = (l + r) >> 1;
        if (x <= mid) upd(p << 1, l, mid, x, v);
        else upd(p << 1 | 1, mid + 1, r, x, v);
        tr[p] = tr[p << 1] + tr[p << 1 | 1];
    }
    long long qry(int p, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tr[p];
        int mid = (l + r) >> 1;
        long long s = 0;
        if (ql <= mid) s += qry(p << 1, l, mid, ql, qr);
        if (qr > mid) s += qry(p << 1 | 1, mid + 1, r, ql, qr);
        return s;
    }
};
```

调用：`build(1,1,n,a)`，`upd(1,1,n,x,v)`，`qry(1,1,n,L,R)`。`a` 下标从 1。

区间 min：`tr[p]` 改存 min，合并 `min(左,右)`，查询初值用 `4e18` 再 `min`。不要和「和」共用一个没想清楚的 `0`——min 的幺元不是 0。

### 3. 查询为什么是 O(log n)

任意 `[ql,qr]` 在树上会被切成 O(log n) 段「正好盖住的结点」（可以画 n=8 的图数一下）。不会把 n 个叶子全走一遍——那是暴力。

修改只走根到一片叶子的一条链，O(log n)，回来一路 `pushup`。

### 4. 懒标记：区间加、区间和

若把 `[L,R]` 每个点都 `upd`，那是 O(n log n)。正确做法：碰到「当前结点区间完全在修改区间内」，**不要往下走**，在这个结点记账：`lazy[p] += v`，同时 `tr[p] += v * (r-l+1)`。

真正要进左右儿子时，先 `pushdown`：把账推给儿子，自己清零。

```cpp
struct Seg2 {
    int n;
    vector<long long> tr, lz;
    Seg2(int n) : n(n), tr(4 * n + 4, 0), lz(4 * n + 4, 0) {}

    void apply(int p, int l, int r, long long v) {
        tr[p] += v * (r - l + 1);
        lz[p] += v;
    }
    void pushdown(int p, int l, int r) {
        if (!lz[p]) return;
        int mid = (l + r) >> 1;
        apply(p << 1, l, mid, lz[p]);
        apply(p << 1 | 1, mid + 1, r, lz[p]);
        lz[p] = 0;
    }
    void rangeAdd(int p, int l, int r, int ql, int qr, long long v) {
        if (ql <= l && r <= qr) {
            apply(p, l, r, v);
            return;
        }
        pushdown(p, l, r);
        int mid = (l + r) >> 1;
        if (ql <= mid) rangeAdd(p << 1, l, mid, ql, qr, v);
        if (qr > mid) rangeAdd(p << 1 | 1, mid + 1, r, ql, qr, v);
        tr[p] = tr[p << 1] + tr[p << 1 | 1];
    }
    long long qry(int p, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tr[p];
        pushdown(p, l, r);
        int mid = (l + r) >> 1;
        long long s = 0;
        if (ql <= mid) s += qry(p << 1, l, mid, ql, qr);
        if (qr > mid) s += qry(p << 1 | 1, mid + 1, r, ql, qr);
        return s;
    }
};
```

两条铁律：

1. **往左右走之前 `pushdown`。** 漏了，儿子还是旧值。  
2. **回来 `pushup`（用儿子更新自己）。** 标记版 `rangeAdd` 末尾那行。

区间赋值为同一值、多种标记混用，是进阶。入门先区间加一种标记，不要同时「加」和「覆盖」除非题面逼你。

### 5. 和 BIT、暴力怎么选

| 需求 | 选 |
| --- | --- |
| 静态和 | 前缀和 |
| 单点加，区间和 | BIT 更短 |
| 单点改，区间 min/max/gcd | **线段树** |
| 区间加，区间和 | 懒标记线段树（或两个 BIT 的公式） |
| 区间加，区间 min | 懒标记线段树 |

两个 BIT 也能搞区间加+区间和，公式容易写错。会线段树之后更稳。

### 6. 复杂度与空间

建树 O(n)，每次操作 O(log n)。`4n` 个 `long long`，n=1e6 大约 32MB 量级，注意内存；n=1e5 非常舒适。

递归深度 log n，不会爆栈。不要把 `[l,r]` 写成全局却多组数据忘了重建。

## 常见坑 / 注意事项

- **开 2n。** 不够，开 4n。
- **`mid` 划分和 `if (x<=mid)` 不一致。** 左闭右开混进闭区间。
- **查询漏 `qr>mid` 或写成 `>=`。** 边界点进错儿子。
- **懒标记查询不 `pushdown`。**
- **`apply` 只改 `lz` 不改 `tr`。** 当前结点答案是错的。
- **min 线段树查询初始 `s=0`。** 全是正数时碰巧对，有负数就炸。
- **下标 0。** 和 BIT 一样，入门 1..n。
- **`upd` 改成赋值却写成 `+=`。** 看题是加还是改。

## 趣味课间：实验室经典翻车集

- **「我抄了 zkw 线段树。」** 非递归好看，调试难。先会递归版，再炫技。
- **动态开点第一次就写。** 值域 1e9 才需要。普通 1..n 静态 4n。
- **样例 n=4 全过，n=5 WA。** 4 是满二叉树，5 才暴露 `4n` 和 `mid`。
- **标记下推写成 `lz[son]=lz[p]` 而题是区间加。** 加应该 `+=`，覆盖才是 `=`。两种标记不是同一个故事。

## 小结

结点管区间，合并左右。单点改走一条链；区间问拆 O(log n) 个整块。区间改先记账，下去再 `pushdown`。能 BIT 的和用 BIT；要最值或真区间改，上线段树。
