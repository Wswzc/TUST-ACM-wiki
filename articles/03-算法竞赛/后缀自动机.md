# 后缀自动机：子串是从根出发的一条路径

> 读完你应该能：从空自动机开始 `extend` 一个字符，处理「直接连」和「克隆」两种情况；用 `len[u]-len[link[u]]` 求本质不同子串个数；沿 link 把出现次数从长串推到短串；知道它和 [后缀数组](后缀数组.md) 都能做重复子串，自动机更适合「在线加字符、从根匹配」。
>
> 一句口号：**每个状态代表一批结束位置相同的子串；link 指向它们最长的真后缀所在的状态。**

## 背景 / 为什么要读这篇

[后缀数组](后缀数组.md) 把后缀排好，`height` 给相邻 LCP。后缀自动机（SAM）把一个串的全部子串收成一张有向无环图：从根走一条路径，读到的串就是原串的一个子串，每条子串恰好一条路径。状态数不超过 `2n-1`（n≥2 时的上界常记成 2n）。

实验室有人克隆时忘了把 `q` 的后继拷给新点，后面匹配断掉；有人 `link` 从 0 开始和根的编号撞车。本篇根固定为 1，0 表示不存在。

## 正文

### 1. 状态里有什么

每个状态 u：

| 字段 | 含义 |
| --- | --- |
| `len[u]` | 这个状态代表的最长串的长度 |
| `link[u]` | 后缀链接：最长的、结束位置集合不同的那个真后缀 |
| `ch[u][c]` | 读入字符 c 之后的状态 |

根是 1，`len[1]=0`，`link[1]=0`。状态 u 代表的串长是一段连续区间 `(len[link[u]], len[u]]`。所以本质不同子串个数是

```text
Σ (len[u] - len[link[u]])    （u 从 2 加到点数）
```

### 2. extend

`last` 是当前整个前缀所在的状态。加入字符 c：

```cpp
const int N = 2000005;
int ch[N][26], link[N], len[N], sz = 1, last = 1;

void extend(int c) {
    int cur = ++sz;
    len[cur] = len[last] + 1;
    int p = last;
    for (; p && !ch[p][c]; p = link[p]) ch[p][c] = cur;
    if (!p) link[cur] = 1;
    else {
        int q = ch[p][c];
        if (len[q] == len[p] + 1) link[cur] = q;
        else {
            int cl = ++sz;
            memcpy(ch[cl], ch[q], sizeof ch[cl]);
            len[cl] = len[p] + 1;
            link[cl] = link[q];
            link[q] = link[cur] = cl;
            for (; p && ch[p][c] == q; p = link[p]) ch[p][c] = cl;
        }
    }
    last = cur;
}
```

`len[q]==len[p]+1`：q 就是 p 后接 c 的「刚好长一截」，直接当 cur 的 link。否则 q 太长，要克隆一个长度恰好为 `len[p]+1` 的状态，把原来指向 q 的边改到克隆点。克隆点继承 q 的出边和 link，再把 q 和 cur 的 link 都指向克隆点。

出现次数：给 `cur` 打 `cnt[cur]++`（每个前缀的结束状态 +1）。克隆点的 `cnt` 初始是 0，它的次数来自后面的推送。按 `len` 从大到小，`cnt[link[u]] += cnt[u]`。推完以后，`cnt[u]` 是该状态代表的那些串在原串里的出现次数。

最长的、出现至少两次的子串长度：推完后看所有 `cnt[u]≥2` 的 `len[u]` 的最大值。这就是洛谷 P3804 的主体。

### 3. 和后缀数组怎么选

| 问 | 更顺手 |
| --- | --- |
| 后缀排名、相邻 LCP | 后缀数组 |
| 本质不同子串、在线追加字符 | SAM |
| 多个串的公共子串 | 在 SAM 上跑第二个串，失配就跳 link |
| 回文 | [Manacher](Manacher.md) 或 [回文自动机](回文自动机.md) |

从根匹配一个模式：顺着 `ch` 走，走不到就不是子串。AC 自动机的 fail 管的是文本上失配之后跳去哪；SAM 的 link 是子串的后缀，文本已经建在自动机里。回文子串用 [回文自动机](回文自动机.md)。

## 常见坑 / 注意事项

- **根写成 0，`!p` 和「没有这个儿子」分不清。** 根用 1。  
- **克隆不拷 `ch`。**  
- **`cnt` 在克隆点上先 +1。** 结束位置只记在 `cur`。  
- **不按长度从大到小推 `cnt`。** 短的先加会漏。  
- **数组开 n 而不是 2n。** 克隆会把状态数顶到约 2n。  
- **多测 `sz`、`ch`、`link` 没重建。** 只清用过的点，或整体重开。

## 趣味课间：实验室经典翻车集

- **「SAM 就是后缀数组加自动机四个字。」** 没有 `sa`。你要的是 `len` 和 `link`。  
- **样例全是同一个字符 `aaa`。** 克隆分支可能不走。换 `abcab`。  
- **本质不同子串用 `n(n+1)/2` 减去 height。** 那是后缀数组的算法，也对，但和自动机的求和不是同一段代码。对拍两者。  
- **`memcpy` 的 `ch[cl]` 在 `ch` 是 `vector` 时写错大小。** 二维数组用 `sizeof ch[cl]`。

## 小结

`extend` 要么把 link 接到现成的 q，要么克隆一个更短的 q。本质不同子串是长度区间的和。出现次数从长状态推到 link。根是 1，空间按 2n 开。
