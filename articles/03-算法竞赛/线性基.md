# 线性基：异或世界里的极大无关组

> 读完你应该能：把一堆整数插入线性基；判断一个数能否被子集 XOR 出来；求出子集 XOR 的最大值；解释它和 [高斯消元](高斯消元.md) 里异或方程组是同一件事，只是通常按位从高到低插。
>
> 一句口号：**每一位最多留一个「代表」；新数能被现有代表消成 0，就是线性相关，丢。**

## 背景 / 为什么要读这篇

[高斯消元](高斯消元.md) 写过：异或方程组是模 2 消元。线性基是同一套线性代数，题面换成「选一个子集，XOR 最大 / 能否拼出 x / 有多少种」。

区域赛包装：宝石编号 XOR、路径 XOR（树上再配 LCA）、选数使得异或和最大。实验室有人把所有数丢进 `set` 再枚举 2^n；有人插入时从低位走，最大值贪心就错；有人 `long long` 只开到 31 位。本篇把插入和高位贪心钉死。

## 正文

### 1. 它在张成什么

把每个数看成 63 维向量（0/1，按二进制位）。XOR 是向量加法（模 2）。线性基是一组「尽量少」的数，能 XOR 出原集合能 XOR 出的一切。

最多 63 个非零基（`long long`）。n=1e5 个插入，基的大小仍 ≤ 63。这就是为什么能从 2^n 掉到线性。

插入失败（消成 0）：这个数能被已有基表出，**线性相关**，不加进去。插入成功：秩 +1，能表出的值的数量翻倍（从 2^r 变成 2^{r+1}，含 0）。

### 2. 从高位插入

`p[i]` 表示「最高有效位为 i」的代表，或 0 表示没有。插入 x：从 62 走到 0，遇到 `x` 的第 i 位是 1：

- `p[i]==0`：把 x 放在这里，结束。
- 否则 `x ^= p[i]`，继续消。

```cpp
long long p[63];

bool insert(long long x) {
    for (int i = 62; i >= 0; i--) {
        if (!(x >> i & 1)) continue;
        if (!p[i]) {
            p[i] = x;
            return true;
        }
        x ^= p[i];
    }
    return false;  // 能被表出，相关
}

bool contain(long long x) {
    for (int i = 62; i >= 0; i--)
        if (x >> i & 1) x ^= p[i];
    return x == 0;
}

long long qmax() {
    long long res = 0;
    for (int i = 62; i >= 0; i--)
        res = max(res, res ^ p[i]);
    return res;
}
```

`qmax`：从高位往低，能变大就 XOR 上。`p[i]==0` 时 `res^0` 不变。若题目要「必须非空子集」，原数组全 0 时答案是 0 还是不存在，读题。

查询「能否 XOR 出 x」就是 `contain(x)`。想要最大值再 XOR 上某个固定值 k（例如路径前缀），先把 k 当初始 `res` 再贪心，或把所有数 XOR k 的差纳入基——按题建模，入门先会 `qmax`。

### 3. 和消元板子的关系

把每个数当一行、每一位当一列，做异或高斯，主元所在行就是基。线性基是「只关心能张成什么、按位贪心」的压缩写法，不必保存整张 n×63 矩阵。

需要「第 k 小异或」时，要把基整理成：`p[i]` 的第 i 位为 1，且更高位互不污染。入门题只要最大 / 能否表出，先不要上 kth。

### 4. 树上路径 XOR

点到根的 XOR 前缀 `pre[u]`。u 到 v 的路径 XOR = `pre[u] ^ pre[v] ^ pre[lca]` 或按边权写法 `pre[u]^pre[v]`（边在 LCA 处消掉）。要把「路径上的边权集合」插入基，离线或点分治，那是下一档。入门先会数组上的插入。

## 常见坑 / 注意事项

- **只开 `p[32]`。** `long long` 用 0..62。  
- **从低位插入再高位贪心。** 最大异或会错。高位优先。  
- **`insert` 之后没清 `p`，多组数据串味。**  
- **空基 `qmax` 当 -1。** 全 0 的最大是 0。  
- **询问能否表出却用 `qmax==x`。** 最大不是全集。  
- **`int` 左移 31 的符号位。** 用 `1LL << i` 判断时小心；这里走的是 `x >> i & 1`。

## 趣味课间：实验室经典翻车集

- **「异或就是不进位加法，我枚举子集。」** n=40 时 2^40。基的大小是位数。  
- **样例三个数最大异或恰好是某个原数。** 测不出「要组合两位」。造 `1,2,3`（3=1^2），最大是 3，基里可能只有 1 和 2。  
- **把线性基抄成「每个位独立取 1」。** 位之间有牵连，必须按代表去 XOR，不能按位 or。  
- **高斯板子 n=1e5、63 列，存 `vector<bitset>` 爆内存或 TLE。** 用本篇的 63 个 `long long`。

## 小结

数是向量，XOR 是加法。高位插入，相关则丢。最大异或从高位贪心。能表出就把数消成 0。先会数组，再谈树上。
