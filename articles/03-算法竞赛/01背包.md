# 01 背包：把「选或不选」做成数组

> 读完你应该能：写出一维滚动的 01 背包；解释为什么内层容量必须**倒序**；分清 01、完全、多重在「每件物品用几次」上的差别；在 n=20 的子集和与 n=100、容量 1e4 之间会选 DFS 还是 DP。
>
> 一句口号：**DFS 把决策树走一遍；DP 把同一棵树上相同子问题的答案存下来。01 背包是最老实的一棵。**

## 背景 / 为什么要读这篇

[贪心](贪心入门.md) 里说过：0-1 背包贪价值密度是错的。每件物品要么拿要么不拿，拿了占体积，问最大价值——这需要记住「当前体积下最好的结果」，而不是每步抓看起来最香的。

[DFS 回溯](DFS回溯.md) 的「选或不选」能暴力出答案，代价是 2^n。n=20 可以；n=100 不行。动态规划做的事很难听也很难忘：**用空间换指数时间。** 把「考虑到前 i 件物品、体积恰好/不超过 j」的最优值记在表里，后面直接查。

实验室有人能背 `for i; for j=m; j>=w; j-- dp[j]=max(dp[j], dp[j-w]+v)`，但说不清倒序。下一题变成完全背包，他仍倒序，于是 WA。本篇把表、倒序、和完全背包的一念之差写开。

## 正文

### 1. 问题长什么样

n 件物品，第 i 件体积 `w[i]`、价值 `v[i]`。背包容量 M。每件**最多选一次**。求不超过 M 时的最大价值和。

变种：恰好装满；求方案数；求是否能装满。骨架同一个数组，转移式改 `max` 还是 `+=`。

和 [贪心](贪心入门.md) 的硬币对照：硬币若每种无限枚，是完全背包；每种至多一枚，是 01。人民币凑整常常是完全。题面「每件物品一件」才是本篇。

### 2. 二维表：先看见再压缩

令 `dp[i][j]` = 只考虑前 i 件物品、容量为 j 时的最大价值。

```text
不选第 i 件:  dp[i][j] = dp[i-1][j]
选第 i 件:    若 j >= w[i]，dp[i-1][j - w[i]] + v[i]
取 max
```

`dp[0][*] = 0`：没有物品，价值 0。若必须恰好装满，则 `dp[0][0]=0`，其余 `dp[0][j]= -∞`（代码里用一个很小的数）。

```cpp
// 二维，便于理解，n、M 到 1000 时大约 1e6 格
vector<vector<int>> dp(n + 1, vector<int>(M + 1, 0));
for (int i = 1; i <= n; i++) {
    for (int j = 0; j <= M; j++) {
        dp[i][j] = dp[i - 1][j];
        if (j >= w[i])
            dp[i][j] = max(dp[i][j], dp[i - 1][j - w[i]] + v[i]);
    }
}
cout << dp[n][M] << '\n';
```

手算一件：`w=3, v=4`，M=5。

```text
j     0 1 2 3 4 5
i=0   0 0 0 0 0 0
i=1   0 0 0 4 4 4    // j>=3 才能放
```

再来一件 `w=2, v=3`：

```text
j=2: max(不选=0, 选= dp[1][0]+3=3) = 3
j=5: max(不选=4, 选= dp[1][3]+3=7) = 7
```

7 就是两件都拿。表比口号诚实。

### 3. 压成一维：倒序是为了「每件只用一次」

观察：`dp[i][j]` 只依赖 `dp[i-1][*]`，不依赖本行左边……等等，选的时候依赖 `dp[i-1][j-w]`，是**上一行、更小的容量**。

若压缩成一维 `dp[j]`，正向 `j` 从 0 到 M 扫：算 `dp[j]` 时 `dp[j-w]` 已经是**本轮更新过**的值，等于第 i 件用了两次——那是完全背包的效果。

所以 01 必须让 `dp[j-w]` 仍是上一件物品的结果：容量**从大到小**。

```cpp
vector<int> dp(M + 1, 0);
for (int i = 1; i <= n; i++) {
    for (int j = M; j >= w[i]; j--) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
cout << dp[M] << '\n';
```

完整可交：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, M;
    cin >> n >> M;
    vector<int> w(n + 1), v(n + 1);
    for (int i = 1; i <= n; i++) cin >> w[i] >> v[i];

    vector<int> dp(M + 1, 0);
    for (int i = 1; i <= n; i++)
        for (int j = M; j >= w[i]; j--)
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);

    cout << dp[M] << '\n';
    return 0;
}
```

口诀：**01 倒序，完全正序。** 写完先看内层 `j++` 还是 `j--`，再看题是不是每件一件。

### 4. 完全背包与多重：只改循环方向 / 拆件

| 种类 | 每件可用次数 | 一维容量循环 |
| --- | --- | --- |
| 01 | 至多 1 | `j = M → w` 递减 |
| 完全 | 无限 | `j = w → M` 递增 |
| 多重 | 至多 k 件 | 二进制拆成若干 01 件，或内层再循环次数 |

完全背包正序的含义：`dp[j-w]` 已经包含「第 i 种又放了一件」，允许继续加。这正是无限枚想要的。

多重：k=3、w=2 拆成 w=2、w=4（2^1 件）、余下 w=2，按 01 塞进去。二进制拆分保证任意 1～k 都能拼出。k 很大、接近无限时当完全背包做。

入门先打穿 01。赛时看清「每种一个 / 无限 / 最多 k」。

### 5. 方案数、恰好装满、能否

**能否：** `vector<char> ok(M+1); ok[0]=1;` 转移 `if (ok[j-w]) ok[j]=1;` 同样倒序。最后看 `ok[M]` 或 `ok` 里任意 true。

**恰好装满的最大价值：** 初值 `dp[0]=0`，其余 `-1e9`。转移时只有 `dp[j-w]` 合法才更新。最终若 `dp[M]` 仍是 -∞，装不满。

**方案数：** `max` 改成 `+=`：

```cpp
vector<int> dp(M + 1, 0);
dp[0] = 1;  // 装满容量 0 有一种方法：什么都不选
for (int i = 1; i <= n; i++)
    for (int j = M; j >= w[i]; j--)
        dp[j] = (dp[j] + dp[j - w[i]]) % MOD;
```

模数看题。`dp[0]=1` 漏写，全是 0。

这些变种和「最大价值」共用同一张表的骨架，不要各背一份神话。

### 6. 复杂度与何时不该背包

`O(nM)`。n=100、M=1e4 → 1e6，轻松；n=100、M=1e7 要看时限；n=1000、M=1e7 大约 1e10，不行。

n≤20、只要方案，DFS 可能更好写。n=40 子集和：折半 + 双向搜索，或 meet in the middle，不是硬背包（体积若 1e18 也开不下数组）。

**体积或价值极大、件数极少：** 对小的那维做 DP。有时对价值 DP、体积当「代价最小值」，叫「价值作下标的 01」。看见 M=1e9、v 总和 ≤ 1e5，就该把下标换成价值。

[前缀和](前缀和与差分.md) 解决静态区间；背包解决「选哪些」。不是一个工具。

### 7. 和贪心、DFS 怎么选

| 观察 | 选 |
| --- | --- |
| 每件至多一次，n·M 可接受 | 01 DP |
| 无限件，n·M 可接受 | 完全背包 |
| 价值密度贪心 | 分数背包（可切碎）才对；01 贪心会错 |
| n≤20 要输出具体子集 | DFS 回溯 |
| 硬币最少枚数、面额任意 | DP，不是人民币直觉 |

分数背包：物品可切，按 v/w 排序贪心是对的。那是贪心篇的亲戚，不要和 01 混。

## 常见坑 / 注意事项

- **01 写成正序。** 每件被用多次，答案偏大。
- **完全写成倒序。** 每件至多一次，答案偏小。
- **`dp` 开成 `int`，价值和 1e9×100。** `long long` 或看清范围。
- **下标 0 件物品、`w[0]` 垃圾值。** 数组从 1 或全程 0-based 选一种。
- **`j >= w[i]` 写成 `j > w[i]`。** 体积恰好相等那档没了。
- **恰好装满却初值全 0。** 未装满的状态被当成价值 0 的合法解。
- **方案数忘了 `dp[0]=1`。**
- **先读 M 再读 n，循环写反。** 模板是「枚举物品在外，容量在内」。
- **多重背包拆件时 `int` 体积溢出。** 拆出的 w 乘 2^k。

## 趣味课间：实验室经典翻车集

- **「我背过九讲。」** 能讲清楚倒序，比背完九章更重要。赛时默写两行，先画 2 件物品的表。
- **「样例答案比我大。」** 你倒序了但读成了完全；或相反。用只有两件、容量刚够都拿的数据打自己。
- **「DP 就是数组。」** 数组是落点。先有「子问题定义」：`dp[j]` 这句话能用人话讲出来再写循环。讲不出来的数组是玄学。
- **硬币再来一次。** `{1,5,10,12}` 凑 15 最少枚：完全背包 `dp[j]=min(dp[j], dp[j-w]+1)`，正序，`dp[0]=0` 其余 inf。贪心 4 枚，DP 2 枚。让数字打脸一次，记得更牢。
- **空间卡了把二维改一维，方向忘了改。** 压缩不是复制一行，是改变遍历顺序。

## 小结

`dp[j]`：容量 j 下的最优。01 物品在外、容量倒序；完全则正序。先画两行表，再压缩。n 很小要方案走 DFS；n·M 合适走背包；贪价值密度只对能切的物品诚实。
