# BFS：网格上的最短路，以及队列里的那些格子

> 读完你应该能：在网格上用队列做 BFS，求出到每个格子的最少步数；知道为什么边权全是 1 时 BFS 就是最短路；会处理墙壁、越界、`vis` 标记的时机；能把「四个方向」写成不容易写反的数组。
>
> 一句口号：**DFS 往深里钻，BFS 一层一层掀。最短步数是一层的半径。**

## 背景 / 为什么要读这篇

第 1 学期清单里「基础搜索」常被理解成「我会写递归了」。递归是 DFS 的皮；**网格迷宫、走地图、最少步数**，现场赛更常考 BFS。

原因很物理：每走一步代价相同（上下左右各算 1）。先被走到的格子，一定不会比后走到的更远——像水波纹从起点一圈圈扩出去。第一圈半径 1，第二圈半径 2。第一次碰到终点，那就是最短路。

DFS 也能找到一条路，那是「某条路」，不是「最短」。实验室有人用 DFS 过了样例（样例只有一条路），正式数据里绕远路，WA 得心服口服。

本篇只打穿**边权为 1 的网格 BFS**。带权最短路是 Dijkstra（[priority_queue](../01-编程语言/priority_queue.md) 预习过）；0-1 边权是双端队列，后话。

## 正文

### 1. 水波纹：为什么 BFS 得到最少步数

想象起点丢一颗石子。第 0 秒：起点自己。第 1 秒：所有与起点相邻的空地。第 2 秒：与「第 1 秒格子」相邻、且还没被水碰到的格子。

队列保证：**先入队的步数一定 ≤ 后入队的。** 于是每个格子第一次入队（或第一次出队，见下文标记时机）时，`dist` 就是最小值。再碰到它，一定更晚或一样晚，直接忽略。

边权若出现 2、3，水波纹不再均匀，BFS 会骗人，必须 Dijkstra。网格上下左右一步一格，边权全是 1，BFS 合法。

### 2. 四个方向：不要现场发明 `if (k==0) x--`

```cpp
const int dx[4] = {-1, 1, 0, 0};
const int dy[4] = {0, 0, -1, 1};
// 上、下、左、右。八连通再加四条对角线。
```

循环：

```cpp
for (int k = 0; k < 4; k++) {
    int nx = x + dx[k];
    int ny = y + dy[k];
    if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;  // 越界
    if (grid[nx][ny] == '#') continue;                     // 墙
    if (vis[nx][ny]) continue;
    // 入队
}
```

把越界写在访问 `grid[nx][ny]` **之前**，否则 `grid[-1][3]` 是 RE 或静默 WA。n 行 m 列，先确认 `grid[x][y]` 是第几维——实验室有人对调了 n、m，样例是正方形看不出来。

### 3. 一份能交的网格最短路

题：n 行 m 列，`.` 空地 `#` 墙，`S` 起点 `T` 终点，四连通，求最少步数，到不了输出 -1。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<string> g(n);
    for (int i = 0; i < n; i++) cin >> g[i];

    int sx = -1, sy = -1, tx = -1, ty = -1;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++) {
            if (g[i][j] == 'S') { sx = i; sy = j; }
            if (g[i][j] == 'T') { tx = i; ty = j; }
        }

    const int dx[4] = {-1, 1, 0, 0};
    const int dy[4] = {0, 0, -1, 1};
    vector<vector<int>> dist(n, vector<int>(m, -1));
    queue<pair<int, int>> q;
    dist[sx][sy] = 0;
    q.push({sx, sy});

    while (!q.empty()) {
        auto [x, y] = q.front();
        q.pop();
        for (int k = 0; k < 4; k++) {
            int nx = x + dx[k], ny = y + dy[k];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            if (g[nx][ny] == '#') continue;
            if (dist[nx][ny] != -1) continue;  // 来过
            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }

    cout << dist[tx][ty] << '\n';
    return 0;
}
```

`dist == -1` 兼当 `vis`。第一次赋值就是最短，不必分开两个数组。`S` 和 `T` 若是空地，不要把它们当墙。

### 4. `vis` 何时标记：入队时，不是出队时

边权为 1 时，**入队就标记**。若出队才标记，同一格子会被邻居重复入队，队列膨胀，最坏指数级，TLE 到怀疑人生。

错误心智：「我还没处理它，先别 vis。」那是 DFS 防环的另一种节奏。BFS 最短路里，第一次看见就已经确定距离，看见即盖章。

### 5. 队列里还可以多带状态

「最少步数」但有钥匙、有鞋子、能破一堵墙——状态不只是 `(x,y)`。把状态扩成 `(x,y,钥匙掩码)` 或 `(x,y,还剩几次破墙)`，`vis` / `dist` 多一维。

入门先把二维打穿。多一维时：维数乘起来 ≤ 1e7 量级通常能过，再大就要压缩或换算法。不要一上来三维 `bool vis[1000][1000][1000]`。

输出路径而不仅是距离：额外 `pre[nx][ny] = {x,y}`，从终点倒推到起点，再 `reverse`。倒推比 BFS 过程中带着整条 vector 走路要干净。

### 6. BFS vs DFS vs 最短路全家桶

| 场景 | 算法 |
| --- | --- |
| 网格 / 图，边权全 1，最短路 | BFS |
| 连通块、染色、能不能走到 | BFS 或 DFS 都行，网格常用 BFS |
| 边权非负任意 | Dijkstra + 堆 |
| 有负边无负环 | Bellman-Ford / SPFA（SPFA 易被卡） |
| 所有点对 | Floyd |
| 全排列、回溯搜方案 | DFS |
| 0 和 1 两种边权 | 0-1 BFS（双端队列） |

「搜方案」和「最短路」不是同一题。前者 DFS 更自然，后者 BFS。赛时先问：要的是存在性、计数，还是最小步数？

连通块：每个未访问空格开一次 BFS，块数 +1。洪水填充和最短路共用同一套队列，只是 `dist` 可以不记。

### 7. 复杂度

网格 n×m，每个格子入队一次、检查 4 个邻居：`O(nm)`。图是 `O(n+m)`（点数+边数）。

`queue` 里最多 O(nm) 个 pair。空间同阶。n、m = 1000 时 1e6，舒适；3000×3000 要看内存，`dist` 用 `int` 大约 36MB 量级，多数 OJ 够，但别再复制三份网格。

## 常见坑 / 注意事项

- **出队才 `vis`。** 队列爆炸。
- **先访问 `g[nx][ny]` 再判越界。** RE。
- **n、m 对调。** `cin >> n >> m` 后 `g` 读了 n 行，每行长度却是另一维。
- **起点 `dist` 忘了置 0。** 或起点是墙。
- **`S` 被你写成不可走。** 读图时 `S`/`T` 当 `.` 处理，或判墙时排除它们。
- **八连通题用了四方向。** 读题，「斜着走」算不算一步。
- **DFS 求最短步数。** 样例骗你。
- **`queue` 用 `priority_queue` 冒充。** 边权为 1 时功能碰巧对，常数更大；边权不为 1 时你以为自己在 BFS。
- **路径还原忘了 reverse。** 输出从终点写到起点，格式 WA。
- **多组数据 `vis` 没清空。** 见 [多组输入](多组输入与EOF.md)。

## 趣味课间：实验室经典翻车集

- **「我递归 DFS 加个 min 更新 dist。」** 能对，复杂度可以坏到走遍所有路径。网格 20×20 无墙时路径数是天文。BFS 才是正道。
- **「样例是 3×3。」** 正方形是帮凶。造一个 `1 5` 的窄走廊。
- **左右写反，`dy` 全是 0。** 只能上下移动，地图却要你去右边的 `T`。输出 -1，你骂出题人。打印一下能走到的 `dist` 网格，墙是 `#`、空地是数字，一眼看出波纹有没有缺一瓣。
- **Python 的 `deque` 忘了 `popleft` 写成 `pop`。** 那是 DFS 的栈。C++ 请用 `queue`，不要用 `vector` 当队列还 `erase(begin())`——那是 O(n²)。
- **走迷宫走成了 Dijkstra。** 功能对，代码长，常数大。边权为 1 时删掉堆，回到队列，是对自己的慈悲。

## 小结

边权为 1，最短步数 = BFS 的层数。入队即标记，方向用数组，越界写在下标前面。先求 `dist`，再需要时倒推路径。
