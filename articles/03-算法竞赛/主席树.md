# 主席树：每一版线段树都留着

> 读完你应该能：说出可持久化是「改一条链、其余结点共享」；用前缀版本差出 `[l,r]` 的权值线段树；求出静态区间第 k 小；先 [离散化](离散化.md) 再开叶子。
>
> 一句口号：**第 i 棵树 = 前 i 个数的权值线段树。区间 = 两棵树相减。**

## 背景 / 为什么要读这篇

[线段树](线段树入门.md) 改完就丢历史。题要「第 l 到 r 个数里第 k 小」，不能每次重建。主席树（可持久化权值线段树）给每个前缀留一个根：`root[i]` 表示 `a[1..i]` 插入后的树。`root[r]` 与 `root[l-1]` 对应结点相减，就是 `[l,r]` 的出现次数。

实验室有人每次复制整棵树 O(n)，MLE；有人查询时左右儿子搞反，k 掉进空侧；有人叶子没离散化，`1e9` 当下标。本篇钉静态第 k 小（洛谷 P3834）。带修、树上主席树是下一档。

## 正文

### 1. 只复制被改到的链

普通线段树单点加走 O(log n) 个结点。可持久化：这些结点 **new** 一份，儿子指针能复用旧的就复用。一版多 O(log n) 个点。n 版共 O(n log n) 空间。

```cpp
const int N = 100005, M = N * 25;
int ls[M], rs[M], sum[M], tot;
int root[N];

int copy_node(int p) {
    ++tot;
    ls[tot] = ls[p];
    rs[tot] = rs[p];
    sum[tot] = sum[p];
    return tot;
}

int upd(int p, int l, int r, int x) {  // 在权值 [l,r] 上给名次 x +1
    int np = copy_node(p);
    sum[np]++;
    if (l == r) return np;
    int mid = (l + r) >> 1;
    if (x <= mid) ls[np] = upd(ls[np], l, mid, x);
    else rs[np] = upd(rs[np], mid + 1, r, x);
    return np;
}
```

`p=0` 表示空结点，`ls[0]=rs[0]=sum[0]=0`，`copy_node(0)` 得到新空壳再改。`tot` 从 0 开始，结点编号 1..。

建树：先离散化到 1..m，`root[0]=0`，`root[i]=upd(root[i-1], 1, m, id(a[i]))`。

### 2. 两棵树相减，走第 k 小

左儿子表示值域较小的一半。`cnt = sum[ls[qr]] - sum[ls[ql]]` 是区间里落在左半的个数。k ≤ cnt 往左，否则 k-=cnt 往右。

```cpp
int kth(int ql, int qr, int l, int r, int k) {
    if (l == r) return l;
    int mid = (l + r) >> 1;
    int cnt = sum[ls[qr]] - sum[ls[ql]];
    if (k <= cnt) return kth(ls[ql], ls[qr], l, mid, k);
    return kth(rs[ql], rs[qr], mid + 1, r, k - cnt);
}
```

调用：`kth(root[L-1], root[R], 1, m, k)`，返回的是**名次**，再用离散化数组 `b[名次]` 还原成原值。

空间：n=1e5、log≈20，`N*25` 量级。`tot` 不要超过数组。多组数据 `tot=0` 并清空 `root`（结点数组可覆盖用）。

### 3. 和莫队、树套树

| 题 | 更可能 |
| --- | --- |
| 静态区间第 k 小 | 主席树 |
| 静态区间种类数 | 离线 BIT / 莫队 |
| 带单点改的第 k 小 | 树套树或带修主席，入门先别写 |
| 子树第 k 小 | dfs 序 + 主席树，或 [启发式合并](启发式合并.md) |

主席树在线、可持久；莫队离线、靠 `add`/`del`。第 k 小用莫队不自然。

## 常见坑 / 注意事项

- **值域用原值 1e9 当 `r`。** 先离散化，`m` 当叶子数。  
- **查询返回名次当答案。** 还要 `b[id]`。  
- **`k <= cnt` 写成 `<`。** 边界错一档。  
- **`copy_node` 忘了拷 `ls/rs`。** 共享断了，或野指针。  
- **空间开 `N*4`。** 可持久化是 log 倍，不是 4 倍。  
- **`L=1` 时 `root[0]` 不是 0。**

## 趣味课间：实验室经典翻车集

- **「可持久化就是把 n 棵线段树 new 出来。」** 共享才活得下。  
- **样例 k 总是 1。** 只会走最左。造 k=2、k=区间长度。  
- **离散化 `unique` 后 m 错，叶子对不上 `id`。** 对拍 n≤10 暴力 `vector` 排序取 `k-1`。见 [对拍](../00-团队指南/对拍.md)。  
- **主席树和线段树懒标记一起抄。** 静态第 k 小没有懒标记。

## 小结

每插入一个数，复制根到叶一条链。前缀版本相减得到区间权值树。左子树个数决定第 k 小往哪走。先离散化，再分配 `n log n` 个结点。

建议练习：

- 洛谷 [P3834 【模板】可持久化线段树 2](https://www.luogu.com.cn/problem/P3834)
- 手画插入 3,1,2 三版树，哪些结点是新的  
- n≤8 暴力对拍第 k 小
