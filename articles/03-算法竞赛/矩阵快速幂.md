# 矩阵快速幂：把递推乘到第 n 项

> 读完你应该能：把线性递推写成「列向量左边乘一个常矩阵」；用和 [数论入门](数论入门.md) 里相同的二进制快速幂算 `M^n`；用 2×2 矩阵在 O(log n) 内求出第 n 项斐波那契（取模）；知道邻接矩阵的 k 次方在数「走 k 步的方案」。
>
> 一句口号：**数字快速幂把乘法重复 log 次；矩阵快速幂只是把「乘」换成矩阵乘。**

## 背景 / 为什么要读这篇

斐波那契 `F(n)=F(n-1)+F(n-2)`，n=1e18。循环加会超时，公式带无理数会精度爆炸。竞赛标准解法：找到一个矩阵 `M`，使得

```text
[ F(n)   ]     [ 1 1 ] [ F(n-1) ]
[ F(n-1) ]  =  [ 1 0 ] [ F(n-2) ]
```

于是从初始向量出发，乘 `M^{n-1}`。矩阵乘一次 O(k³)，k=2 时常数可以忽略；指数仍是 log n。

[数论入门](数论入门.md) 说过「矩阵快速幂以后写」。实验室有人把矩阵乘写成 `c[i][j] += a[i][j] * b[i][j]`（对应元素相乘，那是另一门课）；有人 `n=0` 没处理单位矩阵；有人乘法中间不取模，`long long` 先爆再 `%` 已经不是原来的数。本篇把骨架钉死。

## 正文

### 1. 矩阵乘：行乘列

`C = A * B` 要求 A 的列数等于 B 的行数。`C[i][j] = Σ A[i][k] * B[k][j]`。

竞赛里 k 很小（2～100），用 `vector` 或定长数组均可。取模几乎总是要的。

```cpp
const long long MOD = 1e9 + 7;

struct Mat {
    int n;
    vector<vector<long long>> a;
    Mat(int n = 0, bool ident = false) : n(n), a(n, vector<long long>(n, 0)) {
        if (ident)
            for (int i = 0; i < n; i++) a[i][i] = 1;
    }
};

Mat operator*(const Mat& A, const Mat& B) {
    Mat C(A.n);
    for (int i = 0; i < A.n; i++)
        for (int k = 0; k < A.n; k++)
            if (A.a[i][k])
                for (int j = 0; j < A.n; j++)
                    C.a[i][j] = (C.a[i][j] + (__int128)A.a[i][k] * B.a[k][j]) % MOD;
    return C;
}

Mat qpow(Mat A, long long n) {
    Mat R(A.n, true);  // 单位矩阵，相当于数字 1
    while (n) {
        if (n & 1) R = R * A;
        A = A * A;
        n >>= 1;
    }
    return R;
}
```

和数字快速幂对照：`r = 1` 变成单位阵；`r *= a` 变成矩阵乘。`n=0` 时循环不进，返回单位阵——对应 `a^0 = 1`。

### 2. 斐波那契

约定 `F(0)=0, F(1)=1, F(2)=1, F(3)=2, ...`。

```cpp
long long fib(long long n) {
    if (n == 0) return 0;
    Mat M(2);
    M.a[0][0] = 1;
    M.a[0][1] = 1;
    M.a[1][0] = 1;
    M.a[1][1] = 0;
    Mat P = qpow(M, n - 1);
    // P * [F(1), F(0)]^T = [F(n), F(n-1)]^T
    return P.a[0][0];  // F(1)=1 时就是 P[0][0]*1 + P[0][1]*0
}
```

洛谷 P1962 一类模板：注意题目 `F(1)`、`F(2)` 的定义，差一项就全错。自己用 n=1,2,3,10 对拍暴力。

一般线性递推 `f(n) = a1 f(n-1) + ... + ak f(n-k)`：第一行放系数，下面放「移位」的 1。k=阶数。

```text
[ f(n)   ]   [ a1 a2 ... ak ] [ f(n-1) ]
[ f(n-1) ]   [ 1  0  ... 0  ] [ f(n-2) ]
[  ...   ] = [ 0  1  ... 0  ] [  ...   ]
[ f(n-k+1)]  [ 0  0  ... 0  ] [ f(n-k) ]
```

（最后一行是把 `f(n-k+1)` 从上一份向量的 `f(n-k+1)` 位置「移上来」，具体 0/1 布局按你向量的排列写，画一次就不会混。）

### 3. 图上走 k 步

邻接矩阵 `A[i][j] = 1` 表示 i→j 有边（或多条边就放条数）。则 `(A^k)[i][j]` = 从 i 到 j **恰好 k 步** 的路径条数（可重复点）。

n≤100、k=1e18 时矩阵快速幂。这和 [BFS](BFS网格最短路.md) 的最短路不是一回事：BFS 问最少步，这里问方案数或「能不能恰好 k 步」。

有边权、要最短路的 `min-plus` 矩阵（加法变 min、乘法变 +）也是同一套循环，换运算符。入门先把普通乘 + 取模写对。

### 4. 复杂度与什么时候不要上

| 规模 | 能不能 |
| --- | --- |
| k≤100，幂次 1e18 | 常规 |
| k=200，幂次 1e18，时限 1s | 看常数和模数，可能紧 |
| 要第 n 项但递推不是线性 | 矩阵帮不上，换 DP / 数论 |

`k^3 log n` 心里要有数：k=100，100³×60 ≈ 6e7 次运算量级，再乘 `__int128` 取模。

## 常见坑 / 注意事项

- **矩阵乘下标乘成 `a[i][j]*b[i][j]`。**  
- **不取模或先爆再取模。** 用 `__int128` 或保证 `MOD²` 进得了 `long long`。  
- **单位阵写成全 0。** `n=0` 或指数最低位处理会错。  
- **斐波那契初始项和题目差 1。**  
- **`operator*` 里 `C` 没清零。** 结构体构造函数已经 0，自己手写数组时容易忘。  
- **`A * B` 写成 `B * A`。** 矩阵乘法不交换。递推「左乘还是右乘」要和向量列/行约定一致。  
- **邻接矩阵幂去求最短路。** 那是路径计数。

## 趣味课间：实验室经典翻车集

- **「快速幂我只会数字。」** 把 `*` 换成函数对象，脑子就通了。  
- **样例 n=10。** 暴力循环也对。n=1e18 才是这题存在的理由。  
- **`fib(0)` 特判漏了，`qpow(M, -1)`。** 无符号绕一圈成超大数，TLE 兼 WA。  
- **把转移矩阵抄反：第一行 `{1,0}` 第二行 `{1,1}`。** 小 n 碰巧对，后面全飞。对拍 n=5、n=10。

## 小结

线性递推 ↔ 乘一个常矩阵。矩阵快速幂 = 单位阵 + 二进制平方。斐波那契、方案数、图上 k 步，都是同一副骨架。先画 2×2，再推广到 k。
