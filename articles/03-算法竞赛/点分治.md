# 点分治：路径统计先过重心

> 读完你应该能：求出当前连通块的重心；统计「过重心」的路径，再删掉重心对子树递归；解释为什么每层 O(n)、层数 O(log n)；分清它和 [启发式合并](启发式合并.md)（子树）不是同一问。
>
> 一句口号：**树上路径要么过重心，要么整条落在某一棵子树。过的当场算，剩下的分治。**

## 背景 / 为什么要读这篇

[LCA](LCA倍增.md) / [树剖](树链剖分入门.md) 擅长路径点权和、修改。路径条数「长度恰好 k」「异或为 0」这类，信息不好挂在链上。点分治把树按重心切开：先算所有穿过当前重心的路径，再把重心关掉，对每棵子树重复。

实验室有人重心找成任意点，链上退化成 O(n²)；有人先递归再统计，路径被算漏或算重；有人 `vis` 了点却还走回去。本篇钉模板题：是否存在长度为 k 的路径（洛谷 P3806 一类）。

## 正文

### 1. 重心：最大子树最小

对当前还活着的连通块，找一个点，删掉它后最大连通块最小。这个点叫重心。性质：每块大小 ≤ 总大小 / 2。于是分治层数 O(log n)。

```cpp
int sz[N], mx[N], ncur, rt;
bool vis[N];  // 已被当分治重心删掉

void get_sz(int u, int p) {
    sz[u] = 1;
    for (int v : g[u]) {
        if (v == p || vis[v]) continue;
        get_sz(v, u);
        sz[u] += sz[v];
    }
}

void get_rt(int u, int p) {
    mx[u] = ncur - sz[u];  // 向上那块
    for (int v : g[u]) {
        if (v == p || vis[v]) continue;
        mx[u] = max(mx[u], sz[v]);
        get_rt(v, u);
    }
    if (mx[u] < mx[rt]) rt = u;
}
```

调用：先 `get_sz(任意活点, 0)`，`ncur = sz[该点]`，`rt=0; mx[0]=ncur`（哨兵），再 `get_rt`。

### 2. 过重心的路径

重心为 rt。路径 = rt 到子树 A 某点 + rt 到子树 B 某点（或一端就是 rt）。

做法：枚举 rt 的每个活儿子，把该子树里所有到 rt 的距离收集起来，和**已经处理过的子树**做配对，再把这棵子树的距离并入「已有」。这样不会把同一子树内、不过 rt 的路径算进来——那些留给递归。

```cpp
int dist[N], cnt;
bool ans_k;  // 是否存在长度 k
int kneed;

void get_dist(int u, int p, int d) {
    dist[++cnt] = d;
    for (int v : g[u])
        if (v != p && !vis[v]) get_dist(v, u, d + w[u][v]);  // 边权按你的存法
}

void calc(int u) {
    vector<int> have;  // 已处理子树的距离；也可用桶
    have.push_back(0);  // 重心自己，距离 0
    for (int v : g[u]) {
        if (vis[v]) continue;
        cnt = 0;
        get_dist(v, u, /*边权*/ 1);
        for (int i = 1; i <= cnt; i++) {
            int need = kneed - dist[i];
            // 在 have 里查 need 是否存在
        }
        for (int i = 1; i <= cnt; i++) have.push_back(dist[i]);
    }
}
```

查询多个 k 时，用数组 `bool buck[kmax]` 或 `map`。注意清空：并入后、下一棵子树前不要误用别的块。**同一子树内部的两条腿不要配对**——上面「先查 have 再并入」保证了。

算完：`vis[u]=true`，对每个还活着的儿子，重求该块大小和重心，再 `calc` + 递归。

```cpp
void divide(int u) {
    rt = 0;
    get_sz(u, 0);
    ncur = sz[u];
    mx[0] = ncur;
    get_rt(u, 0);
    u = rt;
    calc(u);
    vis[u] = true;
    for (int v : g[u]) {
        if (vis[v]) continue;
        divide(v);
    }
}
```

层数 log，每层扫所有边 O(n)，总 O(n log n)，再乘查询结构。

### 3. 和树剖、启发式

| 问 | 更可能 |
| --- | --- |
| 路径点权和、带改 | 树剖 |
| 子树统计 | 启发式 / 主席树 dfs 序 |
| 路径长度 / 异或 / 点对数 | 点分治 |
| 静态区间第 k 小 | [主席树](主席树.md)，不是点分治 |

点分治改边权很烦。无改路径计数优先想它。

## 常见坑 / 注意事项

- **任选根当重心。** 链上 O(n²)。  
- **先 `vis` 再 `calc`。** 子树走不到。先 calc 再 vis。  
- **同一子树两条路径配对。** 先查旧 `have` 再并入。  
- **`get_sz` 没跳 `vis`。** 统计进已删点。  
- **多组数据 `vis` 没清。**  
- **边权不是 1，桶下标按距离开爆。** 改 map 或离散距离。

## 趣味课间：实验室经典翻车集

- **「分治就是点分治。」** CDQ、整体二分、线段树分治是亲戚，不是这一份 `vis` 重心。  
- **样例是菊花。** 重心就是中心，测不出链上选错根。造一条链。  
- **k=到自己的 0，把空路径当答案。** 读题是否允许。  
- **对拍只随机树不随机 k。** k 要覆盖 1、n-1、不存在的值。见 [对拍](../00-团队指南/对拍.md)。

## 小结

找重心，算过重心的路径，删掉重心，子树递归。重心保证块减半。先 calc 再 vis，先查再并入。子树问题去启发式，区间第 k 小去主席树。

建议练习：

- 洛谷 [P3806 【模板】点分治 1](https://www.luogu.com.cn/problem/P3806)
- 手找一条 7 点链的重心（应靠近中点）
