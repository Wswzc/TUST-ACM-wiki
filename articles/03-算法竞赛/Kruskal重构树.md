# Kruskal 重构树：路径上最大的边变成 LCA

> 读完你应该能：按边权从小到大合并，每合并一次新建一个父亲结点；说出原图两点在最小生成树上的最大边权，等于重构树上两点 LCA 的点权；用它回答「瓶颈不超过 limit 时和谁连通」。
>
> 一句口号：**叶子是原来的点。每条被选中的边长成一个新父亲，父亲的权就是这条边。**

## 背景 / 为什么要读这篇

[Kruskal](Kruskal.md) 得到一棵最小生成树。[LCA](LCA倍增.md) 问树上两点的交。卡车运输一类题问的是：两点之间，路径上最大边的最小值是多少。在 MST 上这条路径是唯一的（边权互不相同时），最大边就是答案。重构树把「最大边」直接做成 LCA 的点权，后面再挂可持久化或倍增都方便。

实验室有人仍然在原树上跳 LCA，边权放在边上，倍增时和点权搞混；有人新点的编号从 1 开始把叶子盖了。本篇叶子是 `1..n`，新点从 `n+1` 向上长。

## 正文

### 1. 怎么长出来

边按权值从小到大。并查集合并 u、v 的两个根时，若不同根，新建点 `tot`，点权 `val[tot]=w`，两个根的父亲都设成 `tot`。`tot` 自己的父亲先是自己。

```cpp
int fa[N * 2], val[N * 2], lc[N * 2], rc[N * 2], tot;

int find(int x) { return fa[x] == x ? x : fa[x] = find(x); }

int build(int n, vector<tuple<int, int, int>>& edges) {
    sort(edges.begin(), edges.end());  // 按边权升序
    for (int i = 1; i <= 2 * n; i++) fa[i] = i;
    tot = n;
    for (auto [w, u, v] : edges) {
        u = find(u);
        v = find(v);
        if (u == v) continue;
        ++tot;
        val[tot] = w;
        lc[tot] = u;
        rc[tot] = v;
        fa[u] = fa[v] = fa[tot] = tot;
    }
    return tot;
}
```

原图连通时，最后的 `tot` 是整棵重构树的根，结点数 `2n-1`。不连通就有多棵，根是那些「父亲仍是自己且被当过合并点或孤立点」的点。孤立点自己就是一棵只有叶子的树。

边权从大到小合并，得到的是**最大生成树**上的重构：LCA 点权变成路径上的**最小**边。瓶颈是「最大边最小」还是「最小边最大」，先看排序方向。本篇默认从小到大，LCA 权 = MST 路径上的最大边。

### 2. 为什么是最大边

归纳：两个连通块第一次被连起来时，用的是它们之间最便宜的边（Kruskal 的正确性）。重构树上，两片叶子的 LCA 就是这次新建的父亲，点权就是这条边。叶子到叶子的路径会经过这个父亲，更高的父亲权值更大（因为边是按权排序加入的），所以路径上最大的内部点权就是这个 LCA。原树路径上的最大边，就是这个值。

询问 `u` 到 `v`：在重构树上求 LCA，输出 `val[lca]`。u、v 不连通则没有 LCA（或 LCA 不存在于同一棵）。倍增前先把 `lc/rc` 收成邻接表，对每个根跑一遍。

### 3. 连通块

「从 u 出发，只走边权 ≤ limit 的边，能到哪些点」：在重构树上找到 u 最高的、点权仍 ≤ limit 的祖先（叶子点权可看成 0 或 -∞，不参与边权）。那个祖先的子树里的**叶子**就是答案。子树叶子可以用 DFS 序 + 出现位置表。先把「LCA 点权 = 瓶颈」写对，再做子树展开。

## 常见坑 / 注意事项

- **新点编号覆盖 1..n。**  
- **`fa[tot]=tot` 忘了，find 飞出去。**  
- **排序从大到小，仍把答案说成最大边。**  
- **原图边权相等时 MST 不唯一，但瓶颈相同。** 重构树的 LCA 权仍是这个瓶颈。  
- **在叶子上读 `val[u]` 当边权。** 叶子没有那条边。  
- **不连通还输出一个 LCA。** 先看是否同一根。

## 趣味课间：实验室经典翻车集

- **「重构树就是把 MST 存下来。」** MST 的边还在叶子和叶子之间。重构树把边变成了内部点。  
- **样例是一条边。** LCA 就是那个新点，权等于边权。再加一条更贵的边形成三角，瓶颈应仍是便宜的那条。  
- **倍增数组按 n 开，新点到 2n 越界。**  
- **和虚树一起建，关键点用了重构树的内部点当叶子。** 询问的端点是原图的点，编号 1..n。

## 小结

边从小到大，合并时新建父亲，权为边权。原图两点的 MST 瓶颈（路径最大边）等于重构树 LCA 的点权。叶子是旧点，内部点是被选中的边。从大到小合并则 LCA 权变成路径最小边。
