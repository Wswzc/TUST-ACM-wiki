# 斜率优化 DP：决策点在凸壳上挪

> 读完你应该能：把 `dp[i] = min_j dp[j] + (s[i]-s[j])^2` 写成「一条直线在某个点上取值」；用单调队列维护下凸壳；在横坐标、查询斜率都单调时从队头弹出过时决策。这不是 [单调队列优化 DP](单调队列优化DP.md) 那种「窗口里直接取 min(dp)」。
>
> 一句口号：**每个决策是一条线；最优决策是下凸壳上、斜率先碰到查询斜率的那个点。**

## 背景 / 为什么要读这篇

窗口 DP 的合法 j 是一段下标，队头就是最小 `dp[j]`。另一类：j 可以是任何 `< i` 的位置，代价里有 `s[i]*s[j]` 这种交叉项。枚举 j 是 O(n²)。当决策点的优劣能用斜率比较，并且插入顺序、查询斜率都单调，就可以只留凸壳上的点，均摊 O(n)。

实验室有人把斜率优化写成「队列里 dp 递增」；有人除法比较斜率，整除截断把壳切错。本篇用平方代价这一条式子，比较一律交叉相乘。

## 正文

### 1. 拆成直线

设 `s` 为严格递增的前缀和（元素为正）。令

```text
dp[0] = 0
dp[i] = min_{j<i} dp[j] + (s[i] - s[j])^2
```

展开：

```text
dp[i] = s[i]^2 + min_j ( (dp[j] + s[j]^2) - 2*s[i]*s[j] )
```

记 `X[j]=s[j]`，`Y[j]=dp[j]+s[j]^2`，`K[i]=2*s[i]`。要对所有已有 j 求

```text
min (Y[j] - K[i] * X[j])
```

j 比 k 更好（j、k 都已出现，`X[j]>X[k]`）当且仅当

```text
(Y[j]-Y[k]) / (X[j]-X[k])  ≤  K[i]
```

查询斜率 K 越大，最优 j 越靠右。

### 2. 下凸壳

按 j 增大插入。维护下标队列，相邻两点的斜率递增。新点 i 进来前，弹掉队尾：只要最后一段的斜率 **≥** 倒数第二段到新点的斜率，中间点就在壳的上面或边上，丢掉。

设队尾两点 a、b，新点 c。弹 b 当

```text
(Y[b]-Y[a]) * (X[c]-X[b]) >= (Y[c]-Y[b]) * (X[b]-X[a])
```

（X 严格递增，分母为正，不等号方向就是这样。）

查询：K 随 i 增大。弹队头，只要队头和下一个的斜率 **≤ K**，下一个更好：

```text
(Y[b]-Y[a]) <= K * (X[b]-X[a])
```

然后队头就是当前最优 j。用它算 `dp[i]`，再把 i 插进壳。j=0 要先在壳里。

```cpp
long long s[N], dp[N], X[N], Y[N];
int q[N], hh, tt;

bool pop_back(int a, int b, int c) {
    __int128 left = (__int128)(Y[b] - Y[a]) * (X[c] - X[b]);
    __int128 right = (__int128)(Y[c] - Y[b]) * (X[b] - X[a]);
    return left >= right;
}

bool better_next(int a, int b, long long K) {
    return (__int128)(Y[b] - Y[a]) <= (__int128)K * (X[b] - X[a]);
}

void solve(int n) {
    hh = tt = 0;
    dp[0] = 0;
    X[0] = s[0];
    Y[0] = dp[0] + s[0] * s[0];
    q[tt++] = 0;
    for (int i = 1; i <= n; i++) {
        long long K = 2 * s[i];
        while (hh + 1 < tt && better_next(q[hh], q[hh + 1], K)) hh++;
        int j = q[hh];
        dp[i] = dp[j] + (s[i] - s[j]) * (s[i] - s[j]);
        X[i] = s[i];
        Y[i] = dp[i] + s[i] * s[i];
        while (tt - hh >= 2 && pop_back(q[tt - 2], q[tt - 1], i)) tt--;
        q[tt++] = i;
    }
}
```

`s` 用 `long long`。乘积用 `__int128`，见 [数论入门](数论入门.md)。评测机若没有 `__int128`，见 [2026 赛场环境](../06-前沿动态/2026赛场环境.md)：世界赛稿是 `gnu++20`，通常有；国内老 OJ 要先试。

### 3. 什么时候这套壳不够

| 条件断了 | 后果 |
| --- | --- |
| X 不单调 | 不能只在队尾插，要平衡树或李超线段树 |
| 查询斜率不单调 | 不能弹队头，要在壳上二分 |
| 代价不是直线 | 斜率比较不成立 |

[单调队列优化 DP](单调队列优化DP.md) 比的是 `dp` 值本身，窗口还要过期下标。本篇队列里是决策点，过期靠斜率，不靠「j < i-k」。两套不要混抄。

用 n≤500 的 O(n²) 对拍，见 [对拍](../00-团队指南/对拍.md)。壳错一位，大 n 才爆。

## 常见坑 / 注意事项

- **用 `double` 比斜率。** 能过一些题，边界点会翻车。交叉相乘。  
- **`>=` 方向反了，壳变成上凸，min 变 max。**  
- **先插入 i 再查询。** 用自己转移。  
- **`s` 不严格递增仍用 `>` 做分母。** 相等要特判。  
- **`int` 乘 `K*dx`。**  
- **队空还取队头。** 至少留 j=0。

## 趣味课间：实验室经典翻车集

- **「斜率优化就是单调队列。」** 队列只是容器。比的东西不一样。  
- **样例递增且 n=5。** O(n²) 也对。对拍 n=20 再交 n=1e5。  
- **把窗口限制 k 和凸壳写在同一个 while 里，两个条件或在一起。** 先确认题是「全体 j<i」还是「j 在窗口里」。窗口加凸壳是进阶。  
- **最大代价却建了下凸壳。** 最大是上凸壳，不等号全翻。

## 小结

交叉项拆成 `Y - KX`。X 和 K 都单调时，下凸壳加队头弹出。比较用乘法不用除法。窗口最值 DP 是另一篇。

- 把本节式子 n≤8 打表，对照程序的 `dp[n]`
