# 容斥原理：加回去的那一次

> 读完你应该能：写出两集合、三集合的容斥；用二进制枚举 n 个条件的交（n≤20）；把「1..m 里能被某些数整除」算成 `m/lcm`；知道和 [莫比乌斯反演](https://oi-wiki.org/math/number-theory/mobius/) 是同一类计数，反演以后再学。
>
> 一句口号：**加单集，减两两交，加三三交。多算的减掉，减多的加回来。**

## 背景 / 为什么要读这篇

直接数「满足至少一条性质」常常会把同时满足两条的元素数两遍。[DFS](DFS回溯.md) / [状压](状压DP.md) 能枚举，n 大时不行。容斥把并集拆成交集：交集往往更好算（整除、颜色、棋盘放子）。

实验室有人只减两两、三个集合仍多减；有人 `lcm` 用 `a*b/gcd` 先乘爆 `int`。本篇从两三个集合写到 2^n 枚举。

## 正文

### 1. 两个和三个

```text
|A∪B| = |A| + |B| - |A∩B|
|A∪B∪C| = |A|+|B|+|C| - |A∩B|-|A∩C|-|B∩C| + |A∩B∩C|
```

奇次加，偶次减。n 个集合：枚举非空子集 S，交集体积符号是 `(-1)^{|S|+1}`。

### 2. 整除：1..m 里能被 a1..ak 至少一个整除

子集的交集 = 能被这些数的 lcm 整除的个数 = `m / lcm`。

k≤20 时枚举子集：

```cpp
long long lcm(long long a, long long b) {
    return a / std::gcd(a, b) * b;  // 先除后乘
}

long long count_divisible(long long m, const vector<long long>& a) {
    int k = (int)a.size();
    long long ans = 0;
    for (int s = 1; s < (1 << k); s++) {
        long long L = 1;
        int bits = 0;
        bool overflow = false;
        for (int i = 0; i < k; i++) if (s >> i & 1) {
            bits++;
            long long g = std::gcd(L, a[i]);
            if (L / g > m / a[i]) { overflow = true; break; }  // lcm > m
            L = L / g * a[i];
        }
        if (overflow || L > m) continue;
        long long add = m / L;
        if (bits & 1) ans += add;
        else ans -= add;
    }
    return ans;
}
```

`bits` 为奇加、为偶减，等价于符号 `(-1)^{bits+1}` 加到并集上。lcm 超过 m 时个数是 0。

「都不能被整除」= `m - count_divisible(...)`。

### 3. n 更大时

k≤20：2^k × k 次 gcd，足够。k=1e5 且问的是 1..n 里与 n 互质、或倍数个数，改用整除分块、欧拉函数、线性筛，不要 2^k。多个条件若结构是「gcd=1」，可能是莫比乌斯，本篇先会枚举。

[欧拉函数](欧拉函数.md) 本身就是容斥的一个闭式：1..n 里与 n 互质的个数。会筛 φ 之后，仍要会手写三集合容斥，因为题不一定长成 φ。

### 4. 和概率

容斥也用于概率的并。期望见 [期望入门](期望入门.md)，不要把「概率之和」当成并集概率。

## 常见坑 / 注意事项

- **三个集合减完两两就停。** 三重交被减没了，要加回来。  
- **`a*b/gcd` 溢出。** 先除。  
- **子集从 0 开始，空集 lcm 没定义还加了 m。** 从 1 开始。  
- **符号按位数写反。** 用 n=1、n=2 对一下：单集合应是正的。  
- **`std::gcd` 要 C++17。** 见 [2026 赛场环境](../06-前沿动态/2026赛场环境.md)。否则自己写 [数论入门](数论入门.md) 里的 gcd。

## 趣味课间：实验室经典翻车集

- **「容斥就是减一次。」** 那是两个集合。第三个集合会教育你。  
- **样例只有一个数。** 任何符号都对。三个质数 2、3、5，m=30，手算应是 15+10+6-5-3-2+1=22。  
- **用 double 存 lcm。** 大整数边界不再整除。  
- **2^25 还说是容斥模板。** 先算运算量。

## 小结

奇加偶减。交集好算才用容斥。整除的交集是 lcm。k≤20 枚举子集，先除后乘。空集不要算进并集。条件变成「所有整除」时用 [莫比乌斯反演](莫比乌斯反演.md)。

建议练习：

- 手算 2、3、5 在 1..30 的并

- 用 n≤10 暴力标记对拍 `count_divisible`
