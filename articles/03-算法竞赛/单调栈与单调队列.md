# 单调栈与单调队列：维护「下一个更大」和滑动窗口最值

> 读完你应该能：用单调栈求每个位置左边/右边第一个更大（更小）的元素；用单调队列在 O(n) 内求滑动窗口 min/max；知道栈里存下标比存值更不容易写丢边界。
>
> 一句口号：**栈里从栈底到栈顶单调，新来的把不合格的弹走。队列同样单调，还要从队头扔掉滑出窗口的过期下标。**

## 背景 / 为什么要读这篇

很多题长这样：「每个柱子向右能延伸到哪」「窗口长度为 k 的最小/最大值」。朴素对每个 i 扫描是 O(n²) 或 O(nk)。n=1e6 时，正确复杂度必须 O(n) 均摊。

单调栈、单调队列不增加新理论：还是栈和队列，只是**维持有序**，让队头/栈顶永远是当前需要的那个最值。

实验室有人窗口题上线段树，能过，但常数和代码量都亏；有人单调栈存了值没存下标，弹完不知道是谁。本篇两块模板，配柱状图和滑动窗口两道名题。

## 正文

### 1. 单调栈：下一个更大的数

对每个 i，找最小的 j>i 且 `a[j] > a[i]`（没有则为 n 或 -1）。

从左到右扫，栈里下标的 **a 值从底到顶递减**（栈顶最小）。新来的 x：把栈里所有「比 x 小」的弹掉——它们的「下一个更大」就是 x。然后 x 入栈。

```cpp
vector<int> nge(n, n);  // 右边第一个更大，没有则 n
vector<int> st;
for (int i = 0; i < n; i++) {
    while (!st.empty() && a[st.back()] < a[i]) {
        nge[st.back()] = i;
        st.pop_back();
    }
    st.push_back(i);
}
```

每个下标入栈出栈至多一次，O(n)。

变体：

| 要找 | 比较 | 扫描方向 |
| --- | --- | --- |
| 右更大 | 弹掉 ≤ 或 <（看是否严格） | 左→右 |
| 左更大 | 同上 | 右→左，或扫的时候看栈顶 |
| 右更小 | 弹掉 ≥ | 左→右 |

严格与否：`<=` 还是 `<`。题面「大于」用 `<` 弹；「大于等于」用 `<=` 弹。`{1,1}` 测一遍。

**存下标。** 值可以从 `a[st.back()]` 读。只要值，弹出来你不知道原位置，柱状图求面积会哭。

### 2. 柱状图最大矩形

每个柱子当「最矮的那根」，向两边延伸到比它更矮的柱子为止，面积 `h[i] * 宽度`。宽度由左右第一个严格更矮的位置决定——两侧各一次单调栈。洛谷 [P4147 玉蟾宫](https://www.luogu.com.cn/problem/P4147) 是二维版；一维原题在各 OJ 搜 “Largest Rectangle in Histogram”。

思路：对每个 i 找到左、右第一个 **< h[i]** 的位置（实现里用 `>=` 弹栈，相同高度只留一个代表），面积 `h[i]*(R-L-1)`。

```cpp
// 左第一个 < h[i]
vector<int> L(n), R(n);
st.clear();
for (int i = 0; i < n; i++) {
    while (!st.empty() && h[st.back()] >= h[i]) st.pop_back();
    L[i] = st.empty() ? -1 : st.back();
    st.push_back(i);
}
st.clear();
for (int i = n - 1; i >= 0; i--) {
    while (!st.empty() && h[st.back()] >= h[i]) st.pop_back();
    R[i] = st.empty() ? n : st.back();
    st.push_back(i);
}
long long ans = 0;
for (int i = 0; i < n; i++)
    ans = max(ans, (long long)h[i] * (R[i] - L[i] - 1));
```

`>=` 使得相同高度只让一个当「最矮代表」，避免重复矩形。`long long` 面积。

### 3. 单调队列：滑动窗口最值

固定窗口 k，对每个右端 r，求 `[r-k+1, r]` 的 min（或 max）。

队列里下标 **对应值单调递增**（队头最小）。新来 r：

1. 队头若 `q.front() < r-k+1`，滑出窗口，弹出  
2. 队尾凡是 `a[q.back()] >= a[r]` 的都弹掉（它们不可能再当窗口 min）  
3. r 入队  
4. 队头就是当前 min 的下标  

```cpp
deque<int> q;  // 存下标
vector<int> mn;
for (int i = 0; i < n; i++) {
    while (!q.empty() && q.front() <= i - k) q.pop_front();
    while (!q.empty() && a[q.back()] >= a[i]) q.pop_back();
    q.push_back(i);
    if (i >= k - 1) mn.push_back(a[q.front()]);
}
```

窗口 max：队内递减，弹尾条件改 `<=`。洛谷 [P1886 滑动窗口](https://www.luogu.com.cn/problem/P1886) 要同时输出 max 和 min，开两个 deque。

必须用 `deque`：两端都要弹。`queue` 不能弹尾，`vector` 当队列弹头是 O(n)。

### 4. 和线段树、稀疏表

静态、不可改、只查任意区间 min：ST 表 O(1) 查询，预处理 O(n log n)。滑动窗口是特殊的「区间长度为 k、右端连续扫」，单调队列 O(n) 更优。

动态改数组再问窗口：线段树。不要用单调队列硬刚修改。

### 5. 复杂度

每个元素进栈/进队、出栈/出队至多一次，均摊 O(1)，总 O(n)。空间 O(n)。

## 常见坑 / 注意事项

- **存值不存下标。**  
- **窗口过期条件写成 `q.front() < i-k` 差一。** 画 k=3 的下标。  
- **`queue` 没有 `back` 弹。** `deque`。  
- **严格性 `>` / `>=`。**  
- **柱状图面积用 `int`。**  
- **从右往左扫时栈的「左/右」搞反。**  
- **窗口还没形成满 k 就输出。** `i >= k-1`。  
- **单调栈当单调队列，忘了弹头。** 栈只能弹顶，过期的在栈底取不出来。

## 趣味课间：实验室经典翻车集

- **「我 ST 表过了滑动窗口。」** 能过。面试/赛时十分钟，单调队列更短。工具认题。
- **栈用 `vector` 当栈是对的，队列用 `vector.erase(begin)`。** 后者 O(n²)。
- **样例 k=n。** 全程一个窗口，队头一直是全局 min，掩盖过期逻辑错误。造 k=2、n=6。
- **下一个更大用 `sort` 离线。** 能做，慢，而且下标关系容易乱。单调栈就是为这个发明的。

## 小结

单调栈：弹掉不可能再当「下一个更 x」的，均摊 O(n) 找两侧边界。单调队列：再加一步扔掉离开窗口的下标，队头即窗口最值。都存下标。
