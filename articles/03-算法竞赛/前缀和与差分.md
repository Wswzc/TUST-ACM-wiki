# 前缀和与差分：区间变成两下标的算术

> 读完你应该能：用 `s[r] - s[l-1]` 回答「第 l 到第 r 个数的和」；用差分数组把「区间全体加 v」变成两个点的修改；知道二维前缀和那张「加三减一」的矩形图是怎么来的。
>
> 一句口号：**前缀和问区间，差分改区间。它们互为逆运算，像积分和导数。**

## 背景 / 为什么要读这篇

排序会了，二分会了，下一道签到常常长这样：

> 给你 n 个数，q 次询问，每次问区间 `[l, r]` 的和。n, q ≤ 1e5。

朴素做法每次从 l 加到 r，最坏 `O(nq)` = 1e10。评测机不会陪你加到天荒地老。

有人说「那我每次把数组存下来」。存不解决问题，**重复的加法**才是敌人。前缀和的主意非常无赖，也非常漂亮：把所有「从 1 加到 i」预先算好，询问变成两次减法。

实验室里这招会反复出现：统计、哈希、差分约束之前的直觉、树状数组的前身。第 1 学期把它写进手指，后面少走很多弯路。

## 正文

### 1. 前缀和：把「从开头累加」存下来

设原数组 `a[1..n]`（本篇用 1-based，减起来顺眼；0-based 也行，下面会对照）。

定义：

```text
s[0] = 0
s[i] = a[1] + a[2] + ... + a[i]     (i = 1..n)
```

那么区间和：

```text
a[l] + ... + a[r]  =  s[r] - s[l-1]
```

为什么？`s[r]` 是前 r 个的和，减掉前 `l-1` 个，剩下刚好 `[l, r]`。`l = 1` 时用到 `s[0] = 0`，所以 **`s[0]` 不是摆设，是防越界的垫片。**

手算一遍：

```text
下标 i    1  2  3  4  5
a[i]      2  3 -1  5  1
s[i]      2  5  4  9 10
          s[0]=0
```

问 `[2, 4]`：`s[4] - s[1] = 9 - 2 = 7`，而 `3 + (-1) + 5 = 7`。问 `[1, 5]`：`s[5] - s[0] = 10`。

代码（1-based，`a`、`s` 都开 `n+1`）：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    vector<long long> a(n + 1), s(n + 1);
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++) s[i] = s[i - 1] + a[i];

    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << s[r] - s[l - 1] << '\n';
    }
    return 0;
}
```

预处理 `O(n)`，每次询问 `O(1)`。这就是「门票一次，入场一万次」。

0-based 对照：`s[i]` 表示 `a[0] + ... + a[i-1]`（前 i 个），区间 `[l, r]` 闭区间的和是 `s[r+1] - s[l]`。两种约定不要混在同一题里。实验室建议：**前缀和默认 1-based**，和题面下标一致，少很多 `±1`。

### 2. 必须 `long long` 的那些时刻

`a[i]` 是 `int`、n = 1e5、每个 1e9 时，总和 1e14，`int` 只有大约 2e9。**`s` 用 `long long`，减法也在 `long long` 里做。** 写成：

```cpp
cout << s[r] - s[l - 1];  // s 是 vector<long long> 就对了
```

若 `s` 是 `int`，先溢出再赋给 `long long` 救不回来。模意义下的前缀和另说：先加再取模时，减法要写成 `(s[r] - s[l-1] % MOD + MOD) % MOD`，防止负数。入门题没模数就老老实实 `long long`。

### 3. 前缀和不止「求和」

任何满足「区间信息 = 两个前缀的差」的东西，都可以如法炮制。

| 要的区间信息 | 前缀里存什么 |
| --- | --- |
| 和 | 累加 |
| 异或 | 累异或（`s[r] ^ s[l-1]`） |
| 某个数出现次数 | `s[i] = 前 i 个里有几个 x` |
| 奇偶个数 | 分别开两个前缀 |

区间最值（最大 / 最小）**不能**用普通前缀减出来——`max(前 r 个) - max(前 l-1 个)` 毫无道理。最值要稀疏表或线段树，那是后话。看见「区间和 / 区间异或」再掏前缀和；看见「区间 max」不要硬套。

「和为 k 的子数组有多少个」是前缀和的进阶用法：`s[r] - s[l-1] = k` 等价于「之前有多少个前缀等于 `s[r]-k`」。用 `map` 或哈希表边走边记。本篇不展开，你会在 [map 与 set](../01-编程语言/map与set.md) 之后遇见。

### 4. 二维前缀和：冰箱贴上的那张图

矩阵 `a[1..n][1..m]`。定义 `s[i][j]` 为左上角 `(1,1)` 到 `(i,j)` 的矩形和。

递推（容斥）：

```text
s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j]
```

为什么减一块？`s[i-1][j]` 和 `s[i][j-1]` 把左上小矩形加了两遍。

查询子矩形 `(x1,y1)`～`(x2,y2)`（含边界）：

```text
s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]
```

减掉上边、左边两块之后，左上角那块被减了两次，要加回来。口诀：**加大矩形，减上面，减左边，加回左上角。** 和容斥原理是亲戚。

```cpp
// s 开 (n+1) * (m+1)，全 0
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j];

long long ask(int x1, int y1, int x2, int y2) {
    return s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1];
}
```

边界全靠 `s[0][*] = s[*][0] = 0`。查询时若 `x1=1`，`x1-1=0`，垫片再次立功。

### 5. 差分：前缀和的逆，专门改区间

前缀和擅长**问**区间。若题目改成：

> q 次操作，每次把 `[l, r]` 里每个数都加上 v，最后输出整个数组。

朴素每次改 r-l+1 个格子，q 次同样 1e10。差分的无赖之处：只改两个点。

定义差分数组 `d`：

```text
d[1] = a[1]
d[i] = a[i] - a[i-1]     (i = 2..n)
d[n+1] 多开一格当哨兵
```

于是 `a` 是 `d` 的前缀和：`a[i] = d[1] + ... + d[i]`。

把 `[l, r]` 都加 v，等价于：

```text
d[l]     += v
d[r + 1] -= v
```

直觉：从 l 开始，后面每一个前缀和都多了 v；到 r+1 把这多出来的 v 减掉，r 之后不受影响。像在走廊开头开灯、在结尾关灯。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    vector<long long> a(n + 2), d(n + 2);
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++) d[i] = a[i] - a[i - 1];  // a[0]=0

    while (q--) {
        int l, r;
        long long v;
        cin >> l >> r >> v;
        d[l] += v;
        d[r + 1] -= v;
    }
    for (int i = 1; i <= n; i++) {
        d[i] += d[i - 1];  // 还原成数组
        cout << d[i] << " \n"[i == n];
    }
    return 0;
}
```

若初始数组全 0，`d` 一开始也全 0，只做操作再前缀和还原。很多「区间覆盖 / 上下车」题属于这一类。

**差分和前缀和是一对：** 对 `d` 做前缀和得到 `a`；对 `a` 做差分得到 `d`。你会写其中一个，另一个就是倒着做。

二维差分同理，矩形加 v 改四个角，最后二维前缀和还原。入门先把一维打穿，矩形覆盖再翻 OI Wiki。

### 6. 什么时候不该用

| 操作 | 前缀和 / 差分够不够 |
| --- | --- |
| 静态区间和，多次询问 | 前缀和，够 |
| 一次性区间加，最后问整列 | 差分，够 |
| 既有区间加、又有区间查，交替发生 | 不够，要树状数组 / 线段树 |
| 区间最值 | 不够 |
| n ≤ 1000、q ≤ 1000 | 暴力也能过，但请用前缀和练手 |

「静态」的意思是：询问之前数组不再改，或改完再一次性还原。动态交替是进阶数据结构的开场白。

### 7. 复杂度与手感

| 做法 | 预处理 | 每次询问 / 修改 |
| --- | --- | --- |
| 暴力求和 | 0 | O(n) |
| 前缀和 | O(n) | O(1) |
| 暴力区间加 | 0 | O(n) |
| 差分 | O(n) 建，最后 O(n) 还原 | 每次修改 O(1) |

二维前缀和预处理 `O(nm)`，查询 `O(1)`。n、m = 1000 时预处理 1e6，非常舒适。

## 常见坑 / 注意事项

- **`s[l-1]` 在 `l=1` 时越界。** 开 `n+1` 并令 `s[0]=0`，或 0-based 想清楚。
- **`int` 装前缀和。** 见第 2 节。
- **差分漏了 `d[r+1] -= v`。** 于是 r 后面全部被加，像忘了关灯。
- **`r=n` 时 `d[n+1]` 没开。** 差分数组开 `n+2`。
- **题面 1-based，你 0-based，查询没换算。** 样例小，错位不一定看出来。
- **二维少减或多加一块。** 画 2×2 的矩阵手算一遍 `ask(1,1,2,2)`。
- **对前缀和再 `sort`。** 下标乱了，区间减出来的不是原区间。离散化是另一题。
- **模数下减法变负。** `+ MOD` 再 `%`。
- **把区间 max 用前缀和减。** 数学上不成立，AC 不了不是评测机的错。

## 趣味课间：实验室经典翻车集

- **「我前缀和写对了，样例差 1。」** 十有八九是 `s[r]-s[l]` 而不是 `s[l-1]`。闭区间少减了一个 `a[l]` 或多亏了一个。用开头那组 `2 3 -1 5 1` 把 `[2,4]` 手算贴在显示器上。
- **「差分比线段树简单，以后都用差分。」** 有交替查询时差分会沉默。工具箱里多几把锤子，不要看见钉子以外的东西也当钉子。
- **「二维前缀和公式我背不下来。」** 不要背。在纸上画三个重叠矩形，自己推一遍「加两次所以减一块」。推过的公式赛时写得出来，背的公式赛时写反。
- **上下车问题。** 车站 `[l, r]` 表示上车点 l、下车点 r+1。这就是差分。人数峰值是差分数组的前缀和的最大值。生活和算法突然握手。

## 小结

前缀和把区间和变成两次取值；差分把区间加变成两个点。先画下标，再写 `s[0]` 和 `d[n+1]` 两块垫片，`long long` 不要省。
