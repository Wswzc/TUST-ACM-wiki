# 后缀数组：把所有后缀排成字典序

> 读完你应该能：说出 `sa`、`rk`、`height` 三个数组各是什么；用倍增加基数排序在 O(n log n) 里求出它们；用 `height` 上的区间最小值得到任意两个后缀的 LCP；知道这和 [KMP](KMP.md) 不是同一件事。
>
> 一句口号：**sa[i] 是排第 i 的后缀从哪开始；height[i] 是它和前一名有多长的公共前缀。**

## 背景 / 为什么要读这篇

[KMP](KMP.md) 找一个模式。[哈希](字符串哈希.md) 比两段子串等不等。[字典树](字典树.md) 共享前缀。后缀数组把一个串的**全部后缀**排序。排序之后，相同的一段会挤在一起，公共前缀变成相邻后缀的 `height`。本质不同的子串个数、可重叠最长重复子串、两个后缀的 LCP，都从这张表来。

实验室有人 `rk` 和 `sa` 用反；有人倍增时 `rk[a+w]` 在越界处读到脏值，排名永远合并不了。本篇用 1-based 倍增，越界排名当成 0。

## 正文

### 1. 三个数组

串 `s[1..n]`（实现里可以 0-based 存字符，下标对外 1-based）。

| 名字 | 含义 |
| --- | --- |
| `sa[i]` | 字典序第 i 小的后缀的起点 |
| `rk[i]` | 从 i 开始的后缀排第几 |
| `height[i]` | `lcp(sa[i], sa[i-1])`，和前一个后缀的最长公共前缀 |

互逆：`sa[rk[i]]=i`。`height[1]` 无前一名，定为 0。

两个起点 i、j 的 LCP 不是 `height` 的某一格，而是它们排名之间的 `height` 最小值：不妨 `rk[i]<rk[j]`，

```text
lcp(i,j) = min(height[rk[i]+1 .. rk[j]])
```

这段最小值用 [ST 表](ST表.md)。

### 2. 倍增

先按第一个字符排序。然后假设已经按前 `w` 个字符排好，再按前 `2w` 个：每个后缀是一对 `(rk[i], rk[i+w])`，`i+w` 超出 n 则第二关键字为 0。用基数排序而不是 `std::sort`，否则 n=1e6 会慢。

```cpp
const int N = 1000005;
int sa[N], rk[N << 1], oldrk[N << 1], id[N], cnt[N], height[N];

void build_sa(const string& s) {
    int n = (int)s.size();
    int m = 256;
    fill(cnt, cnt + m + 1, 0);
    fill(rk, rk + 2 * n + 2, 0);
    for (int i = 1; i <= n; i++) rk[i] = (unsigned char)s[i - 1], cnt[rk[i]]++;
    for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
    for (int i = n; i >= 1; i--) sa[cnt[rk[i]]--] = i;
    for (int w = 1; w < n; w <<= 1) {
        int p = 0;
        for (int i = n - w + 1; i <= n; i++) id[++p] = i;
        for (int i = 1; i <= n; i++)
            if (sa[i] > w) id[++p] = sa[i] - w;
        fill(cnt, cnt + m + 1, 0);
        for (int i = 1; i <= n; i++) cnt[rk[id[i]]]++;
        for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
        for (int i = n; i >= 1; i--) sa[cnt[rk[id[i]]]--] = id[i];
        memcpy(oldrk, rk, sizeof(int) * (2 * n + 2));
        p = 0;
        for (int i = 1; i <= n; i++) {
            int a = sa[i], b = (i == 1 ? 0 : sa[i - 1]);
            if (i > 1 && oldrk[a] == oldrk[b] && oldrk[a + w] == oldrk[b + w]) rk[a] = p;
            else rk[a] = ++p;
        }
        if (p == n) break;
        m = p;
    }
}
```

`oldrk` 开到 `2n`，超出 n 的位置保持 0，第二关键字才不会读脏。

### 3. height

```cpp
void build_height(const string& s) {
    int n = (int)s.size(), k = 0;
    for (int i = 1; i <= n; i++) {
        if (rk[i] == 1) { height[1] = 0; continue; }
        if (k) k--;
        int j = sa[rk[i] - 1];
        while (i + k <= n && j + k <= n && s[i + k - 1] == s[j + k - 1]) k++;
        height[rk[i]] = k;
    }
}
```

`k` 每次至少减 1 而不是清零，总比较次数 O(n)。这是 height 能线性求的原因。

本质不同子串：每个后缀贡献 `n-sa[i]+1` 个前缀，减去和前一个后缀重复的 `height[i]`。总和即答案。

### 4. 和别的字符串工具

| 问 | 工具 |

| 一个模式在文本里 | KMP 或哈希 |
| 很多短模式 | AC 自动机 |

后缀自动机可以用更小的状态做一部分同样的题。入门先把 `sa/rk/height` 这三个名字说准。

## 常见坑 / 注意事项

- **`sa` 存的是排名不是起点。** 起点是 `sa[排名]`。  
- **`height` 下标用起点不用排名。** `height[rk[i]]` 才是和前一名的 LCP。  
- **`oldrk[a+w]` 越界。**  
- **字符 0 和「空第二关键字」撞车。** 排名从 1 开始，0 留给越界。  
- **多测计数数组 `cnt` 没清。**  
- **n=1e6 用 `vector<pair>` 排序倍增。** 多一个 log，容易 TLE。

## 趣味课间：实验室经典翻车集

- **「后缀数组就是把后缀丢进 set。」** set 比的是整个串，复杂度多一个 n。倍增只比两段已经算好的排名。  
- **样例 `a`。** 只有一个后缀。用 `aabaaa` 看 `sa` 是不是以最右边的 `a` 们打头。  
- **LCP 取成 `height[rk[i]]` 和 `height[rk[j]]` 的 min，中间没盖到。** 排名之间每一格都要。  
- **和 KMP 的 `pi` 混用。** `pi` 是模式自己和自己，`height` 是两个不同后缀。

## 小结

倍增：先排 1 个字符，再排 2、4、8。`sa` 与 `rk` 互逆。`height` 是相邻后缀的 LCP，任意两后缀的 LCP 是排名区间的 min。重复子串问 height，单个模式仍用 KMP。
