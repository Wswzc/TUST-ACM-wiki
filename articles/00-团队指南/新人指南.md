# TUST-ACM 算法实验室新人指南

> 这不是培养方案，也不是「学完就能保研 / 进大厂」的承诺。它是一份给 TUST-ACM 算法实验室新人的路线图：你现在站在哪、接下来读什么、哪些课值得花时间、哪些坑可以少踩一轮。
>
> 结构上向 [CS 自学指南（csdiy.wiki）](https://csdiy.wiki/) 取经——分人群、给地图、列课、讲工具——内容按我们自己的赛场和机房改写。

## 前言：梦开始的地方往往是 WA

很多人第一次走进 TUST-ACM 算法实验室，状态和 csdiy 作者写的那种大一很像：装了一个巨大的 Visual Studio，天天和 OJ 你死我活；会 `cin` / `cout` 和 `for`；CE、RE、WA 循环；作业能跑，但「能跑」的补集是没有头文件、没有模块、没有 Git。

竞赛这边还有一层更具体的挫败：**题会读，代码会写，一提交就错。** 你不知道错在边界、复杂度、还是自己根本没理解题意。课内老师在讲语法，网上大佬在晒蓝名，你夹在中间，有劲没处使。

这份指南想做的事很窄：把「有劲没处使」变成一条能走的路。路不是唯一的。想把 ICPC 打上去、想把计算机基础补扎实、想先找实习、想学会用 AI 而不是被 AI 带着抄——目标不同，取用的章节就不同。

**不要试图把知识库从第一篇读到第 1000 篇。** 和 csdiy 一样：全学完既不现实，也没必要，硬啃只会事倍功半。

## 如何使用这份指南

按你现在的身份选一条，只走那一条里加粗的部分。其余当目录，用到再点开。

### A. 刚进大学 / 刚进队，几乎没写过题

你的任务不是「成为竞赛选手」，而是**先能独立写出能编译、能交题的程序，并养成提问和记笔记的习惯。**

建议顺序：

1. 下文「必学工具」里的环境、编辑器、OJ、提问。
2. 「学习地图」的第 0 周和第 1 学期。
3. 课程地图里的「编程入门」+「算法竞赛 · 入门」。
4. 每搞懂一件小事，就按 [写作规范](写作规范.md) 写进知识库——哪怕只有两页。

课内 C / C++ 可以继续上，但不要把课内作业当成唯一的编程训练。OJ 上的简单题、一门真正带作业的入门课（例如 CS61A 或一门带 Lab 的数据结构课），往往比把语法课听三遍更有效。

### B. 明确想打 ACM / ICPC / CCPC

你的主线是**语言熟练度 → 基础算法与数据结构 → 专题 → 组队与赛时流程。** 工程课、前沿课可以并行，但不要用「我先把操作系统学完再刷题」当拖延。

建议顺序：

1. C++ 竞赛向最小工作流（编译、输入输出、STL、[对拍](对拍.md)）。
2. 学习地图的第 1 学期到第 2 年「竞赛主线」。
3. 课程地图「算法竞赛」整段；系统课放到寒暑假补。
4. 每周固定场次：Codeforces / AtCoder，赛后必复盘，复盘写成题解入库。

区域赛不是靠把知识库读完。它靠的是：模板能默写、题型能分类、队内能沟通、赛时能做取舍。

### C. 竞赛之外，还想把 CS 学扎实

你已经能做题，或暂时不走竞赛主线，但希望**体系、网络、操统、编译这些课不是考完就还。** 这时请把本指南当成 csdiy 的「本地入口」：先走竞赛或编程入门站住脚，再按「课程地图 · 计算机基础」选课，而不是同时开五门硬课。

原则：一门课配作业或 Lab 才算上过；只看完视频不等于学会。课内考试用老师的 PPT 和往年题应试，原理用高质量公开课补——两套可以并存。

### D. 时间很少：高年级、转专业、已经在实习

不要从编程入门重新读。选「删繁就简」那张核心课表，每学期最多啃 1～2 门带项目的硬课，其余用知识库里的短文补缺口。

## 先说清楚几件事

**培养方案不是地图。** 课表保证你毕业，不保证你会写程序、会打比赛、会找工作。课内该过的过，课外该补的补，两者不要互相道德绑架。

**优雅的代码从第一行就开始。** 只求 OJ 过、把逻辑全塞进 `main`、靠复制粘贴过关——题量变大或开始做课程 Project 时，debug 成本会把你吞掉。哪怕是 100 行的题解，也问自己：有没有重复？这个函数是不是在做三件事？

**工具是必修，不是炫技。** Git、命令行、编辑器快捷键、会提一个能让别人复现的问题——这些比再背一个语法边角更值钱。

**AI 是加速器，不是替身。** 用它解释编译错误、对比两种写法、生成对拍数据，可以。把题面丢进去交一份自己看不懂的代码，等于把训练时间卖了。赛时多数赛会不允许外部大模型；日常训练如果完全依赖它，上场会空。

**英语是检索能力。** 优质文档、课程网站、论文、Stack Overflow 大量是英文。不要求你能听完全英授课，但要能读题面、读报错、读官方 tutorial。

**自律比天赋常见得多。** 没有 DDL 的刷题和公开课很容易烂尾。给自己加外部约束：组队周训、公开赛日历、把复盘写进知识库让别人看见。

## 必学工具

磨刀不误砍柴工。下面按「越早越好」排列。不必一天学完，但不要拖到「等我刷完题再配环境」。

### 学会提问

这是第一条，不是鸡汤。不会提问的人会把队友变成人肉搜索引擎；会提问的人先自己缩小范围。一份能被回答的问题通常包含：

- 你想做什么（原题链接或一句话目标）
- 你做了什么（代码片段、编译命令、输入）
- 你看到了什么（完整报错、Wrong Answer 的一组数据）
- 你已经排除了什么

推荐阅读：[提问的智慧](https://github.com/ryanhanwu/How-To-Ask-Questions-The-Smart-Way/blob/main/README-zh_CN.md)。队内提问同样适用：先搜索知识库和聊天记录。

### 写代码的地方

| 场景 | 建议 | 说明 |
| --- | --- | --- |
| 日常刷题、写知识库 | [VS Code](https://code.visualstudio.com/) 或 [Cursor](https://cursor.com/) | 轻、插件够用；Cursor 适合读代码、改报错、写文档 |
| 大型课设 / Java | IntelliJ IDEA / CLion | 工程索引和调试更稳 |
| 竞赛选手备用 | Dev-C++ / 任何能一键编译的环境 | 机房电脑可能没有你的点满插件的 IDE |

原则：你要熟悉**至少一套**「打开 → 编译 → 运行 → 看报错」的路径，而不是只会按绿色三角。

### C++ 竞赛环境

ICPC 系比赛主流仍是 C++。你需要会：

- 用 `g++` 编译：`g++ -std=c++17 -O2 -Wall a.cpp -o a`
- 重定向测试：`./a < in.txt`
- 打开编译警告，而不是默默忽略

Windows 上逐步操作见 [第 0 周实操](第0周-Windows下g++与A+B交题.md)：w64devkit 解压即用。能在终端里编译，比只会点按钮更接近正式赛环境。

### Git 与 GitHub

版本控制和开源协作的基本盘。不会 Git 的人，知识库和课设迟早会变成 `最终版 (3) 真的最终.zip`。入门不必一次学完分支策略，先掌握：`clone`、`add`、`commit`、`pull`、`push`，以及「为什么不要把可执行文件提交上去」。

### OJ 与比赛平台

| 平台 | 用来干什么 |
| --- | --- |
| [洛谷](https://www.luogu.com.cn/) | 中文题面、专题、入门到省选的题库 |
| [Codeforces](https://codeforces.com/) | 周赛手感、等级分、题解社区 |
| [AtCoder](https://atcoder.jp/) | 题面清晰、适合练实现和思维 |
| 牛客 / 计蒜客等 | 国内高校赛、部分企业赛 |
| 队内 OJ / 校赛 | 以教练和队长通知为准 |

注册账号、弄清「怎么提交、怎么看评测结果」本身就是第 0 周作业。

### 命令行、Git、编辑器进阶

强烈建议在入门课之后抽一段时间过 [MIT Missing Semester](https://missing.csail.mit.edu/)（有中文翻译社区版本可搜）。它覆盖 Shell、Git、Vim、调试、性能——都是「课内不讲、工作天天用」的东西。

不必一上来就改信 Vim。先做到：终端不恐惧、能 `grep` / 重定向、Git 不会把仓库搞炸。

### AI 工具（正确用法）

- **可以：** 解释报错、问「这段 STL 在做什么」、生成随机数据、把复盘草稿改通顺、翻译英文题面后再自己做。细则见 [竞赛里怎么用 AI](../05-AI工具/竞赛里怎么用AI.md)。
- **不可以（训练期）：** 不读题直接要满分代码；不理解就交；用它代替自己写每场比赛的 A、B 题。
- **赛时：** 以当届规则为准。默认按不能用外部大模型来训练。

知识库 [`05-AI工具`](../05-AI工具/) 会持续补具体产品的用法。产品会变，原则不变：你要能在没有它的时候把题做出来。

## 学习地图（仅供参考）

计算机方向庞杂，算法竞赛只是其中一条很陡的路。下面按时间给一条**默认路径**。除了标了「入门 / 第 0 周」的部分，后面模块没有严格先后，满足先修即可跳转。

入队前可以用 8 小时左右看完 [Crash Course Computer Science](https://www.youtube.com/playlist?list=PL8dPuuaLjXtNlUrzyH5r6jN9ulIgZBpdo)（计算机科学速成课）。它不代替任何一门课，但能让「计算机不是魔法」这句话落地，后面学算法、体系、网络时不会两眼一抹黑。

### 第 0 周：活下来

目标：环境能跑、能交一道 A+B、知道实验室的人在哪训练。逐步操作见 [第 0 周实操：Windows 下 g++ 最短环境与 A+B 交题](第0周-Windows下g++与A+B交题.md)。

- 装好编译器 + 编辑器，终端编译 Hello World / A+B。
- 在一个 OJ 上通过最简单的输入输出题。
- 加入实验室沟通渠道，问清：周训时间、常用平台、下一场校内赛。
- 读完 [如何使用本知识库](如何使用本知识库.md)，在 INDEX 里随便点开一篇看结构。

### 第 1 学期：语言 + 基础算法

目标：C++ 写起来不卡手；前缀和、二分、贪心、基础搜索、简单动态规划见过面。

- 语言：语法够用即可，重点放在 STL。先掌握 [vector 与 sort](../01-编程语言/vector与sort.md)，再补 [string 读入](../01-编程语言/string读入.md)、[map 与 set](../01-编程语言/map与set.md)、[priority_queue](../01-编程语言/priority_queue.md)。输入格式见 [多组输入与 EOF](../03-算法竞赛/多组输入与EOF.md)。
- 刷题：洛谷入门 / 普及减，或 CF 800–1200。输入格式先过 [多组输入与 EOF](../03-算法竞赛/多组输入与EOF.md)；排序之后的查找过 [lower_bound 与二分](../03-算法竞赛/lower_bound与二分.md)；区间和过 [前缀和与差分](../03-算法竞赛/前缀和与差分.md)；「排序后扫一遍」过 [贪心入门](../03-算法竞赛/贪心入门.md)；网格最少步数过 [BFS](../03-算法竞赛/BFS网格最短路.md)；枚举方案过 [DFS 回溯](../03-算法竞赛/DFS回溯.md)；选或不选的最优过 [01 背包](../03-算法竞赛/01背包.md)。**质量优先**：每题写清复杂度，错题隔天重写。
- 数学：课内高数、线代认真对待。竞赛用到的数论、组合在专题里补，不要幻想「数学课听完就会做数论题」。
- 习惯：开始用 Git 管自己的题解仓库；开始写知识库短文（一篇一个算法）。

### 第 1 年结束：能打完一场训练赛

目标：3～5 小时的套题里，能稳定拿下签到和一道中等题；知道自己卡在实现还是思路。

- 数据结构：栈队列、[并查集](../03-算法竞赛/并查集.md)、[树状数组](../03-算法竞赛/树状数组.md) / [线段树](../03-算法竞赛/线段树入门.md)、[单调栈与单调队列](../03-算法竞赛/单调栈与单调队列.md)、图的遍历与最短路（[BFS](../03-算法竞赛/BFS网格最短路.md) / [Dijkstra](../03-算法竞赛/Dijkstra.md)）。最小生成树见 [Kruskal](../03-算法竞赛/Kruskal.md)，依赖见 [拓扑排序](../03-算法竞赛/拓扑排序.md)。
- DP 在第 1 学期 [01 背包](../03-算法竞赛/01背包.md) 之后补 [LIS](../03-算法竞赛/LIS.md)。
- 每周至少一场正式或虚拟比赛，赛后补题，补题写出「我卡在哪」。
- 组队试水：分工（谁读题、谁敲、谁构造数据）比个人英雄主义重要。
- 寒暑假：选一门带 Project 的课（CS61A / 数据结构公开课 / Missing Semester），避免整学期只会刷题。

### 第 2 年：区域赛水平与 CS 底座

竞赛主线：字符串（[KMP](../03-算法竞赛/KMP.md) / [字符串哈希](../03-算法竞赛/字符串哈希.md) / [AC 自动机](../03-算法竞赛/AC自动机入门.md)）、树（[LCA](../03-算法竞赛/LCA倍增.md) / [树上差分](../03-算法竞赛/树上差分.md) / [树链剖分](../03-算法竞赛/树链剖分入门.md) / [启发式合并](../03-算法竞赛/启发式合并.md) / [点分治](../03-算法竞赛/点分治.md)）、数论（[入门](../03-算法竞赛/数论入门.md) / [扩欧](../03-算法竞赛/扩展欧几里得.md) / [欧拉函数](../03-算法竞赛/欧拉函数.md) / [CRT](../03-算法竞赛/中国剩余定理.md) / [矩阵快速幂](../03-算法竞赛/矩阵快速幂.md) / [高斯消元](../03-算法竞赛/高斯消元.md) / [线性基](../03-算法竞赛/线性基.md)）、[二分图匹配](../03-算法竞赛/二分图匹配.md) / [最大流](../03-算法竞赛/最大流入门.md) / [费用流](../03-算法竞赛/费用流入门.md)、[差分约束](../03-算法竞赛/差分约束.md)、[强连通分量](../03-算法竞赛/强连通分量.md) / [2-SAT](../03-算法竞赛/2-SAT.md)、[欧拉路](../03-算法竞赛/欧拉路.md)、[数位 DP](../03-算法竞赛/数位DP.md) / [状压 DP](../03-算法竞赛/状压DP.md) / [单调队列优化 DP](../03-算法竞赛/单调队列优化DP.md)、[莫队](../03-算法竞赛/莫队.md)、[博弈论](../03-算法竞赛/博弈论入门.md)、[离散化](../03-算法竞赛/离散化.md) / [主席树](../03-算法竞赛/主席树.md)；更重要的是**把已学的写进模板并且真的能在压力下敲对。** 上场前对照 [2026 赛场环境](../06-前沿动态/2026赛场环境.md)，确认当站 `g++` 标准和有没有 AI。按模型找文章用 [专题对照表](../03-算法竞赛/专题对照表.md)，阶段叙事读 [从签到题到气球](../03-算法竞赛/从签到题到气球.md)。本地正确性：[对拍](对拍.md)。语言线补完 [lambda 与自定义排序](../01-编程语言/lambda与自定义排序.md)。

CS 底座（可与竞赛并行，建议寒暑假集中）：

- 计算机系统：CSAPP 或同等课程，至少做一部分 Lab
- 数据结构与算法的「课内版」：补证明和正确性，不只是模板
- 网络 / 操统 / 数据库：按兴趣与课表，一门一门来

实习与方向：读 [校招时间线与岗位](../04-行业认知/校招时间线与岗位.md)、[简历上的竞赛经历](../04-行业认知/简历上的竞赛经历.md) 和 [面试里怎么讲一道题](../04-行业认知/面试里怎么讲一道题.md)；进组前过一遍 [后端实习词汇表](../02-编程方向/后端实习词汇表.md)、[前端实习词汇表](../02-编程方向/前端实习词汇表.md)，有手再跑 [从 OJ 到 Web 的最小后端](../02-编程方向/从OJ到Web的最小后端.md)。避免大三才第一次听说招聘时间线。

### 之后：方向分化

区域赛、保研、工作、科研会把人拉开。知识库允许同时存在「网络流题解」和「后端实习复盘」。你的义务是：**把你已经走通的那条路写清楚**，而不是要求所有人跟你走同一条。

## 课程与资源地图

和 csdiy 一样：这是一份**有偏见的推荐**，不是官方培养方案。基础、入门类建议按序；其余按先修和兴趣选。链接以课程官网为准，打不开就搜课程号。

### 编程入门

| 资源 | 为什么值得 |
| --- | --- |
| [UCB CS61A](https://cs61a.org/) | 很多人的「原来 CS 可以这样学」。Python、抽象、带框架的 Project。零基础友好，作业量大。 |
| 课内 C / C++ | 用来过考试、混语法；不要指望它教你工程习惯。用 OJ 和下面的算法课补实践。 |
| [MIT 6.100L](https://www.youtube.com/playlist?list=PLUl4u3cNGP63WbdFxL8giv4yhgdMGaZNA)（原 6.0001 一脉） | 另一条 Python 科学入门。时间不够时，CS61A 和它二选一即可。 |

入门阶段刻意练两件事：模块化（函数不要巨型 `main`）、读别人的代码框架。低年级有框架的 Project 不是「助教帮你写好了所以学不到」，而是让你把注意力放在核心知识点上。

### 软件习惯与「优雅代码」

国内面向对象课容易变成语法边角。想知道工业界说的「好代码」长什么样，可以读 [MIT 6.031 / 6.102 Software Construction](http://web.mit.edu/6.031/www/) 的 notes（近年语言有迁移，读思想即可）：规格说明、测试、抽象。设计模式入门可用更浅的中文书，目的是「会抽象问题」，不是背名词。

竞赛强不等于实习强。后端、前端、客户端、数据、嵌入式路径不同。先用 [后端实习词汇表](../02-编程方向/后端实习词汇表.md)、[前端实习词汇表](../02-编程方向/前端实习词汇表.md)、[从 OJ 到 Web 的最小后端](../02-编程方向/从OJ到Web的最小后端.md) 和 [校招时间线与岗位](../04-行业认知/校招时间线与岗位.md)、[简历上的竞赛经历](../04-行业认知/简历上的竞赛经历.md) 建立词汇与写法，再选一个方向做**能放进简历的小项目**。项目可以小，但要有 Git 历史、README、你能讲清的设计取舍。

## 常见坑

- **环境配一周、题一道没交。** 第 0 周允许简陋，先交题。
- **收藏 30 个题单，一个都没刷完。** 一个题单用到你开始嫌它简单为止。
- **只打比赛不补题。** 掉分的场次才是教材。
- **用 AI 交题然后以为自己会了。** 合上对话框，把同一题从空白文件重写一遍。
- **把队友当搜索引擎。** 先搜索、再最小复现、再提问。
- **竞赛与课内对着干。** 绩点和训练可以排期，不要用其中一个当放弃另一个的道德理由。
- **不写下来。** 你今年搞懂的并查集路径压缩，下一届还会再搞三个晚上。写进 [`03-算法竞赛`](../03-算法竞赛/)，它才变成实验室的。
