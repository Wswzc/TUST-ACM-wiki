# 如何使用本知识库

> 这是仓库说明书：文章放哪、怎么找、怎么投。想「从零学起来」请先读 [新人指南](新人指南.md)。

## 三分钟上手

1. 从仓库根目录的 [`README.md`](../../README.md) 看七个分类。
2. 新人先打开 [新人指南](新人指南.md)，按自己的身份选一条路线，不要从上到下通读全部文章。
3. 查某篇具体内容时，用 [`INDEX.md`](../../INDEX.md)，或在编辑器里全局搜索标题 / 标签。
4. 准备写文章时，复制 [`templates/article-template.md`](../../templates/article-template.md)，再对照 [写作规范](写作规范.md)。

## 一篇文章长什么样

每篇文章开头有 YAML 头（`title`、`author`、`date`、`category`、`tags`、`level`、`status`）。浏览时可以只看：

- **导语**：适不适合现在的你
- **小结**：读完下一步去哪
- **参考资料**：原课程 / 原题链接

## 投稿最短路径

1. 复制模板 → 放到对应分类目录。
2. 按 [写作规范](写作规范.md) 填头部、写正文。
3. 在 [`INDEX.md`](../../INDEX.md) 加一行。
4. 有 Git 就提交；没有就直接放进文件夹。

## 阅读原则

- **不要试图学完。** 知识库会一直涨到第 1000 篇。按 [新人指南](新人指南.md) 里的路线取用。
- **一篇一事。** 找不到完整教程时，说明这件事还没人写，欢迎你补上。
- **队内经验优先。** 外部课程、题解可以链出去；我们自己踩过的坑，写在这里。
