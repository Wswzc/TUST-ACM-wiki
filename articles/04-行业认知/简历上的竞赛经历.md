# 简历上的竞赛经历：奖牌是证据，不是故事的全部

> 读完你应该能：用三行写清一场区域赛（赛事、名次、你在队里干什么）；把 ICPC / CCPC 奖牌翻译成招聘方能核对的事实；避免「精通算法」和把实验室写成「ACM 社团」；按开发岗 / 算法岗调整详略。
>
> 一句口号：**奖牌证明你能在压力下把题做出来；简历还要证明那和个人贡献、能讲清楚的细节是同一件事。**

## 背景 / 为什么要读这篇

[校招时间线与岗位](校招时间线与岗位.md) 说过：开发岗面试和区域赛不是同一场考试。TUST-ACM 算法实验室成员投实习时，最常见的两种翻车是对称的——有牌的人写「负责算法，获得银牌」，没牌的人把每周 CF 列成二十行。前者面试官追问「键盘谁敲的、卡题谁决定换」就空；后者像把训练日志贴进简历。

本篇只谈**竞赛经历怎么写**。不是美工、不是造假指南。实验室全称始终是 **TUST-ACM 算法实验室**（天津科技大学），不要写成「ACM 社团」「ACM 团队」当官方名。

## 正文

### 1. 一场比赛写成可核对的三件事

招聘方能查的是：哪一年、哪一场、学校队名、奖项。你能补充的是：分工。

建议结构（一条经历，不是一篇游记）：

```text
ICPC / CCPC ××× 区域赛 | 2025 | 银牌（第 x / 约 y 队）
天津科技大学 TUST-ACM 算法实验室 · 三人队
分工：主读题 / 主实现 / 构造与对拍（选你真正干的）
一句话：赛时独立完成最短路 + 并查集两题；卡在网络流时提议换题，后一题 AC。
```

| 要写 | 不要写 |
| --- | --- |
| 官方赛事名、年份、奖项 | 「全国大赛二等奖」这种无法检索的叫法 |
| 队内分工，用动词 | 「负责算法」（三个人都负责算法） |
| 一到两道你能讲 3 分钟的题 | 把题解网站抄进简历 |
| 可公开的榜单名次 | 把热身赛、邀请赛说成区域赛金牌 |

校赛、省赛、网络预赛也可以写，但要标明级别，不要和 ICPC 区域赛排在同一句里充数。Codeforces / AtCoder 写**当前或最高评分、以及「周训坚持」**，不要列 40 场参赛记录。

英文简历用官方名：`TUST-ACM Algorithm Laboratory, Tianjin University of Science and Technology`。ICPC 写 `ICPC Regional`，不要写 `ACM Contest Champion` 这种自己发明的头衔。

### 2. 开发岗和算法岗不是同一份详略

| 岗位 | 竞赛经历的任务 |
| --- | --- |
| 算法岗 / 量化研究一类 | 奖牌和题型是主菜。准备 2 道能手写的题：复杂度、边界、和错因 |
| 后端 / 前端 / 客户端 | 奖牌是加分。面试会很快转到项目、基础、[后端](../02-编程方向/后端实习词汇表.md) / [前端](../02-编程方向/前端实习词汇表.md) 词汇。竞赛条保持短，腾地方给 Git 历史上的项目 |
| 测开 | 强调构造数据、对拍、边界——这是竞赛里真的做过的事，比「我会测」有用 |

开发岗常见追问：「除了比赛你还写过什么能跑一周的东西？」没有项目时，诚实写课程大作业或知识库贡献，比虚构一个电商网站好。有项目时，竞赛经历不要压过项目的字数。

算法岗常见追问：「银牌那题建图怎么建的？」答不出来，奖牌会变成负分。合上电脑能讲，再写上简历。

### 3. 技能栏和实验室身份

技能栏写**用过并且能讲**的：C++ STL、Git、某一门课的 Lab。不要写：

- 「精通 C++ / 精通算法 / 精通数据结构」
- 「熟悉所有 STL」
- 把 [状压 DP](../03-算法竞赛/状压DP.md) 到 [费用流](../03-算法竞赛/费用流入门.md) 列成三十个标签

身份一行写清：`TUST-ACM 算法实验室成员`。实验室不是公司，不要写成「算法工程师（在校）」。队长、教学、出题、维护知识库可以另起一条**学生工作**，同样要有可核对的事实（哪年、做了什么、结果）。

[竞赛里怎么用 AI](../05-AI工具/竞赛里怎么用AI.md)：简历不要写「熟练使用 GPT 刷题」。可以写「用脚本对拍、用文档检索」——如果面试能演示。

### 4. 没牌的人怎么写

没区域赛奖牌不是空白。可写：

- 校内选拔 / 网络赛名次（标明范围）
- 训练量的诚实指标：例如「一学年完成洛谷提高组题单 ×× 题」，准备好被抽查一题
- 队内角色：测数据、写题解入库、带新人配 [g++](../00-团队指南/第0周-Windows下g++与A+B交题.md)

不要：把 CF 灰名写成「算法竞赛多年经验」；不要借队友的金牌。面试会问细节。

## 常见坑 / 注意事项

- **奖项年份、赛区写错。** 可查。  
- **三人金牌写成个人金牌。** ICPC 是队赛。  
- **技能栏和经历互相打脸。** 写了 Git，仓库却是一次 `Initial commit` 塞进全部代码。  
- **开发岗简历 70% 在讲银牌。** 岗位没听懂。  
- **用「ACM 社团」当官方名。** 对外是 TUST-ACM 算法实验室。

## 趣味课间：实验室经典翻车集

- **「我银牌，为什么还要项目。」** 开发岗在招能改仓库的人。银牌说明你会考试，项目说明你会上班。  
- **经历里写「使用 Dijkstra 解决最短路问题」。** 这是模板名，不是贡献。改成「赛时在 40 分钟内实现并过题，数据含自环与重边」。  
- **把知识库文章标题复制进简历当项目。** 可以写「参与实验室知识库，完成××篇题解」，面试官会打开链接——空仓库别写。  
- **三个队员简历里都写「队内主力、全部实现」。** 同一场面试撞车。事先对过口径。

## 小结

赛事、名次、分工、一句能展开的细节。奖牌是证据。开发岗把篇幅让给项目，算法岗把题讲透。没牌就写可核对的训练与角色。名称用 TUST-ACM 算法实验室。

建议接着：

- 把最近一场正式赛写成上面的四行，读给队友听，看他能否复述你的分工  
- 对照 [校招时间线与岗位](校招时间线与岗位.md) 决定这份简历偏开发还是偏算法
