# 校招时间线与岗位：开发、算法、测开不是同一场考试

> 读完你应该能：说出日常实习、暑期实习、秋招、春招大概落在学年的哪一段；分清开发 / 算法 / 测开 / 数据在考什么；知道竞赛奖牌是加分项不是通行证；避免大三暑假才第一次打开招聘官网。
>
> 一句口号：**时间线比算法题更不讲情面。窗口关掉了，紫名也投不进去。**

## 背景 / 为什么要读这篇

TUST-ACM 算法实验室很多人把日历活成「下一场 CF / 下一场区域赛」。互联网校招的日历是另一套：简历有投递窗口，实习有转正窗口，错过以年计。

[新人指南](../00-团队指南/新人指南.md) 写过「避免大三才第一次听说招聘时间线」。本篇把词汇表和粗时间线摊开。**年份会变、公司会变，窗口逻辑不太变。** 具体日期以当年官方为准，这里只建坐标系。

实验室不是职业中介。不保证「按这篇就能进大厂」。只保证：读完后不会把算法岗笔试当成后端岗笔试。

## 正文

### 1. 一张粗日历（本科视角）

按「毕业年的前一年」想象。数字是月，不是绝对日期。

| 时段 | 常见名字 | 你在干什么 |
| --- | --- | --- |
| 大二暑假～大三上 | 日常实习 / 寒假实习 | 第一次进组，简历从空白变成「做过」 |
| 大三 2～4 月 | 暑期实习提前批 / 正式批开始 | **含金量最高的窗口之一**，转正名额多在这儿 |
| 大三暑假 | 暑期实习在岗 | 转正答辩、留用 |
| 大三 7～10 月 | 秋招提前批 + 正式批高峰 | 无实习转正的人主战场；有 offer 的人比较选择 |
| 大四 3～5 月 | 春招 | 补录、考研落榜、秋招没成的人；名额通常更少 |
| 毕业前后 | 入职 | 户口、三方、毁约窗口，另一套麻烦 |

研究生把「大三」换成「研二」思考，窗口往往更挤。

**提前批**不是福利广告，是「更快、有时更少轮、有时更看重竞赛/项目」。实验室有人只投正式批，提前批已经招满。

日常实习时长可能三个月以下，对转正弱于暑期实习，但对「简历第一行」很重要。没有暑期实习并不等于不能秋招，只是故事要靠项目和竞赛自己圆。

### 2. 岗位不是一种笔试

| 岗位 | 日常在干什么 | 笔试 / 面试更像 | 竞赛奖牌 |
| --- | --- | --- | --- |
| 后端 / 客户端 / 前端 | 写业务、改接口、查日志、review | 语言 + 数据结构 + 计算机基础 + 项目 | 加分，很少替代项目 |
| 算法 / 机器学习 | 特征、模型、效果、论文或业务指标 | 手写题 + 概率统计 + 机器学习基础 | **很加分**，仍要能讲项目/论文 |
| 测开 / QA | 自动化、工具、质量 | 编码 + 测试设计，有的也考算法 | 加分 |
| 数据开发 / 分析 | SQL、数仓、报表或策略 | SQL 重，算法中等 | 看岗位 |
| 安全 / 基础架构 | 视组而定 | 更偏系统 | 系统竞赛、CTF 另说 |

区域赛金牌不会自动变成后端 offer。面试官会问：「这题你在队里负责哪一块？项目里你的代码在哪？」讲不清，奖牌只是简历第一行的装饰。

算法岗也不是「只会刷题」。很多组要的是把问题做成可上线的指标，不是把 CF 红名写进 PPT。

### 3. 和实验室训练怎么对齐

- **大一～大二：** 竞赛主线该走就走，同时用一个能讲的小项目学会 Git 和 README（见新人指南工程方向）。  
- **大二暑假：** 试一次实习或实验室/开源，哪怕很土。空白简历比蓝名更致命。  
- **大三上：** 看暑期实习日历，投递与区域赛冲突时**提前**和教练、队友拆时间，不要赛后才发现 DDL 过了。  
- **笔试算法：** 实验室训练直接有用。LeetCode 风格和 ICPC 风格不完全一样：更短、更工程、常考链表树和实现细节。不必把 ICPC 题单丢掉，补一层即可。  
- **计算机基础：** 操作系统、网络、数据库，面试比区域赛爱问。寒暑假 CSAPP / 课内别全扔。

保研、出国、就业三条路的时间线会互撞。选定一条主路，另一条当备选，不要三本日历都以为自己排得开。

### 4. 简历上的竞赛怎么写

写：**年份、赛事全称、奖项、队内分工（题、代码、调试）**。不要只写「ACM 金牌」。ICPC 区域赛、CCPC、省赛、蓝桥、天梯，名称不要混。

没有奖牌：写题量、训练方式、带过新生，诚实。编造奖项是事故，不是策略。

项目与竞赛并列时，项目要有：解决什么问题、你做了哪一层、用了什么技术、结果怎么验证。评委听不懂「我写了个 DFS」。

### 5. 信息从哪来（不绑定某公司）

- 公司招聘官网 / 实习招聘公众号（以当年为准）  
- 学校就业指导、实验室往届成员（比随机小红书可靠）  
- 牛客、校招日程汇总（注意广告和过期帖）  

本库不维护「某厂某年 DDL 表」——那会过期。过期信息比没有更坑。

## 常见坑 / 注意事项

- **只看竞赛，不看日历。**  
- **把算法岗和开发岗投同一份只写奖牌的简历。** 开发岗要项目和技术栈。  
- **暑期实习和区域赛硬刚，两头空。**  
- **春招当秋招用。** 名额和岗位类型都可能不同。  
- **毁约、三方当儿戏。** 学校和公司都有规则。  
- **用 AI 生成整份简历上的项目经历。** 面试第一问就穿。[竞赛里怎么用 AI](../05-AI工具/竞赛里怎么用AI.md) 的红线这里同样适用。

## 趣味课间：实验室经典翻车集

- **「我金奖，为什么后端一面挂在索引和事务。」** 因为岗位在考数据库。  
- **「秋招开始了？」** 你看到正式批时，提前批已结束。  
- **简历技能栏写「精通 C++ STL」。** 面试让你讲 `vector` 扩容，讲不清比不写更糟。  
- **全队同一天投同一家提前批然后集体去外省比赛。** 和教练排期。

## 小结

日历：暑期实习窗口往往在大三春季，秋招在大三下暑假到秋季，春招是补录。岗位：开发考工程与基础，算法考题与建模，测开考质量和编码。奖牌要配分工和项目。日期查当年官网。

建议接着：

- 打开学校就业网和一家你听说过的公司的招聘页，只看**时间线**，不投递，把月份记在自己的日历里  
- 用三句话写你最近一场比赛的队内分工，读 [简历上的竞赛经历](简历上的竞赛经历.md) 再落笔
