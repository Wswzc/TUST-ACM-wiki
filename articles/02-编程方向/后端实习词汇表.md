# 后端实习词汇表：HTTP、接口、SQL、Git 工作流

> 读完你应该能：听懂组里人说的「这个接口 GET 一下」「走主库还是从库」「先拉再推」；知道 HTTP 方法、状态码、JSON 大致是什么；会写最土的 `SELECT` / `WHERE` / 索引直觉；Git 用 `pull, branch, commit, push` 而不丢别人的代码。
>
> 一句口号：**竞赛交的是一份程序；实习交的是能在别人仓库里活下来的改动。**

## 背景 / 为什么要读这篇

[校招时间线与岗位](../04-行业认知/校招时间线与岗位.md) 说过：开发岗面试和区域赛不是同一场考试。TUST-ACM 算法实验室成员第一次进组，最慌的往往不是不会写 for 循环，而是会议室里的词：接口、网关、事务、回滚、code review。

本篇是**词汇表 + 最小动作**，不是 Spring 教程。目标：听得懂、问得出、Git 不拆家。框架一周能上手，词汇不懂会让人以为你没准备过。

## 正文

### 1. HTTP 与接口

浏览器和 App 跟服务器说话，多半是 HTTP：一次请求，一次响应。

| 词 | 人话 |
| --- | --- |
| URL / 路径 | 资源地址，如 `/api/users/3` |
| 方法 GET | 读，不应改数据 |
| POST | 新建、提交 |
| PUT / PATCH | 更新（细节组里规定） |
| DELETE | 删 |
| Header | 附加信息：登录 token、内容类型 |
| Body | 请求体，常见 JSON |
| 状态码 200 | 成功 |
| 400 | 你这请求有问题 |
| 401 / 403 | 没登录 / 没权限 |
| 404 | 没有这个资源 |
| 500 | 服务器自己炸了 |

**接口（API）：** 前后端约定好的「路径 + 方法 + 参数 + 返回」。实习第一周任务经常是：按文档补一个字段、修一个 500。

JSON：花括号的键值，`{"id":1,"name":"acm"}`。竞赛 `cin` 遇到它会想用 [stringstream](../01-编程语言/string读入.md)，组里用库解析，不要手写到凌晨。

REST 是一种风格：用 URL 表示资源、用方法表示动作。组里说「这个 REST 接口」= 按上面那套说话。不必背论文。

### 2. 服务端结构（只记分层）

粗线条：

```text
网关 / Nginx → 应用（业务代码）→ 数据库
                 ↘ 缓存（Redis）可选
                 ↘ 消息队列（异步）可选
```

| 词 | 人话 |
| --- | --- |
| 服务 | 一台或一群跑着的程序 |
| 中间件 | 日志、鉴权、限流，夹在请求真正进业务之前 |
| 配置 | 数据库密码、开关，不该写死在代码里 |
| 日志 | 出事时看的文本；别用 `cout` 当日志上生产 |
| 环境 | 开发 / 测试 / 生产，库和配置都不同 |

竞赛只有一份 `a.cpp`。实习有「在测试环境过了，生产配置没改」这种鬼。

### 3. SQL 与索引（最小能活）

表 = 网格；行 = 一条记录；列 = 字段。

```sql
SELECT id, name FROM users WHERE id = 3;
INSERT INTO users (name) VALUES ('tust');
UPDATE users SET name = 'acm' WHERE id = 3;
DELETE FROM users WHERE id = 3;  -- 生产上很危险
```

**WHERE 漏了** 的 UPDATE/DELETE 是事故。实习权限往往够你删库，手要抖。

**索引：** 课本目录。`WHERE id = 3` 若 id 是主键，很快；`WHERE name LIKE '%acm%'` 常常扫全表。组里说「这个查询没走索引」= 慢、锁表、被 DBA 盯上。

**事务：** 几句话要么一起成功要么一起失败。转账两行 UPDATE 要同一事务。竞赛没有「写到一半断电」；数据库有。

**主从：** 写主库、读可能走从库，从库有延迟。刚插入就去从库读，可能读不到——不是你代码抽了，是复制延迟。

### 4. Git 工作流（别当竞赛私仓）

竞赛仓库可以 `git push -f` 虐自己。公司仓库不行。

最小闭环：

```text
git pull                  # 先拿别人的
git checkout -b feat/xxx  # 自己的分支，不要直接在 master 改
# 改代码
git add / commit
git pull --rebase 或按组里规定合并主干
git push
提 Merge Request / Pull Request，等人 review
```

| 词 | 人话 |
| --- | --- |
| PR / MR | 请别人把你的分支合进去 |
| review | 有人看你的 diff，会提问 |
| conflict | 你们改了同一段，要手工合并 |
| CI | 自动编译测试，红了先看日志 |
| force push 到共享分支 | 通常禁止 |

commit 信息写人话：「fix: 用户列表空指针」，不要 `update` × 20。[写作规范](../00-团队指南/写作规范.md) 的「一篇一事」对 commit 同样适用。

可执行文件、`.env`、密码不要提交。竞赛 `a.exe` 进仓库已经丑，实习会报警。

### 5. 和竞赛训练的翻译

| 竞赛 | 实习 |
| --- | --- |
| 样例 | 测试环境的一条请求 |
| WA | 单测失败或 500 |
| 对拍 | 测试环境 vs 你的分支 |
| 队友读代码 | code review |
| 评测机 | CI + 生产监控 |
| 复杂度 | 慢查询、超时、内存 |

算法功底有用：边界、状态机、并发直觉。但实习第一周更看：会不会看日志、敢不敢问「这个接口的文档在哪」、Git 会不会把 `main` 推爆。

## 常见坑 / 注意事项

- **在生产库手敲 DELETE。**  
- **把密码写进 Git。**  
- **直接在 master 开发。**  
- **GET 请求去改库存。** 缓存和重试会打你。  
- **「接口 500 一定是后端。」** 也可能是参数、网关、依赖挂了。看日志。  
- **简历写精通 Spring。** 面试问事务隔离讲不清，见校招篇。

## 趣味课间：实验室经典翻车集

- **「我和 OJ 一样本地过了。」** 本地 SQLite，测试是 MySQL，SQL 方言不同。  
- **冲突选了 Accept All Mine。** 队友一周工作蒸发。问人。  
- **日志里打了用户密码。** 安全事故。  
- **用 AI 生成一整层 Controller 自己看不懂。** 面试和值班都穿。[竞赛里怎么用 AI](../05-AI工具/竞赛里怎么用AI.md) 同样适用：合上窗口你要能讲这个接口干什么。

## 小结

HTTP 是方法 + 路径 + 状态码。接口是约定。SQL 先 WHERE 再动手，索引是目录。Git 开分支、PR、不强制推主干。竞赛教你写对程序，实习教你在别人的系统里改一刀还不拆家。

建议接着：

- 用浏览器开发者工具看任意网站一个请求的方法和状态码  
- 在自己的知识库仓库练一次分支 + 合并，不要等实习第一天
