# 前端实习词汇表：页面、组件、状态、和那份接口

> 读完你应该能：听懂组里人说的「这个按钮绑在哪个组件」「状态在父还是在全局」「接口 400 了先看 Network」；知道 HTML / CSS / JS 各管什么；会用浏览器开发者工具看一次请求；明白前端实习不是 PS 切图大赛，也不是把 OJ 题糊进网页。
>
> 一句口号：**后端给数据，前端让人看见、点得动、点完还对得上那份接口。**

## 背景 / 为什么要读这篇

[后端实习词汇表](后端实习词汇表.md) 把 HTTP 和 Git 钉过一遍。同一条请求的另一头，是浏览器里的页面。TUST-ACM 算法实验室有人金奖，实习第一周卡在：「这页不是 HTML 文件，是一堆 `.tsx`」「改了字为什么屏幕没变」「CORS 是什么，评测机从来没骂过我」。

本篇是词汇表，不是 React 教程。目标：开会能听懂、issue 能对上号、不要把 CSS 和算法岗简历写成同一套词。框架一周能上手，词不懂会让人以为你没打开过浏览器的 F12。

## 正文

### 1. 三层：结构、样子、行为

| 层 | 语言 | 人话 |
| --- | --- | --- |
| 结构 | HTML | 标题、按钮、输入框、列表，文档里有什么 |
| 样子 | CSS | 颜色、间距、布局，长什么样 |
| 行为 | JavaScript（常写成 JS / TS） | 点击之后干什么，数据怎么变 |

浏览器拿到的往往不是三份手写文件，而是打包工具吐出的一坨。你改的是源码里的组件，保存后开发服务器热更新——竞赛里没有「改一行 `a.cpp` 不用重新 `g++`」这种体验，前端开发时有。

**TypeScript（TS）：** 带类型的 JS。实习仓库大量是 TS。竞赛 `int` 的安全感在这里变成 `interface` / `type`。能读类型，比先背框架 API 要紧。

**DOM：** 浏览器把 HTML 变成一棵能改的树。`document.querySelector` 是土法；现代框架不让你满页直接改 DOM，而是改「状态」，由框架去改树。

### 2. 组件与状态

**组件：** 可复用的一块 UI（按钮、表格、整页）。竞赛里的函数；前端里一个文件往往是一个组件。

**属性（props）：** 父传给子的参数，只读。像函数参数。

**状态（state）：** 组件自己会变的数据。点一次按钮计数 +1，这个数是状态。状态变 → 界面按规则再画一遍。

| 词 | 人话 |
| --- | --- |
| 受控组件 | 输入框的值以 state 为准，不是用户敲完就算 |
| 提升状态 | 两个子组件要共享一份数据，放到父组件 |
| 全局状态 | 登录用户、主题，很多页都要；仓库里可能叫 Redux / Pinia / 某 Context |
| 副作用 | 请求接口、设定时器；「画界面」之外的事，框架有专门的钩子 |

实验室翻车：在 `for` 里改 state 二十次，期望画二十帧，实际可能合成一次且顺序难看。竞赛里循环改数组很正常；前端里「设状态」是在发信号，不是 `a[i]=` 那么朴素。

### 3. 和后端那条缝：还是 HTTP

页面不是自己变出用户列表的。它 **GET/POST** 那份接口，拿到 JSON，再填进组件。[后端篇](后端实习词汇表.md) 的状态码在这里原样出现：

- 200：数据来了，你却渲染成空白——多半是字段名 `userName` vs `user_name`。  
- 401：token 没带或过期，不是 CSS 写错。  
- 500：先把 Network 里的响应体贴给后端，不要先改按钮颜色。

**CORS：** 浏览器拦「网页在 A 域、接口在 B 域」的跨域请求。本地 `localhost:5173` 调 `localhost:8080` 天天撞。竞赛 OJ 没有跨域；实习第一周有。解决是后端配头或开发代理，不是 `cin` 换 `scanf`。

打开 Chrome / Edge：**F12 → Network**。点一次按钮，看那条请求的 URL、方法、状态码、Request / Response。这是前端的 `cerr` 调试。Elements 看结构，Console 看报错。不会 F12 等于竞赛不会看编译器红字。

### 4. 工程词（听得懂即可）

```text
浏览器 ← 静态资源（HTML/JS/CSS，可能在 CDN）
       ← 接口 JSON（同一域或经网关）
源码：组件 + 路由 + 状态
工具：打包（Vite / webpack）、包管理（npm / pnpm）
```

| 词 | 人话 |
| --- | --- |
| 路由 | 地址栏路径对应哪一页，不是后端那个 REST 路径，但经常长得很像 |
| 打包 / 构建 | 把 TS 和组件变成浏览器能跑的 JS |
| npm | 装别人的库；`node_modules` 不要提交 Git |
| 组件库 | 现成按钮表格，Ant Design 一类；面试会问你**封装过什么**，不只是「用过」 |
| 响应式 | 窗口变窄时布局怎么收，不是竞赛「交互式题」 |
| 无障碍 | 键盘能用、读屏能读；大厂会考一点 |
| SEO | 搜索引擎怎么看见你的字；后台系统通常不在乎 |

Git 工作流与后端同一套：分支、PR、别 force push。[校招时间线](../04-行业认知/校招时间线与岗位.md) 里前端岗仍考数据结构与计算机基础，不是只考「会不会写 CSS 居中」。

### 5. 和竞赛的翻译

| 竞赛 | 前端 |
| --- | --- |
| 样例 | 某页的一组 mock 数据 |
| WA | 页面状态和接口对不上，或边界（空列表、超长用户名） |
| 对拍 | 设计稿 / 接口文档 vs 你的实现 |
| 复杂度 | 列表 1e4 行别每行绑一个重组件；滚动与虚拟列表 |
| 队友抢键盘 | 和设计师、后端对字段 |

算法功底有用：状态机（向导步骤）、树（DOM、组件树）、哈希（缓存 key）。第一周更看：会不会 F12、敢不敢问「设计稿和接口谁说了算」、不要在 `main` 分支直接改颜色。

## 常见坑 / 注意事项

- **用 JS 改样式解决一切，HTML 结构是乱的。**  
- **把密码和 token 写进前端仓库。** 前端代码用户都能看见。  
- **CORS 报错去改算法。** 看 Network，找后端或代理。  
- **简历写精通 React。** 面试问 hooks 依赖数组、问闭包过期，讲不清比不写糟。  
- **列表没有 `key`，或用下标当 key 还乱序删除。** 状态绑错行。  
- **只在自己 Chrome 窗口全屏看过。** 手机宽度、Safari、公司规定的浏览器。

## 趣味课间：实验室经典翻车集

- **「前端不就是调 CSS 吗。」** 实习任务经常是：对接口、清状态、处理空数据、把一个竞态（先发的请求后到）按对。CSS 是其中一刀。  
- **本地 mock 过了，联调全红。** 字段大小写、日期格式、分页从 0 还是从 1。和 OJ 样例过、系统测 WA 同一结构。  
- **`console.log` 打了用户手机号上生产。** 和后端打密码进日志一样，事故。  
- **用 AI 生成一整页自己讲不清数据从哪来。** [竞赛里怎么用 AI](../05-AI工具/竞赛里怎么用AI.md) 同样适用：合上窗口你要能指着屏幕说这一格对应哪个字段。

## 小结

HTML 结构、CSS 样子、JS/TS 行为。组件 + props + state。数据来自接口，F12 的 Network 是第一调试器。Git 和校招基础并不因为你写页面就豁免。竞赛教你把程序写对；前端教你把人对着的那一层写对，并且和后端那份 JSON 对得上。
